# ADR-0003: varias vistas, fichas únicas

Estado: aceptado para scaffolding.

Decisión: currículum introductorio, ocho etapas, bonus sistémico, challenge y prácticas son **vistas**; no generan copias divergentes de un concepto. La taxonomía de prompts/intenciones es transversal.

Consecuencia: una ficha puede aparecer en varias rutas y mantener un único ID y evidencia.
