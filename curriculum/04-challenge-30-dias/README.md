# 04 — Challenge de 30 días

**Función:** distribución pedagógica y comunitaria de todo el núcleo del curso, no una taxonomía temática adicional.

El usuario corrigió explícitamente una propuesta anterior: quería un challenge que **distribuyera el contenido de todo el chat**, no un plan genérico de captación. Posteriormente estableció **40 keywords/conceptos por día**, definiciones de máximo 30 palabras y entrega en 30 turnos, avanzando con «sigue» (18-11-2026, 20:11 y 21:18–21:19).

Estructura: `dia-01` … `dia-30`, 40 referencias a conceptos por día = 1.200. Para cada día: tema, conceptos enlazados, publicación breve, explicación ampliada, práctica, llamada a la comunidad y fuente.

**No confundir** el challenge de distribución con el curso completo: ambos deben referenciar las mismas fichas, evitando duplicación.
