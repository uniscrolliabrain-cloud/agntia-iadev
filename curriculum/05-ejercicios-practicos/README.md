# 05 — Ejercicios prácticos y talleres

El usuario pidió ejercicios para principiantes a partir de **repositorios públicos famosos y útiles**, que pudieran replicarse, personalizarse y utilizarse como tareas del curso (18-11-2026, 17:36). También pidió seleccionar modelos y repositorios para lanzar proyectos reales (18-11-2026, 18:32).

Clasificación de prácticas:
1. Comprensión de aplicaciones, archivos y flujos.
2. Prompts y revisión de trabajo de agentes.
3. Git, GitHub, ramas y PRs.
4. Clonación y personalización de repositorios open source.
5. Construcción con IA y combinación low-code + código.
6. Tests, depuración, seguridad y observabilidad.
7. Agentes, APIs, workflows e integraciones.
8. Diseño arquitectónico, toma de decisiones y liderazgo.

Cada ejercicio: `id`, objetivos, nivel, prerrequisitos, conceptos relacionados, repositorio público y licencia (cuando proceda), entorno, pasos, entregables, criterios de aceptación, tests, rúbrica, tiempo orientativo y enlaces a líneas del chat. No publicar detalles de repositorios privados en ejemplos externos.
