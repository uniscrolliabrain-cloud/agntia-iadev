# 0737 — Compatibility matrix: matriz de compatibilidad

## Contenido original

Es una tabla que indica qué versiones de distintos componentes pueden funcionar conjuntamente.

Por ejemplo\:

| Aplicación | Facturación v1 | Facturación v2 |
|--------|--------|--------|
| Web v1 | Compatible | No verificado |
| Web v2 | Compatible | Compatible |

Esta matriz es ficticia. En un proyecto real, sus resultados deben estar respaldados por pruebas.
