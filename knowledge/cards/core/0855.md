# 0855 — Webhook

## Contenido original

Es una notificación HTTP que un servicio envía a nuestra aplicación cuando ocurre un evento.

Por ejemplo, un proveedor puede avisar de que un mensaje fue entregado.

Un webhook debe validarse y procesarse con seguridad.
