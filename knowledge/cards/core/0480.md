# 0480 — ¿Qué es la gobernanza de integraciones?

## Contenido original

Es el conjunto de reglas y procesos para gestionar conexiones externas.

Puede incluir propietarios, permisos, credenciales, versiones, costes, auditoría y procedimientos de desconexión.

En una plataforma empresarial, la gobernanza evita que las integraciones se conviertan en conexiones difíciles de mantener o controlar.

**Descubrimiento\:** una integración profesional debe ser segura, observable, verificable y sustituible cuando cambian las necesidades del negocio.
