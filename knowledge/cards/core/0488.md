# 0488 — ¿Qué es el onboarding de usuarios?

## Contenido original

Es el proceso de incorporación y configuración inicial de una persona en una aplicación.

Puede incluir registro, verificación de correo, aceptación de invitación y selección de preferencias.

En software empresarial también puede incluir asignación de roles.
