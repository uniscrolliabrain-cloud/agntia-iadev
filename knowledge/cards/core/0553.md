# 0553 — ¿Qué es la granularidad de tareas?

## Contenido original

Es el nivel de detalle con el que se divide el trabajo.

Una tarea muy grande puede ser difícil de ejecutar y verificar.

Una tarea demasiado pequeña puede generar exceso de coordinación.

La granularidad adecuada permite asignar responsables y comprobar resultados.
