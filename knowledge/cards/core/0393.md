# 0393 — ¿Qué es la ingesta documental?

## Contenido original

Es el proceso de incorporar información desde fuentes externas a un sistema de conocimiento.

Puede incluir descargar documentos, extraer texto, identificar metadatos y preparar los datos para su indexación.

La ingesta no implica necesariamente que el modelo haya aprendido esa información en sus parámetros.
