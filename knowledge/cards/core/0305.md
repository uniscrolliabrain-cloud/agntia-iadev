# 0305 — ¿Qué es el contexto de un agente?

## Contenido original

Es la información disponible para el modelo durante una interacción.

Puede incluir instrucciones, archivos leídos, resultados de herramientas, mensajes anteriores y documentación del proyecto.

Un agente que no conoce una decisión arquitectónica importante puede proponer cambios incompatibles con ella.
