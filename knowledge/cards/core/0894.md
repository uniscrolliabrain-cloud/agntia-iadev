# 0894 — Alerting: alertas

## Contenido original

Es el mecanismo que notifica cuando se cumple una condición operativa.

Por ejemplo, una tasa de errores elevada durante varios minutos.

Una buena alerta debe ser accionable y evitar ruido innecesario.
