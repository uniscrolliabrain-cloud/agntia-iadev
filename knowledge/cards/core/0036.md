# 0036 — ¿Qué es un prompt?

## Contenido original

Un prompt es la entrada que proporcionamos a un modelo para orientar su respuesta.

Puede ser una pregunta, una instrucción, un documento, una imagen o una combinación de elementos.

Compara estas dos instrucciones\:

PROMPT IMPRECISO

Hazme una aplicación de tareas.

PROMPT CON REQUISITOS

Crea una aplicación web de tareas para una sola persona. Debe permitir añadir, completar y eliminar tareas, funcionar en móvil y guardar los datos localmente. No utilices servicios externos.

La segunda instrucción reduce la ambigüedad y facilita comprobar si se ha cumplido el encargo.
