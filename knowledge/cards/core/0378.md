# 0378 — ¿Qué es un system prompt?

## Contenido original

Es un conjunto de instrucciones de alto nivel proporcionadas al modelo dentro de un sistema conversacional.

Puede definir comportamientos, límites y objetivos generales.

Pero una instrucción textual no sustituye a controles de seguridad implementados fuera del modelo.
