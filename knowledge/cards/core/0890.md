# 0890 — Sentry

## Contenido original

Es una plataforma de seguimiento de errores y rendimiento.

Puede capturar excepciones, agrupar incidencias y proporcionar contexto para investigarlas.

Debe configurarse cuidadosamente para evitar enviar información sensible.

**Descubrimiento\:** OpenTelemetry ayuda a producir y transportar telemetría; Prometheus, Loki y Tempo pueden almacenarla; Grafana permite explorarla; Sentry aporta capacidades especializadas de diagnóstico.
