# 0177 — ¿Qué es RLS?

## Contenido original

RLS significa *Row-Level Security*, o seguridad a nivel de fila.

En PostgreSQL permite establecer políticas que controlan qué filas puede consultar o modificar una operación según su contexto y permisos.

Es una herramienta útil para reforzar el aislamiento entre empresas.
