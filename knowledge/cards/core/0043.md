# 0043 — ¿Qué es tool calling?

## Contenido original

*Tool calling* es el mecanismo mediante el cual un modelo solicita la ejecución de una herramienta mediante una interfaz definida.

Por ejemplo, puede pedir que se lea `package.json` para conocer las dependencias de un proyecto.

La aplicación valida y ejecuta esa solicitud y devuelve el resultado al modelo.

Esto permite que la IA trabaje con información y operaciones que no forman parte de sus parámetros entrenados.
