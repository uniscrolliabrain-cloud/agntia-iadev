# 0717 — Residual risk: riesgo residual

## Contenido original

Es el riesgo que permanece después de aplicar controles o correcciones.

Ningún sistema complejo puede garantizar riesgo cero.

La cuestión es identificarlo, evaluarlo y decidir si resulta aceptable para la operación prevista.
