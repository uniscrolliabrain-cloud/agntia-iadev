# 0002 — ¿Qué es el hardware?

## Contenido original

El hardware es la parte física de un sistema informático: procesadores, memoria, discos, pantalla, teclado y demás componentes.

El procesador ejecuta instrucciones. La memoria RAM mantiene temporalmente información necesaria para trabajar. El almacenamiento conserva archivos y programas incluso después de apagar el equipo.

**Analogía\:** el hardware es el cuerpo físico de una cocina: mesas, utensilios, hornos y neveras.
