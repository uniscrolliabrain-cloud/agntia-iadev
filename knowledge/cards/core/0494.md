# 0494 — ¿Qué es un permiso granular?

## Contenido original

Es una autorización definida para una operación o recurso específico.

Por ejemplo, `invoice.read`, `invoice.create` o `employee.invite`\.

Los permisos granulares permiten mayor precisión que categorías generales como «administrador».
