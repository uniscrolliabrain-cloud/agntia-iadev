# 0335 — ¿Qué es una métrica?

## Contenido original

Es una medida numérica del comportamiento o estado de un sistema.

Por ejemplo, el número de solicitudes por minuto, el porcentaje de errores o el tiempo de respuesta.

Las métricas permiten observar tendencias y comparar periodos.
