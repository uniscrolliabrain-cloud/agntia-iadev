# 0545 — ¿Qué es una épica?

## Contenido original

Es una unidad de trabajo grande que normalmente necesita dividirse en tareas o historias más pequeñas.

Por ejemplo, «implementar el sistema de facturación».

Una épica puede abarcar varias fases de desarrollo.
