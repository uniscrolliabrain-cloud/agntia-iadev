# 0195 — ¿Qué es Vercel?

## Contenido original

Vercel es una plataforma utilizada para desarrollar, desplegar y alojar aplicaciones web.

Ofrece integraciones con repositorios Git y mecanismos de despliegue.

Es una de las plataformas contempladas para el frontend de AgntiaPro.
