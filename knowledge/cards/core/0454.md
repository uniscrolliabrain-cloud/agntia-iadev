# 0454 — ¿Qué es un SDK?

## Contenido original

SDK significa *Software Development Kit*, o kit de desarrollo de software.

Es un conjunto de herramientas, bibliotecas y documentación que facilita trabajar con una plataforma.

Un SDK puede simplificar la autenticación, las solicitudes HTTP y el manejo de respuestas.
