# 0095 — ¿Qué es un string?

## Contenido original

Un *string*, o cadena de texto, representa información textual.

Por ejemplo\:

```javascript

const empresa = "Cafetería Sol";
const saludo = "Bienvenido";
```

Los textos suelen escribirse entre comillas.

Una dirección de correo electrónico, un nombre y una descripción pueden representarse como strings.
