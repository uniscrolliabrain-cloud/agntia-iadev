# 0594 — ¿Qué es la reproducibilidad de un build?

## Contenido original

Es la propiedad de poder generar el mismo artefacto a partir de las mismas entradas y condiciones definidas.

Puede requerir dependencias fijadas, herramientas controladas y procesos deterministas.

No todos los builds son reproducibles automáticamente.
