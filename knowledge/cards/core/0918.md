# 0918 — Docker

## Contenido original

Es una plataforma para empaquetar y ejecutar aplicaciones en contenedores.

Un contenedor proporciona un entorno aislado a nivel de sistema operativo, compartiendo el kernel del anfitrión en las configuraciones habituales.

Docker ayuda a reproducir entornos, aunque no sustituye por sí solo las pruebas ni la seguridad.
