# 0145 — ¿Qué es un sistema de diseño?

## Contenido original

Es un conjunto organizado de reglas, componentes y recursos que ayudan a mantener coherencia visual y funcional.

Puede definir tipografías, colores, espacios, botones, formularios y patrones de interacción.

En una aplicación con decenas de pantallas, un sistema de diseño evita que cada sección parezca un producto diferente.
