# 0080 — ¿Qué es un tag?

## Contenido original

Un tag es una referencia que identifica un punto concreto del historial Git.

Se utiliza frecuentemente para señalar versiones publicadas, como `v1.0.0`\.

A diferencia de una rama, un tag normalmente no avanza automáticamente con nuevos commits.
