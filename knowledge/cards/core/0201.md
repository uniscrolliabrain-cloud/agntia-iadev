# 0201 — ¿Qué es HTTPS?

## Contenido original

Es HTTP protegido mediante TLS.

Permite cifrar las comunicaciones entre cliente y servidor y verificar la identidad del servidor mediante certificados.

Es esencial para proteger información transmitida por Internet.
