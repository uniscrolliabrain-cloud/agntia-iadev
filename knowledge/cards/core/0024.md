# 0024 — ¿Qué es una condición?

## Contenido original

Una condición permite que el programa actúe de forma diferente según una situación.

Por ejemplo\:

```text
SI hay una cita disponible:
    permitir la reserva
SI NO:
    mostrar otra fecha
```

Esta estructura sencilla aparece constantemente en aplicaciones complejas.
