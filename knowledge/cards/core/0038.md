# 0038 — ¿Qué es la ventana de contexto?

## Contenido original

Es la cantidad máxima de información que un modelo puede manejar dentro de una interacción, medida habitualmente en tokens.

No es una memoria ilimitada.

Cuando un proyecto contiene miles de archivos, normalmente no resulta práctico introducirlo íntegramente en una sola conversación.

Por eso existen estrategias para seleccionar archivos relevantes, recuperar información y resumir decisiones anteriores.
