# 0232 — ¿Qué es la inyección SQL?

## Contenido original

Es una vulnerabilidad que aparece cuando datos controlados por un atacante pueden alterar la estructura de una consulta SQL.

Una defensa fundamental consiste en utilizar consultas parametrizadas y evitar construir SQL concatenando entradas no confiables.
