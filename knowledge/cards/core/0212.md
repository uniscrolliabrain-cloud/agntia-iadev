# 0212 — ¿Qué es una vulnerabilidad?

## Contenido original

Es una debilidad que puede ser aprovechada para comprometer un sistema.

Puede existir en el código, la configuración, una dependencia o un procedimiento operativo.

Por ejemplo, una API que permite consultar facturas sin comprobar permisos contiene una vulnerabilidad.
