# 0367 — ¿Qué es un transformer?

## Contenido original

Es una arquitectura de redes neuronales introducida en 2017 que utiliza mecanismos de atención para procesar relaciones entre elementos de una secuencia.

Los transformers son la base de muchos modelos de lenguaje modernos.

Existen diferentes variantes, incluidas arquitecturas de tipo encoder, decoder y encoder-decoder.
