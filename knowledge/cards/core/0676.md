# 0676 — Worktree: árbol de trabajo independiente

## Contenido original

Git permite crear varios directorios de trabajo asociados a un mismo repositorio.

Cada worktree puede tener su propia rama activa y sus archivos de trabajo.

Esto facilita que distintos agentes trabajen en paralelo sin compartir exactamente el mismo directorio.
