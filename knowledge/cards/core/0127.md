# 0127 — ¿Qué es un event handler?

## Contenido original

Es una función encargada de responder a un evento.

Por ejemplo, al pulsar un botón podemos ejecutar una función que añada una tarea.

```javascript

function guardarTarea() {
  console.log("Tarea guardada");
}
```

La función necesita conectarse al evento correspondiente para ejecutarse cuando el usuario pulse el botón.
