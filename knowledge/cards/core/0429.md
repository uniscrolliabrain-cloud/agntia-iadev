# 0429 — ¿Qué es una transición de estado?

## Contenido original

Es un cambio autorizado de un estado a otro.

Por ejemplo\:

`pending → running`

Una transición puede requerir condiciones, permisos o comprobaciones.

Registrar las transiciones facilita investigar el historial de una ejecución.
