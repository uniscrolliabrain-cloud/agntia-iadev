# 0151 — ¿Qué es el backend?

## Contenido original

El backend es la parte del software encargada de realizar operaciones que normalmente no se ejecutan directamente en la interfaz del usuario.

Puede procesar solicitudes, aplicar reglas, verificar permisos, consultar bases de datos y coordinar servicios.

Por ejemplo, cuando una persona crea una factura, el backend puede comprobar los datos, calcular importes y guardar el resultado.
