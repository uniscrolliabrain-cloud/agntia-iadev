# 1100 — Fallback strategy

## Contenido original

Es el procedimiento que define qué hacer cuando falla el modelo o proveedor principal.

Puede utilizar otro proveedor, reintentar o devolver un resultado controlado.

No debemos permitir que un fallback reduzca los requisitos de autorización o calidad.

**Descubrimiento\:** reducir latencia no significa únicamente utilizar un modelo más rápido. También podemos evitar llamadas innecesarias, ejecutar tareas independientes en paralelo y mejorar las consultas.
