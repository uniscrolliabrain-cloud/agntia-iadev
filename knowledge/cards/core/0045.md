# 0045 — ¿Qué es un agente de programación?

## Contenido original

Es un sistema de IA especializado en tareas de desarrollo.

Puede ayudar a explorar repositorios, implementar funciones, escribir pruebas, corregir errores y preparar cambios.

Entre las herramientas de esta categoría encontramos OpenAI Codex, Claude Code y Cline\.

No todas ofrecen las mismas capacidades ni utilizan los mismos modelos.
