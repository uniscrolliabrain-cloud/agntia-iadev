# 0022 — ¿Qué es un requisito?

## Contenido original

Un requisito describe una condición o capacidad que el software debe cumplir.

«El cliente puede seleccionar una fecha» es un requisito funcional.

«La página debe ser utilizable desde un móvil» es un requisito de calidad.

Los requisitos permiten explicar qué esperamos construir y comprobar después si se ha conseguido.
