# 0459 — ¿Qué es un middleware de integración?

## Contenido original

Es una capa de software situada entre componentes o sistemas para gestionar aspectos comunes de la comunicación.

Puede aplicar autenticación, validación, transformación de datos, registro de eventos y control de errores.

No todos los middleware necesitan ser servidores independientes.
