# 1069 — Memory isolation: aislamiento de memoria

## Contenido original

Es la separación de información según empresa, usuario, permisos y contexto.

En una aplicación multiempresa, un usuario no debería recuperar memorias privadas de otra empresa.

El filtrado debe aplicarse en el sistema de datos, no confiarse únicamente al prompt.
