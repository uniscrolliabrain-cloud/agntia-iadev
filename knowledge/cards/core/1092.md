# 1092 — Time to First Token: TTFT

## Contenido original

Es el tiempo que transcurre hasta recibir el primer token generado por un modelo.

Es útil para evaluar la capacidad de respuesta de interfaces conversacionales.

No representa necesariamente el tiempo hasta que una respuesta resulta útil.
