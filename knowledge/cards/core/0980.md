# 0980 — CI test pipeline: pipeline de pruebas

## Contenido original

Es una secuencia automatizada de verificaciones.

Por ejemplo\:

`Install → Typecheck → Unit Tests → Integration Tests → Build → Report`

GitHub Actions puede ejecutar estas comprobaciones en cada pull request.

**Descubrimiento\:** una suite de tests es una infraestructura de conocimiento. Conserva comportamientos esperados y ayuda a detectar cuándo dejamos de cumplirlos.
