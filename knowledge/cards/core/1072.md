# 1072 — SOP executor

## Contenido original

Es el componente que ejecuta los pasos de una SOP.

Debe gestionar estados, errores y resultados.

Puede utilizar modelos de IA en determinados pasos, pero no necesita delegarles el control de todo el procedimiento.
