# 0231 — ¿Qué es la validación de entradas?

## Contenido original

Es el proceso de comprobar que los datos recibidos cumplen las reglas esperadas.

Por ejemplo, una API puede exigir que el importe de una factura sea un número válido y que el identificador de empresa tenga un formato correcto.

La validación reduce errores y ayuda a defenderse frente a determinadas entradas maliciosas.
