# 0259 — ¿Qué es TDD?

## Contenido original

TDD significa *Test-Driven Development*\.

Es una técnica de desarrollo en la que se escribe primero una prueba que expresa un comportamiento esperado, después se implementa el código necesario y finalmente se mejora su estructura.

Suele resumirse mediante el ciclo rojo, verde y refactorización.
