# 0033 — ¿Qué significa entrenar una IA?

## Contenido original

Entrenar un modelo consiste en ajustar sus parámetros utilizando datos y procedimientos de optimización.

Imagina a una persona practicando miles de ejercicios y recibiendo señales sobre sus errores. La analogía es imperfecta, pero ayuda a entender la idea de mejorar el comportamiento mediante la experiencia de entrenamiento.

Una vez entrenado, el modelo puede utilizarse para realizar inferencias sobre nuevas entradas.
