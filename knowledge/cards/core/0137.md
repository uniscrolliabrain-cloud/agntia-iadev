# 0137 — ¿Qué es el renderizado?

## Contenido original

Es el proceso mediante el cual una aplicación determina qué contenido debe mostrarse.

En React, renderizar un componente significa evaluar su representación a partir de sus props y estado.

React coordina después las actualizaciones necesarias en la interfaz.
