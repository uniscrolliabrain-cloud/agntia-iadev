# 0941 — Static Application Security Testing: SAST

## Contenido original

Es el análisis de código sin necesidad de ejecutar la aplicación completa.

Permite detectar determinados patrones inseguros.

No puede demostrar por sí solo que una aplicación esté libre de vulnerabilidades.
