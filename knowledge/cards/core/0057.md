# 0057 — ¿Qué es una revisión de código?

## Contenido original

Es el proceso de examinar cambios para detectar errores, riesgos y oportunidades de mejora.

La revisión puede realizarla una persona, una herramienta automatizada o un agente de IA.

Una revisión útil no consiste solamente en preguntar si el código parece correcto.

Debe examinar comportamiento, seguridad, mantenibilidad y coherencia con el proyecto.
