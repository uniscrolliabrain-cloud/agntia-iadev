# 0754 — Hono como puerta de entrada HTTP

## Contenido original

Hono es un framework para construir APIs.

Una ruta puede recibir una petición desde la interfaz, un servicio o una aplicación externa.

```ts
import { Hono } from "hono";

const app = new Hono();

app.get("/health", (c) => {
  return c.json({ status: "ok" });
});

export default app;
```

Un agente puede crear esta ruta dentro de un patchset y preparar una prueba que compruebe que devuelve `200 OK`\.
