# 0636 — Anchor: ancla de código

## Contenido original

Es un fragmento utilizado para localizar dónde debe aplicarse una modificación.

En un sistema de reemplazos textuales, el anchor debe coincidir con el contenido esperado.

Si aparece varias veces, el parche podría aplicarse en un lugar incorrecto.

Por eso, conviene comprobar que sea único.
