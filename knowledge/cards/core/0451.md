# 0451 — ¿Qué es una integración de software?

## Contenido original

Es una conexión que permite a dos o más sistemas intercambiar información o realizar operaciones coordinadas.

Por ejemplo, una aplicación puede consultar el calendario de un usuario para mostrar sus próximas reuniones.

Las integraciones evitan tener que reconstruir todas las funcionalidades que ya ofrecen otros servicios.
