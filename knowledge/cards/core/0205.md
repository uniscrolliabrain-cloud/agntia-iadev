# 0205 — ¿Qué es la escalabilidad?

## Contenido original

Es la capacidad de un sistema para adaptarse a cambios en la demanda o carga de trabajo.

Una aplicación utilizada por diez personas puede necesitar una arquitectura diferente cuando la utilizan miles.

Escalar puede implicar optimizar código, ampliar recursos o distribuir trabajo.
