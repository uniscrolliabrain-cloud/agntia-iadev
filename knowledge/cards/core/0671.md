# 0671 — Squad: escuadrón de agentes

## Contenido original

Un *squad* es un grupo de agentes coordinados para cumplir una misión.

Puede incluir implementadores, revisores, testers y un supervisor.

No significa necesariamente que todos trabajen simultáneamente.
