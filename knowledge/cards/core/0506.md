# 0506 — ¿Qué es Row-Level Security?

## Contenido original

RLS significa *Row-Level Security*, o seguridad a nivel de fila.

En PostgreSQL permite definir políticas que restringen qué filas puede consultar o modificar una sesión o rol de base de datos.

Es una capa adicional de protección, pero requiere configuración y pruebas cuidadosas.
