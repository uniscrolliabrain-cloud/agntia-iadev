# 0007 — ¿Qué es un archivo?

## Contenido original

Un archivo es una unidad de información almacenada digitalmente.

Puede contener una fotografía, una canción, un documento o instrucciones de programación.

Los archivos suelen identificarse mediante nombres y extensiones, como `foto.jpg`, `informe.pdf` o `app.ts`\.

La extensión ayuda a reconocer el formato, aunque no determina por sí sola el contenido real.
