# 1022 — Interface: interfaz de programación

## Contenido original

Es una definición de las operaciones o estructuras que un componente ofrece.

En TypeScript podemos utilizar interfaces para describir datos.

```ts
interface Invoice {
  id: string;
  companyId: string;
  amountCents: number;
  currency: "EUR";
}
```

Una interfaz TypeScript ayuda durante el desarrollo, pero desaparece al compilar a JavaScript.
