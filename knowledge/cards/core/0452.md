# 0452 — ¿Qué es una API externa?

## Contenido original

Es una interfaz que un proveedor ofrece para que otros programas utilicen determinadas capacidades.

Por ejemplo, una API de correo puede permitir consultar mensajes o crear borradores.

Cada proveedor define sus endpoints, formatos, permisos y límites.
