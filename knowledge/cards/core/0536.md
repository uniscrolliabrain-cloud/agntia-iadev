# 0536 — ¿Qué es el feedback de interacción?

## Contenido original

Es la respuesta que proporciona la interfaz después de una acción.

Puede confirmar que un formulario se guardó, mostrar un error o indicar que una solicitud sigue pendiente.

El feedback ayuda a comprender el estado real del sistema.
