# 1097 — Prompt caching

## Contenido original

Es una capacidad disponible en determinados proveedores que permite reutilizar procesamiento de partes del contexto bajo condiciones específicas.

Puede reducir costes o latencia según el proveedor y la modalidad.

No debe confundirse con almacenar libremente respuestas completas.
