# 0730 — Integration boundary: frontera de integración

## Contenido original

Es el punto donde se controla el intercambio de datos y operaciones entre componentes.

Puede incluir validación, autenticación, transformación, control de errores y observabilidad.

**Descubrimiento\:** conectar dos sistemas no significa mezclar sus códigos. Significa definir cómo colaboran manteniendo responsabilidades claras.
