# 0179 — ¿Qué es OAuth?

## Contenido original

OAuth es un marco de autorización que permite conceder a una aplicación determinados accesos sin compartir directamente la contraseña del servicio original.

Por ejemplo, una aplicación puede solicitar permiso para consultar información de un servicio externo.

Para iniciar sesión utilizando identidades federadas suele intervenir OpenID Connect, construido sobre OAuth 2.0.
