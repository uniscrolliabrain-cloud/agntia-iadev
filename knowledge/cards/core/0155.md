# 0155 — ¿Qué es una respuesta HTTP?

## Contenido original

Es el mensaje que devuelve un servidor después de recibir una petición.

Puede incluir datos, encabezados y un código de estado.

Por ejemplo, una respuesta puede contener una lista de tareas o indicar que el usuario no tiene permiso para acceder.
