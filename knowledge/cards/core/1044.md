# 1044 — Exponential backoff

## Contenido original

Es una estrategia donde el tiempo entre reintentos aumenta progresivamente.

Por ejemplo\:

`1 s → 2 s → 4 s → 8 s`

Habitualmente se añade una variación aleatoria, llamada *jitter*, para evitar que muchos procesos reintenten al mismo tiempo.
