# 0468 — ¿Qué es el polling?

## Contenido original

Es una estrategia en la que una aplicación consulta periódicamente otro sistema para detectar novedades.

Por ejemplo, revisar cada cierto tiempo si hay nuevas tareas.

Puede ser sencillo de implementar, pero consume solicitudes y puede introducir retrasos.
