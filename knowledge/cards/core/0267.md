# 0267 — ¿Qué es una prueba de resiliencia?

## Contenido original

Es una prueba que evalúa cómo responde un sistema cuando ocurren fallos.

Por ejemplo, cuando una API externa tarda demasiado, una base de datos deja de responder o un worker se reinicia.

Su objetivo es comprobar que el sistema puede manejar determinadas condiciones adversas.
