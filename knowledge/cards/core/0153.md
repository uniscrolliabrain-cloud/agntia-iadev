# 0153 — ¿Qué es HTTP?

## Contenido original

HTTP significa *Hypertext Transfer Protocol*\.

Es uno de los protocolos fundamentales utilizados para intercambiar información en la web.

Define cómo se estructuran muchas solicitudes y respuestas entre clientes y servidores.
