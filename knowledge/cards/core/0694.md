# 0694 — Fix report: reporte de corrección

## Contenido original

Documenta una modificación destinada a resolver un defecto.

Incluye identificador del bug, archivos modificados, diff, pruebas y estado de verificación.

Un fix report permite saber si la corrección fue simplemente aplicada o si además quedó demostrada su eficacia.
