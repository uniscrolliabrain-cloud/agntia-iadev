# 0255 — ¿Qué es un stub?

## Contenido original

Es una implementación de prueba que proporciona respuestas predeterminadas.

Por ejemplo, un servicio ficticio puede devolver siempre una lista de tres clientes.

Aunque los términos mock y stub se utilizan a veces de forma intercambiable, tradicionalmente un stub proporciona datos y un mock también puede verificar interacciones esperadas.
