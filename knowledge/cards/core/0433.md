# 0433 — ¿Qué es un job?

## Contenido original

Es una unidad de trabajo preparada para su ejecución.

Puede incluir un identificador, datos de entrada, estado y metadatos.

Por ejemplo, `generar_informe_cliente` puede ser un job.
