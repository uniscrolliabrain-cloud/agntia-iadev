# 0449 — ¿Qué es la compensación de una operación?

## Contenido original

Es una acción destinada a contrarrestar determinados efectos de una operación anterior.

Por ejemplo, cancelar una reserva después de que falle una etapa posterior.

No todas las operaciones pueden deshacerse completamente, por lo que las compensaciones deben diseñarse cuidadosamente.
