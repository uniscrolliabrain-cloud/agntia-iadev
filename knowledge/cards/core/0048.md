# 0048 — ¿Qué es un IDE?

## Contenido original

IDE significa *Integrated Development Environment*, o entorno de desarrollo integrado.

Es una aplicación que reúne herramientas para escribir, navegar, ejecutar y depurar código.

Visual Studio Code es un editor extensible muy utilizado en desarrollo.

Puedes imaginarlo como un taller donde se encuentran el código, las herramientas y los instrumentos para comprobar el trabajo.
