# 0109 — ¿Qué es npm?

## Contenido original

npm es un gestor de paquetes y un registro de software utilizado ampliamente en el ecosistema JavaScript.

Permite instalar bibliotecas y herramientas desarrolladas por otras personas.

Por ejemplo, en lugar de programar desde cero cada componente, podemos utilizar paquetes existentes.
