# 0128 — ¿Qué es un formulario?

## Contenido original

Es un conjunto de controles que permite recoger información.

Puede incluir campos de texto, casillas, listas desplegables y botones.

Por ejemplo, un formulario para registrar un cliente puede solicitar nombre, correo electrónico y teléfono.
