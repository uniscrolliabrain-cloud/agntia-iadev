# 0791 — Neon

## Contenido original

Es un proveedor de PostgreSQL gestionado en la nube.

Permite utilizar una base de datos sin tener que administrar personalmente todo el servidor.

La aplicación sigue utilizando SQL y protocolos PostgreSQL.

**Diferencia\:** PostgreSQL es el motor; Neon es un servicio que lo ofrece y gestiona.
