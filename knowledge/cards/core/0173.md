# 0173 — ¿Qué es la autorización?

## Contenido original

Es el proceso de determinar qué acciones puede realizar una identidad.

Un empleado puede tener permiso para consultar sus tareas, pero no para modificar la facturación de toda la empresa.

Autorizar responde a la pregunta: «¿Qué puedes hacer?».
