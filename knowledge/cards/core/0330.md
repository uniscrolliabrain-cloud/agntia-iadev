# 0330 — ¿Qué significa dirigir desarrollo con IA?

## Contenido original

Significa transformar objetivos en requisitos, organizar tareas, asignar responsabilidades, establecer límites y verificar resultados producidos con ayuda de agentes.

No exige escribir personalmente cada línea de código.

Pero sí requiere desarrollar criterio suficiente para comprender riesgos, evaluar evidencias y tomar decisiones.

**Descubrimiento\:** dirigir agentes de programación es una disciplina de ingeniería, no solamente una habilidad para escribir prompts.
