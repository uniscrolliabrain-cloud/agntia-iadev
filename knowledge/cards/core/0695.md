# 0695 — Patchset report: reporte de patchset

## Contenido original

Resume las modificaciones realizadas dentro de un patchset.

Puede incluir hunks, fixes, archivos, dependencias, conflictos y resultados de tests.

Es especialmente útil cuando una campaña contiene muchos cambios pequeños.
