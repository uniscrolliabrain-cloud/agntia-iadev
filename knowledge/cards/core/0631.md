# 0631 — Fix: corrección de un defecto

## Contenido original

Un *fix* es una modificación destinada a resolver un problema concreto.

Puede consistir en cambiar una condición, añadir una validación, corregir un cálculo o reparar una integración.

**Ejemplo\:** impedir que una reserva se confirme si la mesa ya está ocupada.

Un fix no debe considerarse terminado solo porque el código haya cambiado. Necesita verificación.
