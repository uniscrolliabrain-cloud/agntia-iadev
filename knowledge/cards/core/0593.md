# 0593 — ¿Qué es la trazabilidad de una release?

## Contenido original

Es la capacidad de relacionar una versión publicada con su código fuente, pruebas, artefactos y decisiones de aprobación.

Por ejemplo, asociar una release a un commit específico.

Permite investigar problemas y reproducir resultados.
