# 0088 — ¿Qué es una release?

## Contenido original

Una *release* es una versión del software preparada para distribuirse o utilizarse.

Puede incluir archivos compilados, documentación y notas sobre los cambios.

Una release no implica necesariamente que el software esté desplegado en producción.
