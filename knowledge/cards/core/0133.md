# 0133 — ¿Qué es JSX?

## Contenido original

JSX es una extensión de sintaxis utilizada habitualmente con React.

Permite escribir estructuras visuales parecidas a HTML dentro de código JavaScript o TypeScript.

```jsx

function Saludo() {
  return <h1>Hola, mundo</h1>;
}
```

Las herramientas de desarrollo transforman JSX en instrucciones que React puede utilizar.
