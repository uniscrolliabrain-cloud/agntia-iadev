# 0697 — Command log: registro de comandos

## Contenido original

Es una relación de los comandos ejecutados y sus resultados.

Por ejemplo\:

```text
pnpm typecheck
Exit code: 0

pnpm test
Exit code: 1
```

Un código de salida `0` suele indicar éxito, mientras que otro valor puede indicar un error, según la herramienta.

El reporte debe conservar también la salida relevante y el contexto.
