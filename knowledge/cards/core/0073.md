# 0073 — ¿Qué es una feature branch?

## Contenido original

Es una rama creada para desarrollar una funcionalidad o cambio concreto.

Por ejemplo\:

`feat/calendario-reservas`

Puedes utilizarla para construir un calendario sin alterar directamente el código de `main`\.
