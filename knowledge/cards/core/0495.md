# 0495 — ¿Qué es una política de autorización?

## Contenido original

Es una regla que determina cuándo una acción está permitida.

Puede combinar roles, atributos y condiciones.

Por ejemplo, un empleado puede consultar determinadas facturas, pero no modificar datos bancarios.
