# 0604 — Repository tree: árbol de archivos

## Contenido original

Es la representación jerárquica de las carpetas y archivos de un proyecto.

Permite descubrir dónde vive cada componente.

Un árbol no explica por sí solo cómo funciona el software, pero ayuda a localizarlo.
