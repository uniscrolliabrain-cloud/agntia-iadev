# 0470 — ¿Qué es un rate limit de API?

## Contenido original

Es una restricción sobre cuántas solicitudes puede realizar un cliente durante determinado intervalo o bajo otras condiciones.

Puede expresarse mediante cuotas, límites por usuario o restricciones por operación.

Superar estos límites puede provocar respuestas de error o restricciones temporales.

**Descubrimiento\:** integrar servicios externos también significa administrar permisos, credenciales, límites y comunicaciones que pueden fallar.
