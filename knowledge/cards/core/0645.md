# 0645 — Patch dependency: dependencia entre parches

## Contenido original

Existe cuando una modificación necesita que otra se aplique primero.

Por ejemplo, un fix puede requerir que previamente se haya añadido un campo al esquema de datos.

Ignorar estas dependencias puede provocar errores.
