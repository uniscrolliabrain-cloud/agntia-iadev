# 0018 — ¿Qué es una base de datos?

## Contenido original

Una base de datos es un sistema organizado para almacenar, consultar y modificar información.

Puede guardar clientes, tareas, facturas, mensajes o permisos.

Piensa en una biblioteca: los libros están organizados de forma que puedan localizarse. Una base de datos hace algo parecido con información digital, utilizando estructuras y mecanismos de consulta.
