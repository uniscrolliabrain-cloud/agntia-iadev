# 1090 — Cost guardrail

## Contenido original

Es una regla que limita o controla el consumo económico.

Puede establecer presupuestos, umbrales, avisos o bloqueos para determinadas operaciones.

**Descubrimiento\:** el dato más importante no siempre es el precio por millón de tokens. Puede ser cuánto cuesta completar una operación empresarial correctamente.
