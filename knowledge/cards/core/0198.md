# 0198 — ¿Qué es Docker?

## Contenido original

Docker es una plataforma y conjunto de herramientas para construir, distribuir y ejecutar aplicaciones en contenedores.

Un contenedor no convierte automáticamente una aplicación en segura o escalable.

Es una herramienta para empaquetar y operar software.
