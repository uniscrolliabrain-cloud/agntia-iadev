# 0388 — ¿Qué es un modelo rápido y un modelo deliberativo?

## Contenido original

Es una distinción arquitectónica entre modelos o configuraciones optimizados para respuestas rápidas y otros que pueden dedicar más recursos a problemas complejos.

No constituye una clasificación técnica universal.

En una aplicación puede ser útil separar la interacción conversacional inmediata de determinadas operaciones de análisis más exigentes.
