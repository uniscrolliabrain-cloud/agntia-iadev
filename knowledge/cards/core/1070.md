# 1070 — Memory lifecycle: ciclo de vida de memoria

## Contenido original

Es el proceso de crear, validar, almacenar, actualizar, recuperar y eliminar información persistente.

Puede incluir caducidad, revisión y auditoría.

**Descubrimiento\:** una memoria útil no consiste en guardar todo indefinidamente. Consiste en recuperar información pertinente, autorizada y actualizada.
