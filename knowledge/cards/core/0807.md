# 0807 — Data leakage test: prueba de fuga de datos

## Contenido original

Es una comprobación que intenta detectar si una empresa puede acceder a información de otra.

Por ejemplo, crear registros de dos empresas e intentar consultarlos utilizando identidades cruzadas.

Estas pruebas deben formar parte de los gates de seguridad.
