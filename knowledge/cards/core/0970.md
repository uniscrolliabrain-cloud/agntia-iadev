# 0970 — Test pyramid: pirámide de pruebas

## Contenido original

Es un modelo que propone combinar diferentes niveles de testing.

Habitualmente incluye muchas pruebas unitarias, una cantidad menor de integración y pruebas E2E selectivas.

No es una proporción universal: la estrategia debe adaptarse al software.
