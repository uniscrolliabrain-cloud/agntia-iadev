# 0159 — ¿Qué es REST?

## Contenido original

REST es un estilo arquitectónico para diseñar sistemas distribuidos.

Muchas APIs web utilizan principios asociados a REST, como identificar recursos mediante URLs y aprovechar los métodos HTTP.

No toda API HTTP es necesariamente REST, ni todas las APIs tienen que seguir este enfoque.
