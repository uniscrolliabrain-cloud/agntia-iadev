# 0609 — Evidence: evidencia técnica

## Contenido original

Es información verificable que respalda una afirmación.

Puede ser una ruta de archivo, una línea de código, un resultado de prueba, un log o una respuesta controlada de un servicio.

La evidencia debe relacionarse con la versión del código examinada.
