# 0008 — ¿Qué es una carpeta?

## Contenido original

Una carpeta es una forma de organizar archivos y otras carpetas dentro de un sistema de archivos.

Cuando un proyecto crece, necesita una estructura comprensible.

Por ejemplo\:

**mi-primera-app/**

`src/`

`app.ts`

`public/`

`README.md`

Aquí aparece una idea que después será fundamental para trabajar con agentes de programación: **la organización de los archivos también forma parte del diseño del software**\.
