# 0113 — ¿Qué es la indentación?

## Contenido original

Es el espacio que aparece al comienzo de una línea de código.

En Python tiene significado estructural: ayuda a determinar qué instrucciones pertenecen a un bloque.

```python

edad = 20

if edad >= 18:
    print("Mayor de edad")
```

Los espacios antes de `print` indican que esa instrucción pertenece al bloque condicional.
