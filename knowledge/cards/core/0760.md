# 0760 — Deterministic execution: ejecución determinista

## Contenido original

Significa que las decisiones de control siguen reglas explícitas y reproducibles, en lugar de depender únicamente de una respuesta libre del modelo.

No implica que todas las operaciones externas tengan siempre resultados idénticos.

Significa que podemos establecer reglas como\:

«Sin permiso `invoice.send`, no se invoca el proveedor de correo».

**La IA interpreta. El runtime valida. El ejecutor actúa. La evidencia registra.**
