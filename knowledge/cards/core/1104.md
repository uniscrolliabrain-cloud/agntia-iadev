# 1104 — Quality metric: métrica de calidad

## Contenido original

Es una medida que evalúa si el resultado cumple determinados criterios.

Puede incluir exactitud, cumplimiento de instrucciones, formato, utilidad o tasa de tareas completadas.

Una sola métrica raramente representa toda la calidad.
