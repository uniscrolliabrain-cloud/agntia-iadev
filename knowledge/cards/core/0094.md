# 0094 — ¿Qué es un tipo de dato?

## Contenido original

Un tipo de dato describe qué clase de información representa un valor y qué operaciones tienen sentido con él.

Por ejemplo, un número puede utilizarse para calcular un total. Un texto puede utilizarse para mostrar el nombre de un cliente.

Entre los tipos habituales encontramos números, cadenas de texto, valores booleanos, objetos y listas.
