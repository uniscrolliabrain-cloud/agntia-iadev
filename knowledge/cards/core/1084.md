# 1084 — Context window

## Contenido original

Es la cantidad máxima de contexto que un modelo puede procesar en una solicitud, según su configuración y límites.

Una ventana grande no significa que debamos llenarla siempre.

Enviar información innecesaria puede aumentar costes y perjudicar la relevancia.
