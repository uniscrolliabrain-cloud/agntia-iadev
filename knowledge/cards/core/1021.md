# 1021 — Software contract: contrato de software

## Contenido original

Es un acuerdo técnico que define cómo deben comunicarse dos componentes.

Puede especificar datos de entrada, resultados, errores, permisos y versiones.

Por ejemplo, el módulo de facturación debe saber qué información espera el módulo de notificaciones.

**Con agentes\:** antes de paralelizar el desarrollo, podemos encargar a un agente arquitecto que prepare los contratos y a otro que revise su compatibilidad.
