# 0739 — Integration wave: wave de integración

## Contenido original

Es una ola de trabajo dedicada a conectar y verificar componentes desarrollados previamente.

Puede incluir wiring, adaptadores, migraciones y pruebas transversales.

No debería confundirse con una wave de implementación aislada.
