# 0499 — ¿Qué es una matriz de permisos?

## Contenido original

Es una representación que relaciona roles o identidades con acciones autorizadas.

Permite revisar de forma organizada quién puede consultar, crear, modificar o eliminar recursos.

Es útil para diseñar y auditar sistemas de acceso.
