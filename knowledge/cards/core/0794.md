# 0794 — Node-postgres (`pg`\)

## Contenido original

Es una biblioteca de Node.js que permite comunicarse con PostgreSQL.

Ejemplo\:

```ts
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

const result = await pool.query(
  "SELECT id, name FROM customers WHERE id = $1",
  ["cus_123"]
);
```

Los parámetros como `$1` ayudan a evitar la concatenación insegura de datos dentro de SQL.
