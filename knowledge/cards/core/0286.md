# 0286 — ¿Qué es un paquete compartido?

## Contenido original

Es un conjunto de código reutilizable que diferentes aplicaciones o módulos pueden importar.

Puede contener tipos, validaciones, utilidades o componentes visuales.

Los paquetes compartidos reducen duplicaciones, aunque deben diseñarse para evitar dependencias excesivas.
