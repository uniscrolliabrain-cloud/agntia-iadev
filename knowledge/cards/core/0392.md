# 0392 — ¿Qué es una base de conocimiento?

## Contenido original

Es una colección organizada de información que un sistema puede consultar.

Puede contener documentos, manuales, preguntas frecuentes, procedimientos y registros empresariales.

Una base de conocimiento necesita mecanismos para actualizar, buscar y controlar el acceso a sus contenidos.
