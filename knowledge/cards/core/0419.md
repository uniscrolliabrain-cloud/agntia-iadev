# 0419 — ¿Qué es un grafo de conocimiento?

## Contenido original

Es una representación de entidades y relaciones.

Por ejemplo\:

`Empresa → tiene_cliente → Cliente`

`Cliente → tiene_contrato → Contrato`

`Contrato → pertenece_a → Empresa`

Los grafos pueden ayudar a explorar relaciones complejas entre datos.
