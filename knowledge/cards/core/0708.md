# 0708 — GO/NO-GO: decisión de avanzar o detenerse

## Contenido original

Es una decisión formal sobre si una campaña, release o despliegue puede continuar.

`GO` significa que se autoriza el siguiente paso bajo las condiciones definidas.

`NO-GO` significa que no se autoriza.
