# 0743 — Deprecation: desaprobación de una interfaz

## Contenido original

Es la comunicación de que una funcionalidad o contrato sigue disponible, pero está previsto dejar de utilizarlo.

Puede incluir advertencias, alternativas y plazos de retirada.

No significa eliminación inmediata.
