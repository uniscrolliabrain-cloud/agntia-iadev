# 0120 — ¿Por qué una aplicación utiliza varios lenguajes?

## Contenido original

Porque cada lenguaje y ecosistema puede resultar conveniente para determinadas tareas.

En un sistema empresarial podemos encontrar\:

- TypeScript para interfaces, APIs y contratos.
- Python para procesamiento de documentos, automatización o determinadas herramientas de IA.
- SQL para consultar y modificar datos en una base de datos.

La clave no es utilizar muchos lenguajes, sino elegirlos cuando aportan una ventaja clara y controlar la complejidad de conectarlos.
