# 0759 — Capability: capacidad autorizable

## Contenido original

Es una operación concreta que el software sabe realizar.

Por ejemplo\:

`invoice.read`

`invoice.prepare`

`invoice.send`

Separar capacidades permite conceder permisos diferentes para consultar, preparar y enviar facturas.
