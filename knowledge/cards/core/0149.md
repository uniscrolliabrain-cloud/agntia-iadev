# 0149 — ¿Qué es un dashboard?

## Contenido original

Es una pantalla que reúne información relevante para supervisar una actividad o sistema.

Puede mostrar indicadores, tareas, alertas y acciones frecuentes.

Un buen dashboard no intenta mostrar todos los datos disponibles: prioriza lo que resulta útil para tomar decisiones.
