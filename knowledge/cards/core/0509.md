# 0509 — ¿Qué es la revocación de acceso?

## Contenido original

Es el proceso mediante el cual se retiran permisos o credenciales previamente concedidos.

Puede ser necesario cuando un empleado abandona la empresa o se desconecta una integración.

La revocación debe considerar sesiones activas, tokens y accesos derivados.
