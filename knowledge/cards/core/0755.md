# 0755 — Zod para validar datos reales

## Contenido original

Zod comprueba que los datos recibidos cumplen un esquema.

```ts
import { z } from "zod";

const InvoiceSchema = z.object({
  customerId: z.string().min(1),
  amountCents: z.number().int().positive(),
  currency: z.literal("EUR"),
});
```

Si llega un importe negativo, el esquema lo rechaza.

**Regla\:** los tipos de TypeScript ayudan durante el desarrollo; Zod comprueba datos durante la ejecución.
