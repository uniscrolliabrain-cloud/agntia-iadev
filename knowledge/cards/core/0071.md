# 0071 — ¿Qué es una rama?

## Contenido original

Una rama, o *branch*, es una referencia móvil a una línea de desarrollo dentro del historial Git.

Puedes crear una rama para experimentar sin modificar directamente la rama principal.

Esto facilita el trabajo simultáneo y la revisión.
