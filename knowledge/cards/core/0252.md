# 0252 — ¿Qué es Jest?

## Contenido original

Jest es otro framework popular para realizar pruebas en aplicaciones JavaScript.

Ofrece mecanismos para aserciones, simulaciones y ejecución de tests.

La elección entre herramientas depende del proyecto y sus necesidades.
