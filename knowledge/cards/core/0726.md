# 0726 — Backward compatibility: compatibilidad hacia atrás

## Contenido original

Es la capacidad de una nueva versión para seguir funcionando con consumidores que utilizan un contrato anterior, dentro de las garantías definidas.

Por ejemplo, añadir un campo opcional puede ser compatible si los consumidores toleran campos desconocidos.

La compatibilidad depende de las reglas concretas del contrato.
