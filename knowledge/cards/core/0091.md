# 0091 — ¿Qué es un lenguaje de programación?

## Contenido original

Es un lenguaje formal utilizado para expresar instrucciones y estructuras que las herramientas informáticas pueden procesar.

Igual que existen diferentes idiomas humanos, existen diferentes lenguajes de programación.

Pero tienen reglas mucho más estrictas: una coma, una palabra o un símbolo pueden cambiar el significado de una instrucción.

JavaScript, Python, TypeScript, Java y Rust son ejemplos.
