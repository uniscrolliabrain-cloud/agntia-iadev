# 0093 — ¿Qué es una variable?

## Contenido original

Una variable es un nombre asociado a un valor que el programa puede utilizar.

Imagina una caja etiquetada como «precio». Dentro colocamos el número 25.

```javascript

let precio = 25;
console.log(precio);
```

La variable permite referirse a ese valor sin escribirlo directamente en cada operación.
