# 0633 — Diff: diferencia entre versiones

## Contenido original

Un *diff* muestra qué ha cambiado entre dos estados del código.

Normalmente, las líneas añadidas aparecen con `+` y las eliminadas con `-`\.

Por ejemplo\:

```diff
- const total = precio;
+ const total = precio * cantidad;
```

El diff permite revisar el cambio sin tener que releer todo el archivo.
