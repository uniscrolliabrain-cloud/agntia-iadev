# 0358 — ¿Qué es un indicador de éxito operativo?

## Contenido original

Es una medida que permite evaluar si una operación cumple el resultado esperado.

Por ejemplo, el porcentaje de tareas completadas correctamente o la proporción de correos preparados que superan las validaciones.

Debe definirse con criterios verificables, no solamente con declaraciones del modelo.
