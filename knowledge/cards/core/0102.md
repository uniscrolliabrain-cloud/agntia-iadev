# 0102 — ¿Qué es TypeScript?

## Contenido original

TypeScript es un lenguaje que amplía JavaScript con un sistema de tipos estáticos y otras herramientas de desarrollo.

Permite detectar determinadas clases de errores antes de ejecutar el programa.

Su código normalmente se transforma en JavaScript para ejecutarse en los entornos habituales.
