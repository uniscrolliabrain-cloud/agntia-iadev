# 0595 — ¿Qué es un lockfile?

## Contenido original

Es un archivo que registra versiones resueltas de dependencias y, según el gestor, información adicional necesaria para instalarlas.

Ayuda a conseguir instalaciones más consistentes entre entornos.

No garantiza por sí solo que todas las condiciones de ejecución sean idénticas.
