# 0186 — ¿Qué es DNS?

## Contenido original

DNS significa *Domain Name System*\.

Es un sistema distribuido que permite resolver nombres de dominio y consultar información asociada a ellos.

Una de sus funciones habituales es relacionar un dominio con direcciones IP.

**Analogía\:** funciona en parte como una agenda que ayuda a localizar dónde se encuentra un servicio.
