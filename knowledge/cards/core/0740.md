# 0740 — Cross-repo gate: gate entre repositorios

## Contenido original

Es un control que verifica que los cambios de varios proyectos mantienen la compatibilidad esperada.

Puede exigir pruebas de contratos, versiones correctas y evidencias de integración.

**Descubrimiento\:** cuando varios repositorios evolucionan en paralelo, el problema más peligroso puede no estar dentro de ninguno de ellos, sino en la conexión entre ambos.
