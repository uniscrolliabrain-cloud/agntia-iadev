# 0020 — ¿Qué sucede cuando pulsas un botón?

## Contenido original

Imagina que abres una aplicación empresarial y pulsas «Crear tarea».

El viaje de una tarea

1. **Interfaz\:** recoge el título de la tarea y tu pulsación.
2. **Petición\:** envía la información a una API.
3. **Servidor\:** comprueba que tienes permiso.
4. **Base de datos\:** guarda la tarea.
5. **Respuesta\:** confirma si se ha creado.
6. **Interfaz\:** muestra la nueva tarea en pantalla.

Ejemplo de arquitectura habitual. Otras aplicaciones pueden organizar este proceso de manera diferente.

La operación puede tardar una fracción de segundo, pero contiene múltiples decisiones técnicas.

Y aquí aparece una de las ideas más importantes del desarrollo: **para construir un sistema complejo, primero debemos comprender cómo se comunican sus componentes.**
