# 0600 — ¿Qué es un release gate?

## Contenido original

Es una condición formal que debe cumplirse antes de autorizar o completar una publicación.

Puede exigir pruebas satisfactorias, revisión de seguridad, documentación y aprobación humana.

Un gate bien definido permite tomar decisiones de publicación basadas en evidencias.

**Descubrimiento\:** una release profesional no se identifica solamente por su número de versión. También necesita trazabilidad, pruebas, control de riesgos y capacidad de recuperación.
