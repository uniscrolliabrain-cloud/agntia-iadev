# 0279 — ¿Qué es la inversión de dependencias?

## Contenido original

Es un principio de diseño que recomienda que las partes importantes del sistema no dependan directamente de detalles concretos que podrían cambiar.

Por ejemplo, la lógica de facturación puede depender de una interfaz de almacenamiento en lugar de depender exclusivamente de un proveedor específico de base de datos.

Esto facilita sustituir implementaciones y probar el código.
