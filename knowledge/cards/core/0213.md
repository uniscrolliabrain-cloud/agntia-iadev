# 0213 — ¿Qué es una amenaza?

## Contenido original

Es una circunstancia, actor o evento que podría causar daño a un sistema.

Puede tratarse de un atacante, un programa malicioso, una filtración accidental o una interrupción del servicio.

Una amenaza no implica necesariamente que ya se haya producido un incidente.
