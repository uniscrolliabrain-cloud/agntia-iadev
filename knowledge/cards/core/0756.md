# 0756 — Intent: intención del usuario

## Contenido original

Es la operación que el sistema interpreta a partir de una solicitud.

La frase «prepara una factura» puede traducirse a una intención estructurada\:

```json
{
  "intent": "invoice.prepare",
  "customer": "Nebula",
  "amountCents": 45000,
  "currency": "EUR"
}
```

La interpretación de la IA es una propuesta. Todavía no es una operación autorizada.
