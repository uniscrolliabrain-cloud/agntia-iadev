# 0562 — ¿Qué es un bloqueo?

## Contenido original

Es un impedimento que evita continuar una tarea.

Por ejemplo, falta de acceso a una API o dependencia de un contrato todavía no definido.

Registrar bloqueos permite tomar decisiones antes de que provoquen retrasos mayores.
