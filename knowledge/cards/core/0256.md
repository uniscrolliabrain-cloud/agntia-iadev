# 0256 — ¿Qué es un fixture?

## Contenido original

Es un conjunto de datos o condiciones preparados para ejecutar pruebas de manera reproducible.

Por ejemplo, una base de datos de prueba puede contener dos empresas ficticias y varios empleados.

Los fixtures permiten empezar cada prueba desde un estado conocido.
