# 0398 — ¿Qué es una base de datos vectorial?

## Contenido original

Es un sistema que permite almacenar y consultar vectores, normalmente junto con identificadores y metadatos.

Se utiliza para encontrar representaciones cercanas según determinadas medidas matemáticas.

Algunas bases de datos tradicionales también ofrecen capacidades vectoriales.
