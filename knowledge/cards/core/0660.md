# 0660 — Fix closure: cierre del fix

## Contenido original

Es la decisión documentada de considerar una corrección terminada.

Debe basarse en criterios de aceptación y evidencias.

Un fix puede quedar `BLOCKED` si no es posible ejecutar una prueba imprescindible.

**Descubrimiento\:** aplicar un parche, verificarlo y cerrar el fix son tres estados distintos.
