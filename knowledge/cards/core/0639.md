# 0639 — Idempotent patch: parche idempotente

## Contenido original

Es un parche diseñado para que volver a ejecutarlo no produzca cambios adicionales no deseados.

Por ejemplo, si una modificación ya está aplicada, el sistema puede responder `SKIP`\.

Esto es útil cuando un agente necesita reintentar una operación después de una interrupción.
