# 0253 — ¿Qué es Playwright?

## Contenido original

Playwright es una herramienta que permite automatizar navegadores.

Puede abrir páginas, pulsar botones, introducir texto y comprobar resultados.

Es muy útil para pruebas end-to-end y para verificar el comportamiento de una interfaz real.
