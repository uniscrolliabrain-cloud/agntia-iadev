# 0906 — DNS: Domain Name System

## Contenido original

Es el sistema que traduce nombres de dominio a información necesaria para localizar servicios.

Por ejemplo, permite que una persona escriba `app.orbita.example` en lugar de una dirección IP.

Una configuración DNS incorrecta puede impedir que los usuarios accedan a la aplicación.
