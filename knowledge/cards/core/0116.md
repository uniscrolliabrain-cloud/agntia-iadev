# 0116 — ¿Qué es un entorno virtual?

## Contenido original

Es un entorno aislado que permite instalar dependencias de Python para un proyecto sin mezclarlas innecesariamente con las de otros.

Es especialmente útil cuando diferentes proyectos necesitan versiones distintas de una biblioteca.
