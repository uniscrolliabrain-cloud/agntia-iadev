# 0866 — Provider fallback: proveedor alternativo

## Contenido original

Es una estrategia para utilizar otro servicio cuando el principal no está disponible.

No todas las operaciones pueden cambiarse de proveedor sin consecuencias.

Por ejemplo, cambiar de servicio de correo puede requerir revisar identidad del remitente y configuración de dominio.
