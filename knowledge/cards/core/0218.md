# 0218 — ¿Qué es el principio de mínimo privilegio?

## Contenido original

Consiste en conceder a cada usuario, programa o agente únicamente los permisos necesarios para realizar su trabajo.

Si un agente necesita consultar una agenda, no debería recibir automáticamente permiso para borrar todos los documentos empresariales.

Este principio reduce el impacto potencial de errores y compromisos.
