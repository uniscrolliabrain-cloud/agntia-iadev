# 0820 — Supabase Auth

## Contenido original

Es un servicio de autenticación que puede gestionar usuarios, sesiones y métodos de inicio de sesión.

Puede reducir la cantidad de infraestructura de identidad que necesitamos construir.

Pero integrar un proveedor de autenticación no elimina la necesidad de diseñar correctamente la autorización empresarial.

**Descubrimiento\:** tener login no significa tener un sistema de permisos seguro.
