# 0938 — OWASP Top 10

## Contenido original

Es una referencia ampliamente utilizada para comprender categorías importantes de riesgos de seguridad en aplicaciones web.

Incluye problemas relacionados con controles de acceso, configuraciones, componentes y otros ámbitos.

Un agente puede utilizarla como checklist, pero no debe tratarla como una lista exhaustiva de todos los riesgos posibles.
