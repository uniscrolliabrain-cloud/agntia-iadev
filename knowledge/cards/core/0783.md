# 0783 — SQL

## Contenido original

Significa *Structured Query Language*\.

Es el lenguaje que utilizamos para comunicarnos con bases de datos relacionales.

Por ejemplo\:

```sql
SELECT id, name
FROM customers;
```

Esta consulta pide los identificadores y nombres de los clientes.

Un agente puede escribirla, pero debemos comprobar que consulta la tabla y el ámbito de datos correctos.
