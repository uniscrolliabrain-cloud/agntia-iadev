# 0753 — TypeScript como lenguaje de contratos

## Contenido original

TypeScript permite describir las estructuras que el código espera recibir.

```ts
type CreateInvoice = {
  customerId: string;
  amountCents: number;
  currency: "EUR";
};
```

Si otro programador intenta pasar un importe como texto, el comprobador de tipos puede detectar el problema.

Pero TypeScript no valida automáticamente los datos externos cuando el programa está funcionando.
