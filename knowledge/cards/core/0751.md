# 0751 — Runtime de aplicación

## Contenido original

Es el entorno y la infraestructura que permiten ejecutar un programa.

En nuestro método también utilizamos *runtime* para referirnos a la capa que coordina acciones, permisos, estados y herramientas.

Son dos usos relacionados, pero distintos: Node.js es un entorno de ejecución; nuestro runtime empresarial es software construido encima.
