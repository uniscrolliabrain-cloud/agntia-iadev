# 0607 — Gap: brecha o carencia

## Contenido original

Es la diferencia entre el estado actual y el estado esperado.

Por ejemplo, una aplicación puede tener una pantalla de facturas, pero carecer del proceso que las genera.

Eso es un gap funcional.

No todo gap es un bug: puede tratarse de una capacidad todavía no implementada.
