# 0485 — ¿Qué es una aplicación multitenant?

## Contenido original

Es una aplicación diseñada para prestar servicio a varios tenants utilizando infraestructura compartida, total o parcialmente.

El aislamiento puede implementarse mediante diferentes estrategias de bases de datos y arquitectura.

El objetivo es evitar que una organización acceda indebidamente a recursos de otra.
