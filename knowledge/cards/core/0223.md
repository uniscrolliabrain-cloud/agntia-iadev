# 0223 — ¿Qué es la autenticación multifactor?

## Contenido original

Es un mecanismo que exige más de un factor independiente para verificar una identidad.

Por ejemplo, combinar una contraseña con una clave física o un autenticador.

Puede reducir el riesgo de acceso indebido cuando una contraseña queda comprometida.
