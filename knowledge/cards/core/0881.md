# 0881 — OpenTelemetry

## Contenido original

Es un conjunto de estándares, APIs y herramientas para generar, recopilar y exportar telemetría.

Permite instrumentar aplicaciones sin depender exclusivamente del formato propietario de un proveedor.

Se conoce habitualmente como OTel.
