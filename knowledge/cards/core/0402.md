# 0402 — ¿Qué es la similitud coseno?

## Contenido original

Es una medida matemática utilizada para comparar la orientación de dos vectores.

Puede emplearse para estimar similitud entre representaciones.

Un valor alto de similitud no demuestra por sí mismo que un documento sea correcto o apropiado para una pregunta.
