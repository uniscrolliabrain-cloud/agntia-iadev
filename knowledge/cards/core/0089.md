# 0089 — ¿Qué es un rollback?

## Contenido original

Un *rollback* es una operación para volver a un estado anterior cuando una modificación provoca problemas.

Dependiendo del sistema, puede implicar revertir código, restaurar una versión desplegada o recuperar datos.

No todos los cambios son fáciles de revertir, especialmente cuando afectan a bases de datos o servicios externos.
