# 0281 — ¿Qué es un monolito?

## Contenido original

Es una aplicación cuyas funcionalidades principales se desarrollan y despliegan como una unidad.

Un monolito puede estar muy bien organizado internamente mediante módulos.

No significa necesariamente que todo el código esté mezclado.

Para muchos proyectos, comenzar con un monolito modular puede ser una decisión eficiente.
