# 0207 — ¿Qué es un health check?

## Contenido original

Es una comprobación que evalúa si un servicio está funcionando según determinados criterios.

Por ejemplo, una API puede ofrecer un endpoint que indique si el proceso está activo.

Un health check básico no garantiza que todas las funcionalidades de la aplicación funcionen correctamente.
