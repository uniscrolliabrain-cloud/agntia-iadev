# 0288 — ¿Qué es el versionado semántico?

## Contenido original

Es una convención para identificar versiones de software mediante tres números principales\:

`MAJOR.MINOR.PATCH`

Habitualmente\:

- MAJOR indica cambios incompatibles.
- MINOR indica funcionalidades compatibles.
- PATCH indica correcciones compatibles.

Su utilidad depende de que el proyecto respete esas reglas.
