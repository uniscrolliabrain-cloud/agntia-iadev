# 0625 — Call graph: grafo de llamadas

## Contenido original

Es una representación de qué funciones o componentes llaman a otros.

Puede ayudar a seguir el recorrido de una operación.

Por ejemplo, desde el botón «Confirmar reserva» hasta la escritura en la base de datos.
