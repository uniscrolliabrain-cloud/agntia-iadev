# 0168 — ¿Qué es una migración de base de datos?

## Contenido original

Es un cambio controlado en la estructura o contenido de una base de datos.

Por ejemplo, añadir una columna `telefono` a la tabla de clientes.

Las migraciones ayudan a evolucionar el sistema sin modificar manualmente cada instalación.
