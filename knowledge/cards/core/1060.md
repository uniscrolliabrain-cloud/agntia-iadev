# 1060 — Deterministic executor: ejecutor determinista

## Contenido original

Es el componente que realiza operaciones siguiendo contratos, reglas y estados definidos.

Puede ejecutar una SOP autorizada, registrar resultados y gestionar errores.

**Descubrimiento\:** el modelo interpreta y propone; el runtime verifica y ejecuta. Esa separación permite construir sistemas más auditables.
