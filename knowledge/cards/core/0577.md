# 0577 — ¿Qué es un entorno de desarrollo?

## Contenido original

Es el espacio donde los programadores y agentes construyen y prueban funcionalidades.

Puede funcionar en un ordenador local, una máquina virtual o un entorno remoto.

No debería depender de datos sensibles de producción para realizar pruebas normales.
