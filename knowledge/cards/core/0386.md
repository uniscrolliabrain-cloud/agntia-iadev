# 0386 — ¿Qué es un modelo pequeño especializado?

## Contenido original

Es un modelo con menor tamaño o coste relativo, adaptado o elegido para realizar tareas específicas.

Puede ser suficiente para clasificación, extracción estructurada o determinadas operaciones rutinarias.

Utilizar un modelo más grande para todas las tareas no siempre ofrece la mejor relación entre calidad, velocidad y coste.
