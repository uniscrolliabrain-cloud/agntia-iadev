# 0812 — Authentication: autenticación

## Contenido original

Es el proceso de verificar que alguien es quien afirma ser.

Puede realizarse mediante contraseñas, passkeys, códigos temporales u otros mecanismos.

Autenticarse no concede automáticamente acceso a todos los recursos.
