# 1056 — Task planning: planificación de tareas

## Contenido original

Es la creación de una secuencia de pasos para alcanzar un objetivo.

Por ejemplo\:

`Consultar impagos → Preparar mensajes → Solicitar aprobación → Enviar`

El plan debe distinguir entre operaciones de lectura y acciones con efectos externos.
