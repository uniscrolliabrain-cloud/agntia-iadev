# 0158 — ¿Qué es JSON?

## Contenido original

JSON significa *JavaScript Object Notation*\.

Es un formato de texto utilizado para representar datos estructurados.

```json

{
  "cliente": "Ana",
  "empresa": "ACME",
  "activo": true,
  "tareas": 4
}
```

Es habitual utilizar JSON para intercambiar información entre aplicaciones y APIs.
