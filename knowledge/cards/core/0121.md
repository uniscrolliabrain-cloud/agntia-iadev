# 0121 — ¿Qué es HTML?

## Contenido original

HTML significa *HyperText Markup Language*\.

Es un lenguaje de marcado que describe la estructura y el significado del contenido de una página web.

Permite indicar qué elementos son títulos, párrafos, enlaces, imágenes, formularios o listas.

**Analogía\:** si una página web fuera una casa, HTML definiría sus habitaciones, puertas y distribución.
