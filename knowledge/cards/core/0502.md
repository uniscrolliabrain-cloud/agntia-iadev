# 0502 — ¿Qué es una cuenta de servicio?

## Contenido original

Es una identidad utilizada por software para acceder a recursos o realizar operaciones.

Puede tener credenciales y permisos específicos.

Debe protegerse y limitarse a las capacidades necesarias.
