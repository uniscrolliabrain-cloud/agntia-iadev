# 0544 — ¿Qué es un backlog?

## Contenido original

Es una colección organizada de trabajos pendientes.

Puede incluir funcionalidades, errores, mejoras técnicas y tareas de investigación.

El backlog necesita revisión y priorización para seguir siendo útil.
