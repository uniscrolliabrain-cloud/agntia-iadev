# 0612 — Bug: defecto de software

## Contenido original

Es un error que provoca un comportamiento incorrecto respecto a lo esperado.

Puede estar en la lógica, la interfaz, la configuración o la interacción entre componentes.

Un bug debe describirse con suficiente precisión para poder investigarlo.
