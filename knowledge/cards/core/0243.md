# 0243 — ¿Qué es una aserción?

## Contenido original

Es una comprobación que determina si un resultado cumple una condición esperada.

Por ejemplo\:

```typescript

const total = 20 + 30;

if (total !== 50) {
  throw new Error("El cálculo es incorrecto");
}
```

En frameworks de testing se utilizan funciones especializadas para expresar estas comprobaciones.
