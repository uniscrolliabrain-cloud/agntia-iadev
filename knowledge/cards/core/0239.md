# 0239 — ¿Qué es una aprobación humana?

## Contenido original

Es un mecanismo por el cual determinadas operaciones requieren la autorización explícita de una persona.

Puede utilizarse para enviar comunicaciones, realizar pagos, borrar información o modificar permisos.

Una aprobación debe estar vinculada a una acción concreta y a sus parámetros, no a una autorización genérica e indefinida.
