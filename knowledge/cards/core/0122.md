# 0122 — ¿Qué es una etiqueta HTML?

## Contenido original

Una etiqueta es una construcción que identifica un elemento dentro de un documento HTML.

Por ejemplo\:

```html

<h1>Bienvenido a mi aplicación</h1>
<p>Estas son tus tareas de hoy.</p>
<button>Crear tarea</button>
```

`h1` representa un encabezado principal, `p` un párrafo y `button` un botón.
