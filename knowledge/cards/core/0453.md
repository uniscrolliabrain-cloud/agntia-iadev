# 0453 — ¿Qué es un endpoint de integración?

## Contenido original

Es una dirección o punto de acceso específico de una API.

Por ejemplo, una API puede ofrecer un endpoint para consultar eventos y otro para crear reuniones.

Los endpoints suelen aceptar parámetros y devolver respuestas estructuradas.
