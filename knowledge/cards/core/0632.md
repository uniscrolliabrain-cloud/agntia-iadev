# 0632 — Patch: parche de código

## Contenido original

Un *patch* es una representación de una o varias modificaciones que se aplican al código.

Puede describir líneas añadidas, eliminadas o sustituidas.

Un parche puede corregir un bug, añadir una funcionalidad o modificar una configuración.
