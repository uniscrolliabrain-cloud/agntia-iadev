# 0742 — Expand-and-contract migration: migración expandir y contraer

## Contenido original

Es una estrategia para introducir cambios incompatibles de manera gradual.

Primero se amplía el sistema para aceptar formatos antiguos y nuevos.

Después se migran consumidores y datos.

Finalmente se retira el formato antiguo cuando ya no es necesario.
