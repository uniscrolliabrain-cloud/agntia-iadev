# 0516 — ¿Qué es un caso de uso?

## Contenido original

Es una descripción de cómo un usuario o sistema interactúa con una aplicación para conseguir un resultado.

Por ejemplo: «Un propietario invita a un empleado».

Ayuda a traducir necesidades en comportamientos concretos.
