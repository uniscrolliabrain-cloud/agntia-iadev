# 0131 — ¿Qué es React?

## Contenido original

React es una biblioteca de JavaScript utilizada para construir interfaces mediante componentes reutilizables.

En lugar de gestionar manualmente cada elemento de una página, podemos describir cómo debería mostrarse la interfaz en función de los datos.

React ayuda a actualizar la pantalla cuando esos datos cambian.
