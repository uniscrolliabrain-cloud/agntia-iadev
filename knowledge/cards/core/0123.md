# 0123 — ¿Qué es CSS?

## Contenido original

CSS significa *Cascading Style Sheets*\.

Es un lenguaje utilizado para definir la presentación visual de documentos como HTML.

Permite controlar colores, tamaños, espacios, tipografía, bordes y distribución.

Siguiendo nuestra analogía, CSS sería la decoración y el diseño interior de la casa.
