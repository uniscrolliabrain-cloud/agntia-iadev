# 0953 — Cross-Site Scripting: XSS

## Contenido original

Es una clase de vulnerabilidad donde contenido no confiable termina ejecutándose como código en el navegador.

Las defensas incluyen codificación contextual de salida, uso seguro de frameworks y políticas adecuadas.
