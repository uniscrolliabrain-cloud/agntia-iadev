# 0870 — Provider acceptance gate: gate de aceptación de proveedor

## Contenido original

Es un control que verifica que una integración cumple los requisitos antes de habilitarla.

Puede exigir pruebas con mocks, sandbox, proveedor real controlado, seguridad y observabilidad.

**Descubrimiento\:** integrar un proveedor no termina cuando conseguimos una respuesta HTTP satisfactoria. Termina cuando comprendemos su comportamiento, sus riesgos y cómo operarlo de forma fiable.
