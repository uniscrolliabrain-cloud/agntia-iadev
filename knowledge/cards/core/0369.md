# 0369 — ¿Qué es self-attention?

## Contenido original

Es una forma de atención en la que los elementos de una secuencia interactúan con otros elementos de esa misma secuencia.

Por ejemplo, puede ayudar a relacionar un pronombre con una palabra anterior.

El modelo aprende patrones de estas relaciones mediante entrenamiento.
