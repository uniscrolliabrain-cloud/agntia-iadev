# 0847 — Provider lock-in: dependencia de proveedor

## Contenido original

Es la dificultad de sustituir una plataforma porque nuestro software depende demasiado de sus características particulares.

Una buena arquitectura puede reducirla mediante contratos y adaptadores.

Pero no siempre es posible eliminarla completamente.
