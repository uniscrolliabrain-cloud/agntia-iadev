# 0877 — Gauge: indicador de valor actual

## Contenido original

Es una métrica que puede subir o bajar.

Por ejemplo, el número de tareas pendientes en una cola.

Si normalmente hay diez y de repente aparecen diez mil, podríamos tener un problema de procesamiento.
