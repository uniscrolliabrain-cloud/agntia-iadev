# 0961 — Software testing: pruebas de software

## Contenido original

Es el proceso de comprobar el comportamiento de un programa frente a resultados esperados.

Una prueba puede demostrar que una situación concreta funciona o falla.

No demuestra que el software esté libre de todos los bugs.

**Con agentes\:** podemos encargarles generar casos de prueba, ejecutarlos y producir reportes, siempre diferenciando resultados reales de resultados previstos.
