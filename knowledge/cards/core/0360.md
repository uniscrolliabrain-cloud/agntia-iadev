# 0360 — ¿Qué es un centro de control operativo?

## Contenido original

Es una interfaz que reúne información para supervisar procesos, investigar incidentes y tomar decisiones.

En una aplicación empresarial agéntica puede mostrar tareas, ejecuciones, agentes, errores, aprobaciones y actividad reciente.

**Descubrimiento\:** una interfaz de control no debería limitarse a mostrar lo que los agentes dicen estar haciendo; debe reflejar lo que el sistema ha registrado y verificado.
