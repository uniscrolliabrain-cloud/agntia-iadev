# 0666 — Batch: lote de trabajo

## Contenido original

Un *batch* es un conjunto de operaciones o tareas agrupadas para procesarlas juntas.

Por ejemplo, revisar diez endpoints mediante el mismo procedimiento.

No todos los batches requieren una wave independiente.
