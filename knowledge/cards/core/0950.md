# 0950 — Security regression test: prueba de regresión de seguridad

## Contenido original

Es una prueba que comprueba que una vulnerabilidad corregida no vuelve a aparecer.

Por ejemplo, después de arreglar un acceso indebido a facturas, añadimos un test que intenta repetir ese acceso.

**Descubrimiento\:** una herramienta puede detectar un posible problema. El audit debe verificarlo, determinar su alcance y producir evidencias antes de aplicar un fix.
