# 0466 — ¿Qué es la rotación de credenciales?

## Contenido original

Es el proceso de sustituir credenciales existentes por otras nuevas.

Puede realizarse por seguridad, caducidad o políticas operativas.

Un sistema debe gestionar correctamente las transiciones para evitar interrupciones o exposición de secretos.
