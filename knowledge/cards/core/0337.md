# 0337 — ¿Qué es un gauge?

## Contenido original

Es una métrica que representa un valor que puede subir o bajar.

Por ejemplo, el número de tareas actualmente pendientes o la cantidad de memoria utilizada.

Es útil para conocer estados que cambian con el tiempo.
