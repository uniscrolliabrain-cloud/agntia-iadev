# 0199 — ¿Qué es una imagen de contenedor?

## Contenido original

Es un artefacto que contiene las capas y metadatos necesarios para crear contenedores.

Una imagen puede incluir una aplicación, dependencias y configuraciones.

Puedes utilizar la misma imagen para crear diferentes instancias de un servicio.
