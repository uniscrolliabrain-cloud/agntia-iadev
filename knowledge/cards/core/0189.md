# 0189 — ¿Qué es un centro de datos?

## Contenido original

Es una instalación que alberga infraestructura informática, como servidores, sistemas de almacenamiento, redes, alimentación eléctrica y refrigeración.

Los proveedores cloud operan centros de datos para ofrecer sus servicios.

Una aplicación que parece estar «en la nube» termina ejecutándose sobre recursos físicos.
