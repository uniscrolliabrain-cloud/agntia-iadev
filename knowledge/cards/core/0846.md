# 0846 — Provider abstraction: abstracción de proveedor

## Contenido original

Es una interfaz interna que permite utilizar distintos proveedores sin reescribir toda la aplicación.

Por ejemplo\:

```ts
interface EmailProvider {
  send(message: EmailMessage): Promise<SendResult>;
}
```

Podemos crear implementaciones distintas para varios proveedores.
