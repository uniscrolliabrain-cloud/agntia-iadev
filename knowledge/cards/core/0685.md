# 0685 — Wiring: conexión de componentes

## Contenido original

Es el trabajo de enlazar módulos que ya existen para que funcionen conjuntamente.

Por ejemplo, conectar un formulario de facturas con el endpoint que guarda los datos.

Tener frontend y backend implementados no garantiza que estén correctamente conectados.
