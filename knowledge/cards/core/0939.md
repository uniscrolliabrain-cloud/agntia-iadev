# 0939 — Security baseline: línea base de seguridad

## Contenido original

Es el estado de referencia que documentamos antes de modificar un sistema.

Puede contener\:

- Commit y rama.
- Dependencias instaladas.
- Configuraciones relevantes.
- Hallazgos conocidos.
- Resultados de pruebas.
- Riesgos pendientes.

Sin baseline, resulta difícil demostrar que una campaña mejoró realmente la seguridad.
