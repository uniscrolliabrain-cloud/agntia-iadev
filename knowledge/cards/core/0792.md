# 0792 — Connection string: cadena de conexión

## Contenido original

Es una dirección que contiene la información necesaria para conectarse a la base de datos.

Puede incluir servidor, puerto, usuario y base de datos.

Debe tratarse como un secreto si contiene credenciales.

Un agente no debería imprimirla en logs ni incluirla en reportes.
