# 1007 — Merge conflict: conflicto de integración

## Contenido original

Ocurre cuando Git no puede combinar automáticamente determinados cambios.

Por ejemplo, dos agentes modifican de forma incompatible las mismas líneas.

El conflicto debe resolverse comprendiendo la intención de ambos cambios.
