# 0076 — ¿Qué es un pull request?

## Contenido original

Un *pull request*, o PR, es una propuesta de integración de cambios que plataformas como GitHub permiten revisar.

Puede incluir descripción, archivos modificados, comentarios y resultados de pruebas.

Es una herramienta fundamental para trabajar con agentes de programación sin aceptar ciegamente sus modificaciones.
