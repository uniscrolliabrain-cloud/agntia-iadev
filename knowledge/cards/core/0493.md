# 0493 — ¿Qué es ABAC?

## Contenido original

ABAC significa *Attribute-Based Access Control*, o control de acceso basado en atributos.

Las decisiones consideran propiedades del usuario, recurso, acción o contexto.

Por ejemplo, permitir consultar un documento si pertenece a la empresa activa y el usuario tiene una atribución adecuada.
