# 0447 — ¿Qué es fail-closed?

## Contenido original

Es un principio según el cual, cuando no puede comprobarse una condición de seguridad, el sistema rechaza la operación en lugar de permitirla.

Por ejemplo, si falla la consulta de permisos, una acción sensible debe permanecer bloqueada.

Este enfoque reduce el riesgo de accesos no autorizados.
