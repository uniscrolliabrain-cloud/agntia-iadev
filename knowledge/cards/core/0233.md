# 0233 — ¿Qué es XSS?

## Contenido original

XSS significa *Cross-Site Scripting*\.

Es una familia de vulnerabilidades que permite introducir código ejecutable en páginas web que otros usuarios visitan.

Entre las defensas se encuentran el tratamiento correcto de contenido no confiable, la codificación contextual y políticas de seguridad del navegador.
