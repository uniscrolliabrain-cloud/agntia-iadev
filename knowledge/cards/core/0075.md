# 0075 — ¿Qué es un conflicto de merge?

## Contenido original

Ocurre cuando Git no puede combinar determinados cambios automáticamente.

Por ejemplo, dos agentes modifican de manera incompatible la misma parte de un archivo.

Un conflicto no significa que el proyecto esté destruido.

Significa que alguien debe decidir cómo combinar correctamente esos cambios.
