# 0954 — Cross-Site Request Forgery: CSRF

## Contenido original

Es una clase de ataque donde se intenta provocar que el navegador de una persona autenticada realice una acción no deseada.

Las defensas dependen del mecanismo de autenticación y pueden incluir tokens CSRF, cookies adecuadas y validación del origen.
