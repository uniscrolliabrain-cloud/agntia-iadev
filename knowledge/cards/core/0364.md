# 0364 — ¿Qué es un dataset?

## Contenido original

Es un conjunto de datos utilizado para entrenar, evaluar o analizar un sistema.

Puede contener textos, imágenes, ejemplos de instrucciones o registros estructurados.

La calidad, diversidad y procedencia de los datos influyen en el comportamiento del modelo.
