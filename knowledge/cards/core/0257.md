# 0257 — ¿Qué es la cobertura de código?

## Contenido original

Es una medida que indica qué partes del código han sido ejecutadas durante las pruebas.

Puede medirse mediante líneas, ramas, funciones u otros criterios.

Una cobertura del 90 % no significa que el software sea un 90 % correcto.

La calidad de las comprobaciones importa tanto como la cantidad de código ejecutado.
