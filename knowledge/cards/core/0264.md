# 0264 — ¿Qué es una prueba de aislamiento multitenant?

## Contenido original

Es una prueba que comprueba que los datos y operaciones de un tenant no pueden ser utilizados indebidamente por otro.

Por ejemplo, crear una tarea en ACME e intentar acceder a ella utilizando una identidad perteneciente a SOL.

Este tipo de pruebas es fundamental para aplicaciones empresariales compartidas.
