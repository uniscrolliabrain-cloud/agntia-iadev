# 0821 — OAuth 2.0

## Contenido original

Es un marco de autorización que permite a una aplicación obtener acceso limitado a recursos de otra plataforma.

Por ejemplo, un usuario puede autorizar que una aplicación consulte determinados datos de su calendario.

OAuth por sí solo no es un protocolo de autenticación de identidad.
