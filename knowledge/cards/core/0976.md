# 0976 — Mock: simulación de dependencia

## Contenido original

Es una implementación controlada que sustituye temporalmente una dependencia.

Por ejemplo, simular la respuesta de un proveedor de correo.

Permite probar nuestro código sin enviar mensajes reales.

Pero un test con mocks no demuestra que el proveedor externo funcione.
