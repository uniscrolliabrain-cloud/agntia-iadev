# 0208 — ¿Qué es un log?

## Contenido original

Es un registro de eventos producidos durante la ejecución de un sistema.

Puede indicar que una solicitud llegó, que una operación terminó o que ocurrió un error.

Los logs ayudan a investigar problemas, aunque deben evitar exponer contraseñas y datos sensibles.
