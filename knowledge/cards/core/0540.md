# 0540 — ¿Qué es la experiencia de usuario agéntica?

## Contenido original

En el contexto de este libro, es una experiencia donde agentes o capacidades de IA ayudan a realizar tareas dentro de una interfaz.

Puede combinar conversación, acciones estructuradas, supervisión humana y resultados verificables.

La interfaz debe distinguir claramente entre propuestas, operaciones en curso y acciones completadas.

**Descubrimiento\:** una interfaz con IA no debería limitarse a mostrar un chat. Puede combinar conversación, herramientas visuales y procesos empresariales, siempre que el usuario comprenda qué está ocurriendo.
