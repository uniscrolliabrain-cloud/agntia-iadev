# 0575 — ¿Qué es un build?

## Contenido original

Es el proceso de transformar código fuente y otros recursos en una versión preparada para ejecutarse o distribuirse.

Puede incluir compilación, empaquetado, optimización y generación de archivos.

Por ejemplo, una aplicación web desarrollada con React puede generar archivos optimizados para el navegador.
