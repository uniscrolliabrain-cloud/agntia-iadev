# 0139 — ¿Qué es una SPA?

## Contenido original

SPA significa *Single Page Application*\.

Es una aplicación web que puede actualizar su contenido dinámicamente sin cargar un documento HTML completamente nuevo en cada navegación.

Este enfoque puede ofrecer experiencias fluidas, aunque requiere gestionar adecuadamente navegación, carga de datos y rendimiento.
