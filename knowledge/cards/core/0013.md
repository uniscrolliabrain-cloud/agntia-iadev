# 0013 — ¿Qué es un navegador?

## Contenido original

Un navegador es una aplicación que permite acceder a contenidos y aplicaciones web.

Chrome, Firefox, Edge y Safari son ejemplos.

El navegador interpreta tecnologías como HTML, CSS y JavaScript para mostrar interfaces interactivas.

Cuando construyes una aplicación web, gran parte de lo que ve el usuario se ejecuta dentro de su navegador.
