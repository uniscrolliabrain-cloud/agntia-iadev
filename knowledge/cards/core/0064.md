# 0064 — ¿Qué es un commit?

## Contenido original

Un commit es un registro identificable de un estado del proyecto dentro del historial de Git.

Suele incluir un mensaje que explica el cambio y referencias a sus antecedentes.

Por ejemplo\:

**Commit de ejemplo**

Añadir formulario de creación de tareas

Archivos modificados

`src/TaskForm.tsx`

`src/App.tsx`

`tests/task-form.test.ts`

Un commit no garantiza que el código sea correcto. Registra un estado que después podemos examinar o recuperar.
