# 0315 — ¿Qué es una tarea atómica?

## Contenido original

Es una tarea suficientemente delimitada para ejecutarse y verificarse de manera independiente.

Por ejemplo, «añadir validación de correo al endpoint de invitaciones» es más concreta que «mejorar todo el sistema de usuarios».

Las tareas pequeñas facilitan revisar resultados y detectar errores.
