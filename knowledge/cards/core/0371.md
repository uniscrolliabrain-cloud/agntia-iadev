# 0371 — ¿Qué es la inferencia?

## Contenido original

Es el proceso de utilizar un modelo entrenado para producir un resultado a partir de una entrada.

Cuando escribes una pregunta y el modelo genera una respuesta, está realizando inferencia.

No es lo mismo que entrenar el modelo desde cero.
