# 0487 — ¿Qué es una invitación de usuario?

## Contenido original

Es un mecanismo para incorporar una persona a una organización.

Normalmente incluye una invitación identificable, un destinatario, una caducidad y un proceso de aceptación.

El sistema debe comprobar que quien acepta la invitación está autorizado a hacerlo.
