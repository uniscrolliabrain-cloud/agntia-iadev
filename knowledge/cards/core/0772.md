# 0772 — Event bus: bus de eventos

## Contenido original

Es una infraestructura que distribuye eventos entre componentes.

Por ejemplo, cuando se aprueba una factura, un servicio puede recibir un evento y preparar una notificación.

No es necesario que todos los componentes se llamen directamente entre sí.
