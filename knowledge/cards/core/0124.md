# 0124 — ¿Qué es una clase CSS?

## Contenido original

Una clase permite aplicar estilos a determinados elementos.

```html

<button class="principal">
  Guardar
</button>
```

```css

.principal {
  background: royalblue;
  color: white;
  padding: 12px;
}
```

El navegador utiliza estas reglas para representar el botón con la apariencia indicada.
