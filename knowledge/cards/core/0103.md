# 0103 — ¿Qué es el tipado estático?

## Contenido original

Es un enfoque en el que se comprueban determinadas propiedades de los tipos durante el análisis o compilación del programa.

Por ejemplo\:

```typescript

let edad: number = 30;

// Esto provocaría un error de tipos:
// edad = "treinta";
```

TypeScript ayuda a detectar que estamos intentando asignar texto a una variable declarada como numérica.

Esto no elimina todos los errores, pero puede evitar muchos problemas comunes.
