# 0635 — Atomic fix: corrección atómica

## Contenido original

Es una corrección delimitada que aborda un propósito coherente.

Por ejemplo, un fix para validar el identificador de una reserva.

La atomicidad facilita revisar, probar y revertir cambios.

No significa necesariamente que solo pueda modificarse una línea o un archivo.
