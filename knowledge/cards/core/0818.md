# 0818 — Password hashing: hash de contraseñas

## Contenido original

Es el procedimiento para transformar contraseñas mediante algoritmos especializados de almacenamiento, como Argon2id.

No debemos guardar contraseñas en texto plano.

Tampoco basta con aplicar un hash genérico rápido como SHA-256 sin un diseño adecuado.
