# 0590 — ¿Qué es un feature flag?

## Contenido original

Es un mecanismo que permite activar o desactivar funcionalidades mediante configuración.

Puede utilizarse para pruebas, despliegues graduales o control operativo.

Un feature flag no sustituye a los permisos de seguridad del backend.

**Descubrimiento\:** publicar una nueva versión no tiene por qué significar activarla inmediatamente para todos los usuarios.
