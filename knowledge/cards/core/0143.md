# 0143 — ¿Qué es un wireframe?

## Contenido original

Es una representación esquemática de una pantalla.

Permite decidir dónde se colocarán los elementos principales antes de desarrollar el diseño visual definitivo.

Se parece a un plano arquitectónico: muestra la distribución sin necesitar todos los detalles decorativos.
