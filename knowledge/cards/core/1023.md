# 1023 — Runtime validation: validación en ejecución

## Contenido original

Es la comprobación de datos mientras el programa funciona.

Zod permite validar objetos recibidos de APIs, colas o proveedores externos.

```ts
import { z } from "zod";

const InvoiceSchema = z.object({
  id: z.string().uuid(),
  companyId: z.string().uuid(),
  amountCents: z.number().int().nonnegative(),
  currency: z.literal("EUR"),
});

type Invoice = z.infer<typeof InvoiceSchema>;
```

Con `InvoiceSchema.parse(data)` podemos comprobar que los datos recibidos respetan el contrato.
