# 0084 — ¿Qué es GitHub Actions?

## Contenido original

Es un servicio de automatización integrado en GitHub.

Permite ejecutar procesos cuando ocurren eventos, como publicar un commit o abrir un pull request.

Por ejemplo, puede instalar dependencias y ejecutar tests automáticamente.
