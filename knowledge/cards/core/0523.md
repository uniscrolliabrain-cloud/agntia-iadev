# 0523 — ¿Qué es un prototipo?

## Contenido original

Es una representación que permite explorar el comportamiento de un producto antes de construirlo completamente.

Puede simular navegación, formularios o interacciones.

Sirve para validar decisiones de diseño y detectar problemas tempranos.
