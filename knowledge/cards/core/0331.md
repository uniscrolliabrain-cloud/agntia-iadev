# 0331 — ¿Qué es la observabilidad?

## Contenido original

Es la capacidad de comprender el estado y comportamiento interno de un sistema utilizando las señales que genera.

En ingeniería de software, estas señales suelen incluir registros, métricas y trazas.

La observabilidad permite investigar problemas que no se habían previsto exactamente cuando se diseñó la aplicación.
