# 0050 — ¿Qué es GitHub?

## Contenido original

GitHub es una plataforma que ofrece alojamiento de repositorios Git y herramientas de colaboración, revisión, automatización y gestión de proyectos.

Git y GitHub no son lo mismo.

Git es el sistema de control de versiones. GitHub es una plataforma que utiliza Git y añade servicios alrededor.

**Del mensaje a una modificación real**
