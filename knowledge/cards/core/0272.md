# 0272 — ¿Qué es un componente de software?

## Contenido original

Es una unidad identificable que cumple una responsabilidad dentro de un sistema.

Puede ser un módulo, una biblioteca, un servicio o una parte de la aplicación.

Por ejemplo, una aplicación empresarial puede tener componentes para usuarios, facturación y documentos.
