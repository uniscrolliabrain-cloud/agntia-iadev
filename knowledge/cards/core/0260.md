# 0260 — ¿Qué es la pirámide de testing?

## Contenido original

Es un modelo conceptual que recomienda distribuir las pruebas entre diferentes niveles.

Normalmente propone muchas pruebas unitarias, una cantidad intermedia de integración y menos pruebas end-to-end.

No es una regla matemática universal. Cada proyecto necesita una estrategia adecuada a sus riesgos.
