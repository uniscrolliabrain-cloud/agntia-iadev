# 0770 — Recovery: recuperación

## Contenido original

Es el proceso para restaurar una operación o sistema después de un fallo.

Puede incluir reintentos, compensaciones, restauración de estados o intervención humana.

**Un sistema fiable no es aquel que nunca falla, sino aquel que detecta los fallos y tiene procedimientos controlados para tratarlos.**
