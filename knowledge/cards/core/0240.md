# 0240 — ¿Qué es un sistema fail-closed?

## Contenido original

Es un sistema diseñado para denegar una operación cuando no puede comprobar que se cumplen las condiciones necesarias de seguridad.

Por ejemplo, si el servicio de permisos no responde, el sistema puede rechazar una transferencia en lugar de permitirla.

**Descubrimiento\:** cuando una operación puede causar daño, no saber si está autorizada no debería interpretarse como permiso.
