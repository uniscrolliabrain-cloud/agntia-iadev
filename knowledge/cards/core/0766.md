# 0766 — Exponential backoff: espera exponencial

## Contenido original

Es una estrategia para aumentar progresivamente el tiempo entre reintentos.

Por ejemplo\:

`1 s → 2 s → 4 s → 8 s`

Puede combinarse con variaciones aleatorias para evitar que muchos workers reintenten simultáneamente.
