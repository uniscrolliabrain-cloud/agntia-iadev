# 0341 — ¿Qué es OpenTelemetry?

## Contenido original

OpenTelemetry es un proyecto de código abierto que proporciona estándares, APIs y herramientas para generar, recopilar y exportar telemetría.

Ayuda a instrumentar aplicaciones sin depender completamente del formato propietario de una única plataforma.
