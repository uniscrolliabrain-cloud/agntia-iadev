# 0227 — ¿Qué es una clave de API?

## Contenido original

Es una credencial utilizada para identificar o autorizar solicitudes a determinados servicios.

Por ejemplo, una aplicación puede necesitar una clave para utilizar un proveedor de modelos de IA.

Las claves de API no deben exponerse en código frontend cuando conceden acceso a operaciones privadas.
