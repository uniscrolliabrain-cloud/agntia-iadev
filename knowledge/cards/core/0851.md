# 0851 — Gmail API

## Contenido original

Es una API que permite integrar determinadas funcionalidades de Gmail en una aplicación.

Puede utilizarse para consultar mensajes, gestionar borradores o enviar correos, según los permisos concedidos.

Un agente de programación puede construir el adaptador, pero el acceso a datos reales requiere autorización válida.
