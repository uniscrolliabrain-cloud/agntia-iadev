# 0200 — ¿Qué es una variable de entorno?

## Contenido original

Es un valor de configuración que un proceso recibe desde su entorno de ejecución.

Por ejemplo\:

```bash

PORT=3000
NODE_ENV=production
DATABASE_URL=...
```

Las variables de entorno permiten configurar aplicaciones sin introducir todos los valores directamente en el código.

Los valores sensibles deben protegerse mediante mecanismos adecuados de gestión de secretos.
