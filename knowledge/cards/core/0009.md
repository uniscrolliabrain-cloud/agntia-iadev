# 0009 — ¿Qué es el código fuente?

## Contenido original

Es el texto escrito en un lenguaje de programación que describe cómo debe funcionar un programa.

Por ejemplo\:

```javascript

const nombre = "Ana";
console.log("Hola, " + nombre);
```

Este código guarda un nombre y construye un saludo.

No necesitas comprender todavía la sintaxis. Basta con reconocer que las instrucciones están expresadas en un lenguaje formal que las herramientas informáticas pueden interpretar o transformar para ejecutarlas.
