# 0729 — Anti-corruption layer: capa de protección del dominio

## Contenido original

Es una capa que impide que el modelo interno de un sistema externo contamine directamente el diseño de nuestra aplicación.

Puede utilizar adaptadores, validadores y traductores.

Es especialmente útil al integrar proveedores o software con modelos de datos distintos.
