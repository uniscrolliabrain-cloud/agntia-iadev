# 0837 — Fail closed: fallo seguro por denegación

## Contenido original

Significa que, si falla un componente crítico de autorización, el sistema no concede acceso por defecto.

Por ejemplo, si no podemos verificar la pertenencia de un usuario a una empresa, la consulta se rechaza.
