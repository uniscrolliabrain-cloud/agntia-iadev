# 1034 — Event envelope: envoltorio de evento

## Contenido original

Es la estructura común que acompaña al contenido específico de cada evento.

Por ejemplo\:

```ts
type EventEnvelope<T> = {
  id: string;
  schemaVersion: number;
  type: string;
  occurredAt: string;
  correlationId: string;
  causationId?: string;
  payload: T;
};
```

Ayuda a identificar, correlacionar y procesar mensajes.
