# 0484 — ¿Qué es un tenant?

## Contenido original

Es una unidad lógica de aislamiento dentro de una aplicación compartida.

Normalmente representa una organización o cliente empresarial.

Un tenant puede disponer de usuarios, datos, configuraciones y permisos propios.
