# 0874 — Log levels: niveles de registro

## Contenido original

Son categorías que indican la importancia de un mensaje.

| Nivel | Significado |
|--------|--------|
| DEBUG | Información detallada para investigar |
| INFO | Funcionamiento normal |
| WARN | Situación inesperada o potencialmente problemática |
| ERROR | Operación fallida |
| FATAL | Fallo crítico, si el sistema utiliza este nivel |

No existe una clasificación universal idéntica en todas las herramientas.
