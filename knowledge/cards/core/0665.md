# 0665 — Wave: ola de ejecución

## Contenido original

Una *wave* agrupa trabajos que pueden desarrollarse en un periodo o ciclo coordinado.

Puede incluir tareas paralelas y tareas secuenciales.

**Diferencia importante\:** la fase describe el tipo de trabajo; la wave organiza cuándo y con qué dependencias se ejecuta.
