# 0580 — ¿Qué es una release?

## Contenido original

Es una versión identificable del software preparada o publicada para determinados usuarios.

Puede incluir funcionalidades, correcciones, documentación y notas de cambios.

Una release debería permitir responder: «¿Qué versión está funcionando y qué contiene?».

**Descubrimiento\:** escribir código, construir una aplicación y publicarla son actividades diferentes. Cada una necesita verificaciones propias.
