# 0274 — ¿Qué es la separación de responsabilidades?

## Contenido original

Es el principio de organizar el software para que diferentes partes se encarguen de problemas diferentes.

Por ejemplo\:

- La interfaz muestra información.
- El backend procesa operaciones.
- La base de datos conserva registros.
- El sistema de autorización decide qué acciones están permitidas.

Esta separación facilita comprender, probar y modificar el sistema.
