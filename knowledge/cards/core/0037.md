# 0037 — ¿Qué es el contexto?

## Contenido original

El contexto es la información que el modelo recibe y puede utilizar durante una interacción.

Puede incluir instrucciones, mensajes anteriores, documentos, fragmentos de código y resultados de herramientas.

Cuando trabajas en un proyecto grande, proporcionar el contexto adecuado es esencial.

Un modelo que no conoce la arquitectura de tu aplicación puede proponer cambios incompatibles con ella.
