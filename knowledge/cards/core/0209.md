# 0209 — ¿Qué es la monitorización?

## Contenido original

Es la observación sistemática del estado y comportamiento de un sistema mediante indicadores, eventos y señales.

Permite detectar problemas de disponibilidad, rendimiento y funcionamiento.

Una aplicación profesional necesita mecanismos para saber qué ocurre cuando no estamos mirando directamente la pantalla.
