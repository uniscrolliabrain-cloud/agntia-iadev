# 0295 — ¿Qué es un patrón de diseño?

## Contenido original

Es una solución reutilizable para un problema recurrente de diseño de software.

No es necesariamente una biblioteca ni una pieza de código que debamos copiar literalmente.

Los patrones ayudan a comunicar decisiones y aprovechar experiencias conocidas.
