# 0012 — ¿Qué es la web?

## Contenido original

La World Wide Web es uno de los servicios que funcionan sobre Internet.

Está formada por páginas, aplicaciones y recursos accesibles mediante tecnologías como HTTP y los navegadores.

Internet es la infraestructura de comunicación. La web es una de las formas de utilizarla.

**Ejemplo\:** puedes utilizar Internet para consultar una página web, realizar una videollamada o enviar correo electrónico. Son servicios diferentes que comparten infraestructura.
