# 0638 — Patch guard: protección del parche

## Contenido original

Es una condición que debe cumplirse antes de aplicar una modificación.

Por ejemplo, comprobar que el archivo existe, que el anchor aparece exactamente una vez y que el fix no se aplicó previamente.

Si la comprobación falla, el sistema debe detener o rechazar esa modificación.
