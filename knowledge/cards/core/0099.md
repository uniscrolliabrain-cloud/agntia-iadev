# 0099 — ¿Qué es una expresión?

## Contenido original

Una expresión es una combinación de valores, operadores y otras construcciones que produce un resultado.

Por ejemplo\:

```javascript

const precio = 100;
const iva = precio * 0.21;
const total = precio + iva;
```

Aquí utilizamos expresiones aritméticas para calcular un impuesto y el precio final.
