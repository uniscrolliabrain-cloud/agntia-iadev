# 0234 — ¿Qué es CSRF?

## Contenido original

CSRF significa *Cross-Site Request Forgery*\.

Es un ataque que intenta provocar que el navegador de una persona autenticada realice una operación no deseada.

Las defensas pueden incluir tokens CSRF, políticas adecuadas de cookies y comprobaciones del origen de las solicitudes.
