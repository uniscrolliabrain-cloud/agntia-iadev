# 0565 — ¿Qué es una revisión técnica?

## Contenido original

Es una evaluación de código, arquitectura o documentación realizada para detectar errores y oportunidades de mejora.

Puede efectuarla otra persona o un agente de IA.

La revisión debe apoyarse en evidencia y no limitarse a opiniones generales.
