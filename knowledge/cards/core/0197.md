# 0197 — ¿Qué es un contenedor?

## Contenido original

Es una forma de empaquetar una aplicación junto con los componentes de entorno necesarios para ejecutarla de manera relativamente aislada.

Los contenedores comparten el kernel del sistema operativo anfitrión, a diferencia de muchas máquinas virtuales.

Ayudan a conseguir entornos más reproducibles.
