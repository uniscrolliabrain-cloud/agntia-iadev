# 0588 — ¿Qué es un despliegue blue-green?

## Contenido original

Es una estrategia que mantiene dos entornos o conjuntos de instancias: uno activo y otro preparado con una nueva versión.

El tráfico puede cambiarse del entorno anterior al nuevo cuando se cumplen las condiciones previstas.

Facilita determinados tipos de recuperación, aunque también exige gestionar datos y compatibilidades.
