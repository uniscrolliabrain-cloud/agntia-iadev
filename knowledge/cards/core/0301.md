# 0301 — ¿Qué es un coding agent?

## Contenido original

Es un sistema de inteligencia artificial que puede utilizar herramientas para realizar tareas de desarrollo.

Dependiendo de sus permisos y entorno, puede leer archivos, modificar código, ejecutar comandos, lanzar pruebas y preparar cambios para revisión.

A diferencia de un chatbot que solamente explica código, un coding agent puede interactuar con un proyecto real.
