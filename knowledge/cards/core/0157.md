# 0157 — ¿Qué es un endpoint?

## Contenido original

Es una dirección o punto de acceso mediante el que un servicio expone una operación o recurso.

Por ejemplo\:

`GET /api/clientes`

Podría utilizarse para consultar clientes.

`POST /api/tareas`

Podría utilizarse para crear una tarea.

Los endpoints forman parte de la interfaz que un backend ofrece a otros programas.
