# 0176 — ¿Qué es multitenancy?

## Contenido original

Es una arquitectura que permite atender a múltiples tenants mediante infraestructura o componentes compartidos, manteniendo los aislamientos necesarios.

Puede adoptar diferentes diseños, desde bases de datos separadas hasta tablas compartidas con identificadores de tenant.
