# 0615 — Impact analysis: análisis de impacto

## Contenido original

Es la evaluación de las consecuencias de un defecto o cambio.

Considera usuarios afectados, datos, seguridad, funcionalidades y dependencias.

Un problema pequeño en apariencia puede tener consecuencias importantes si afecta a una operación central.
