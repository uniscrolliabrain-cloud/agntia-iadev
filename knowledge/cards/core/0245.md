# 0245 — ¿Qué es una prueba de integración?

## Contenido original

Es una prueba que comprueba cómo colaboran varios componentes.

Por ejemplo, una ruta HTTP, un servicio de tareas y una base de datos.

Puede descubrir problemas que no aparecen cuando comprobamos cada componente por separado.
