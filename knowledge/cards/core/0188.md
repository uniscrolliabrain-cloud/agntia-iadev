# 0188 — ¿Qué es cloud computing?

## Contenido original

Es un modelo de utilización de recursos informáticos proporcionados a través de redes, normalmente bajo demanda.

Puede incluir servidores, bases de datos, almacenamiento, funciones y servicios especializados.

La nube no significa que el software exista en un lugar misterioso.

Significa que utiliza infraestructura física administrada y ofrecida mediante servicios.
