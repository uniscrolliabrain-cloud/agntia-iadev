# 0077 — ¿Qué es un code review?

## Contenido original

Es la revisión técnica de los cambios propuestos.

El revisor puede examinar lógica, seguridad, arquitectura, pruebas y legibilidad.

La revisión puede detectar problemas que los tests no han cubierto.
