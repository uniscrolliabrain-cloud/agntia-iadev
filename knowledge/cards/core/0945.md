# 0945 — Dependabot

## Contenido original

Es una herramienta de GitHub que ayuda a identificar y proponer actualizaciones de dependencias.

Puede abrir pull requests para actualizar paquetes.

Actualizar una dependencia no garantiza automáticamente que el software siga funcionando: debemos ejecutar pruebas.
