# 0442 — ¿Qué es un runtime?

## Contenido original

Es el entorno y conjunto de mecanismos que permiten ejecutar un programa o proceso.

En sistemas agénticos, también podemos llamar runtime a la infraestructura que coordina herramientas, estados, permisos y ejecuciones.

El significado exacto depende del contexto.
