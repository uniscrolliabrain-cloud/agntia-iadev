# 0187 — ¿Qué es hosting?

## Contenido original

El hosting, o alojamiento, es el servicio de proporcionar recursos para almacenar y servir aplicaciones, páginas web o datos.

Puede incluir máquinas, almacenamiento, conectividad y herramientas de administración.

Existen distintas modalidades, desde alojamiento web compartido hasta plataformas de aplicaciones y servidores dedicados.
