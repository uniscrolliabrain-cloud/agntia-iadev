# 0815 — JWT: JSON Web Token

## Contenido original

Es un formato de token que contiene afirmaciones o *claims*\.

Puede incluir el identificador del usuario, el emisor y la fecha de expiración.

Un JWT firmado permite verificar su integridad y procedencia, pero su contenido no está necesariamente cifrado.
