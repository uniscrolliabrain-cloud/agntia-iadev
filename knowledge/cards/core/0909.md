# 0909 — Latency: latencia

## Contenido original

Es el tiempo que tarda una operación o comunicación.

Por ejemplo, una API situada lejos de su base de datos puede añadir retrasos a cada consulta.

**Con agentes\:** podemos solicitar mediciones de latencia entre servicios y un diagnostic report antes de decidir si conviene moverlos.
