# 0105 — ¿Qué es una función en JavaScript?

## Contenido original

Es un bloque reutilizable de código que puede recibir argumentos y devolver resultados.

```javascript

function saludar(nombre) {
  return "Hola, " + nombre;
}

console.log(saludar("Ana"));
```

La función `saludar` recibe un nombre y construye un mensaje.
