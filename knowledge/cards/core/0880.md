# 0880 — Span: segmento de una traza

## Contenido original

Es una operación individual dentro de una traza.

Por ejemplo, una consulta a PostgreSQL puede ser un span.

Una traza suele contener varios spans relacionados.

**Descubrimiento\:** los logs cuentan qué ocurrió, las métricas muestran cuánto ocurre y las trazas ayudan a explicar dónde y cómo ocurrió.
