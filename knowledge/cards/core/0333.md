# 0333 — ¿Qué es un log estructurado?

## Contenido original

Es un registro de eventos organizado mediante campos identificables.

En lugar de escribir solamente\:

`Ha fallado algo`

podemos registrar\:

```json

{
  "level": "error",
  "service": "gmail-adapter",
  "operation": "list_messages",
  "error_code": "UPSTREAM_TIMEOUT",
  "duration_ms": 5000
}
```

Los campos permiten filtrar, buscar y agrupar eventos.
