# 0194 — ¿Qué es una build?

## Contenido original

Una *build* es el proceso de preparar el software para ejecutarse o distribuirse.

Puede incluir transformar TypeScript en JavaScript, agrupar archivos, optimizar recursos y generar artefactos.

No todas las aplicaciones necesitan el mismo proceso de build.
