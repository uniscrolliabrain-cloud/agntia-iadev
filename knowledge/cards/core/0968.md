# 0968 — Smoke test: prueba de humo

## Contenido original

Es un conjunto reducido de comprobaciones que determina si las funciones esenciales están disponibles.

Por ejemplo, verificar que la aplicación arranca, que el login responde y que la API puede consultar la base de datos.

No sustituye una suite completa.
