# 0810 — Data integrity gate: gate de integridad de datos

## Contenido original

Es un control que verifica que una modificación no rompe las garantías definidas para la información.

Puede incluir restricciones, migraciones, transacciones, permisos y pruebas de aislamiento.

**Descubrimiento\:** una base de datos profesional no consiste únicamente en guardar registros. Consiste en conservarlos correctamente, protegerlos y permitir que evolucionen sin perder integridad.
