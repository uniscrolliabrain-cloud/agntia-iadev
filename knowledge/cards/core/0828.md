# 0828 — RBAC: control de acceso basado en roles

## Contenido original

Es un modelo donde los permisos se asignan a roles.

Por ejemplo\:

`Owner → Administrar usuarios`

`Manager → Gestionar proyectos`

`Employee → Consultar tareas asignadas`

Los roles simplifican la administración, aunque no siempre bastan para representar todas las condiciones empresariales.
