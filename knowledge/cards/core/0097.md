# 0097 — ¿Qué es un objeto?

## Contenido original

Un objeto permite agrupar información relacionada.

Por ejemplo, un cliente puede tener nombre, correo electrónico y teléfono.

```javascript

const cliente = {
  nombre: "Ana",
  email: "ana@ejemplo.com",
  activo: true
};
```

En lugar de mantener tres valores completamente separados, podemos representarlos como propiedades de una misma entidad.
