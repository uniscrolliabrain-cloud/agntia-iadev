# 0130 — ¿Qué es una media query?

## Contenido original

Es una característica de CSS que permite aplicar estilos dependiendo de condiciones del dispositivo o entorno.

Por ejemplo\:

```css

@media (max-width: 600px) {
  .sidebar {
    display: none;
  }
}
```

Esta regla oculta un elemento con clase `sidebar` cuando el ancho disponible no supera 600 píxeles.
