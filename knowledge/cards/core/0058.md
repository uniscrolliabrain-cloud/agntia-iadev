# 0058 — ¿Qué es una prueba de integración?

## Contenido original

Es una prueba que comprueba cómo colaboran varios componentes.

Por ejemplo, crear una tarea mediante una API y verificar que queda almacenada correctamente.

Es diferente de una prueba unitaria, que normalmente examina una unidad de comportamiento más aislada.
