# 0481 — ¿Qué es una identidad digital?

## Contenido original

Es una representación de una persona, servicio o entidad dentro de un sistema informático.

Puede estar asociada a identificadores, credenciales, atributos y permisos.

La identidad permite distinguir quién está interactuando con la aplicación.
