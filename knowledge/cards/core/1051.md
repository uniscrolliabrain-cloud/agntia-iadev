# 1051 — Cognitive architecture: arquitectura cognitiva

## Contenido original

Es la organización de componentes que permiten a un sistema procesar información, utilizar memoria, razonar y seleccionar acciones.

En software agéntico, no implica necesariamente conciencia ni comprensión humana.

Es una arquitectura funcional para resolver tareas.
