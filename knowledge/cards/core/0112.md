# 0112 — ¿Qué es un intérprete?

## Contenido original

Es un programa que ejecuta instrucciones de un lenguaje mediante un determinado proceso de interpretación.

Python utiliza habitualmente un intérprete que ejecuta código compilado internamente a una representación intermedia.

Para empezar, basta con comprender que necesitas un entorno capaz de ejecutar los programas escritos en Python.
