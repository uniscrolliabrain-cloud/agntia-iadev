# 0518 — ¿Qué es la arquitectura de información?

## Contenido original

Es la organización de contenidos y funcionalidades para que puedan encontrarse y comprenderse.

Incluye categorías, jerarquías, etiquetas y navegación.

Una arquitectura de información bien diseñada reduce el esfuerzo necesario para utilizar una aplicación.
