# 0892 — Service Level Objective: SLO

## Contenido original

Es un objetivo definido para un indicador.

Por ejemplo, que el 99,9 % de determinadas peticiones se complete satisfactoriamente durante un periodo.

Un SLO debe tener una definición precisa de qué cuenta como éxito.
