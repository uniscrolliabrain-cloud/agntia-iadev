# 0477 — ¿Qué es un mock de proveedor?

## Contenido original

Es una implementación simulada de un servicio externo utilizada durante pruebas.

Puede devolver respuestas controladas sin realizar llamadas reales.

Es útil para probar errores, límites y escenarios difíciles de reproducir.
