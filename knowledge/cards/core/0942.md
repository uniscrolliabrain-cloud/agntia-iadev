# 0942 — CodeQL

## Contenido original

Es una herramienta de análisis de código que permite formular consultas sobre su estructura y comportamiento.

Puede integrarse en GitHub para detectar determinadas clases de problemas.

Un agente puede interpretar los hallazgos, localizar el código afectado y preparar propuestas de corrección.
