# 1108 — Cost-quality frontier

## Contenido original

Es la relación entre coste y calidad de distintas alternativas.

Una opción puede ser más barata pero menos fiable; otra puede ser más cara sin mejorar significativamente el resultado.

Buscamos alternativas que ofrezcan el mejor equilibrio para nuestras necesidades.
