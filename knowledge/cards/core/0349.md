# 0349 — ¿Qué es un dashboard de observabilidad?

## Contenido original

Es una interfaz que presenta indicadores y visualizaciones sobre el funcionamiento de un sistema.

Puede mostrar solicitudes, errores, latencias, consumo de recursos y actividad empresarial.

Un buen dashboard debe ayudar a responder preguntas concretas, no limitarse a mostrar gráficos decorativos.
