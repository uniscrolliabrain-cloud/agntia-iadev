# 0140 — ¿Qué es Vite?

## Contenido original

Vite es una herramienta utilizada para desarrollar y construir aplicaciones web modernas.

Proporciona un servidor de desarrollo rápido y mecanismos para preparar los archivos que se distribuirán.

En AgntiaPro se ha utilizado Vite dentro del entorno frontend.
