# 0501 — ¿Qué es una identidad de agente?

## Contenido original

Es una identidad técnica asignada a un agente de software para distinguir sus operaciones.

Permite registrar qué componente ha solicitado o realizado una acción.

Una identidad de agente no implica que el sistema sea una persona jurídica ni que posea autonomía legal.
