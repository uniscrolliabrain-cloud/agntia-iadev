# 0409 — ¿Qué es la procedencia de una fuente?

## Contenido original

Es la información que permite conocer de dónde procede un dato.

Puede incluir documento, identificador, fecha, versión y ubicación del fragmento.

La procedencia facilita comprobar las respuestas y detectar documentos desactualizados.
