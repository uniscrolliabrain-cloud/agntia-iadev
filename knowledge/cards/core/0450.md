# 0450 — ¿Qué es una saga?

## Contenido original

Es un patrón de coordinación de operaciones distribuidas que utiliza una secuencia de transacciones locales y, cuando procede, acciones compensatorias.

Puede ayudar a gestionar procesos que abarcan varios servicios sin utilizar una única transacción de base de datos.

Su complejidad exige diseñar estados, errores y recuperaciones de manera explícita.

**Descubrimiento\:** en una aplicación agéntica profesional, el modelo puede interpretar intenciones y proponer pasos, mientras el runtime aplica las reglas que determinan qué puede ejecutarse realmente.
