# 0809 — Migration rollback: reversión de migración

## Contenido original

Es el procedimiento para recuperar un estado anterior después de una migración problemática.

No todas las migraciones pueden revertirse fácilmente.

Eliminar columnas o transformar datos puede exigir backups y estrategias específicas de recuperación.
