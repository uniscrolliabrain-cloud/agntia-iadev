# 0793 — Connection pool: grupo de conexiones

## Contenido original

Es un mecanismo que reutiliza conexiones a la base de datos.

Abrir una conexión nueva para cada operación puede resultar costoso.

Un pool permite gestionar conexiones de manera más eficiente, con límites adecuados.
