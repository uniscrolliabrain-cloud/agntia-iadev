# 0303 — ¿Qué es Claude Code?

## Contenido original

Claude Code es una herramienta de desarrollo asistido por IA que puede trabajar con archivos, terminales y repositorios.

Permite delegar tareas de programación y realizar operaciones sobre el código según las capacidades del entorno.

Distintos agentes pueden ofrecer flujos de trabajo diferentes, pero comparten una necesidad: instrucciones claras y verificación.
