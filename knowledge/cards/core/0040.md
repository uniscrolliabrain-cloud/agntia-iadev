# 0040 — ¿Qué es la inferencia?

## Contenido original

La inferencia es el proceso de utilizar un modelo ya entrenado para producir un resultado a partir de una entrada.

Cuando escribes una pregunta y recibes una respuesta, el modelo está realizando inferencia.

Esta operación consume recursos computacionales y puede tener costes asociados.
