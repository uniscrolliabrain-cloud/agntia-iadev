# 0701 — Quality gate: puerta de calidad

## Contenido original

Es una condición que debe cumplirse antes de permitir el avance de una tarea, fase o release.

Puede exigir compilación, pruebas, revisión de seguridad o aprobación.

El gate debe tener criterios explícitos.
