# 0042 — ¿Qué es una herramienta para un agente?

## Contenido original

Una herramienta es una capacidad externa que el sistema pone a disposición de la IA.

Por ejemplo, leer un archivo, buscar código, ejecutar un test o consultar una base de datos.

El modelo puede solicitar su utilización, pero la herramienta y el sistema que la controla son quienes ejecutan la operación.
