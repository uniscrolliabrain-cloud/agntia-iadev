# 0681 — Dependency graph: grafo de dependencias

## Contenido original

Es una representación de qué tareas dependen de otras.

Por ejemplo, el frontend de facturas puede necesitar que el contrato de la API esté definido.

Un grafo permite ordenar el trabajo y detectar tareas que pueden ejecutarse en paralelo.
