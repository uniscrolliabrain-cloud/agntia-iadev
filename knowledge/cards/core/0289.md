# 0289 — ¿Qué es la compatibilidad hacia atrás?

## Contenido original

Es la capacidad de una nueva versión para seguir funcionando con consumidores que utilizan contratos anteriores.

Por ejemplo, añadir un campo opcional a una respuesta puede ser compatible con clientes existentes, dependiendo de cómo estén implementados.

Eliminar un campo obligatorio puede romper integraciones.
