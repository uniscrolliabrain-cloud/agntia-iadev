# 0475 — ¿Qué es la degradación controlada?

## Contenido original

Es una estrategia que permite ofrecer funcionalidad parcial cuando una dependencia no está disponible.

Por ejemplo, si falla la consulta de calendario, una aplicación puede seguir permitiendo consultar documentos.

La degradación no debe comprometer permisos ni presentar información desactualizada como si fuera actual.
