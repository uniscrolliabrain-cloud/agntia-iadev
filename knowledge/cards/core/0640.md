# 0640 — Patch marker: marca de modificación

## Contenido original

Es una etiqueta identificable que ayuda a registrar o detectar un cambio aplicado.

Por ejemplo\:

```ts
// FIX_RESERVAS_DUPLICADAS_V1
```

Las marcas textuales son útiles, pero no sustituyen la revisión del código ni las pruebas.

**Descubrimiento\:** modificar código con precisión exige conocer qué se cambia, dónde, por qué y cómo comprobar que la operación fue correcta.
