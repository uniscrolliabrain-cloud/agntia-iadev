# 0596 — ¿Qué es una migración de despliegue?

## Contenido original

Es un cambio necesario para que una nueva versión funcione correctamente con su entorno o sus datos.

Puede incluir modificar esquemas de base de datos o configuraciones.

Las migraciones deben planificarse teniendo en cuenta compatibilidad, datos existentes y recuperación.
