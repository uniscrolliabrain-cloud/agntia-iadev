# 0242 — ¿Qué es un caso de prueba?

## Contenido original

Es una descripción de una situación concreta que queremos comprobar.

Normalmente incluye condiciones iniciales, acciones y resultados esperados.

Por ejemplo: «Si un usuario crea una tarea con un título válido, el sistema debe guardarla y devolver su identificador».
