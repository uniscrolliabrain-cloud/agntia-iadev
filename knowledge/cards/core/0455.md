# 0455 — ¿Qué es un cliente API?

## Contenido original

Es el componente de software que realiza solicitudes a una API.

Puede ser una biblioteca, una clase o un módulo.

Por ejemplo, un cliente de Gmail puede encapsular las llamadas necesarias para consultar mensajes.
