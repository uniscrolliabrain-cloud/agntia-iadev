# 0210 — ¿Qué es un rollback de despliegue?

## Contenido original

Es una operación para recuperar una versión anterior cuando una nueva publicación provoca problemas.

Puede consistir en volver a desplegar un artefacto anterior o cambiar qué versión recibe tráfico.

Pero una reversión de código no siempre revierte modificaciones de datos, por lo que debe planificarse cuidadosamente.
