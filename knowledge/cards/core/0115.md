# 0115 — ¿Qué es pip?

## Contenido original

pip es una herramienta habitual para instalar paquetes de Python.

Por ejemplo\:

```bash

python -m pip install requests
```

Este comando instala una biblioteca que permite realizar solicitudes HTTP.

En proyectos reales conviene gestionar cuidadosamente versiones y entornos.
