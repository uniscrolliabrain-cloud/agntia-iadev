# 0668 — Task granularity: granularidad de tareas

## Contenido original

Es el nivel de detalle con el que se divide el trabajo.

Una tarea demasiado grande puede ser difícil de verificar.

Una excesivamente pequeña puede producir mucha coordinación innecesaria.

Buscamos unidades que un agente pueda completar, probar y reportar de forma independiente.
