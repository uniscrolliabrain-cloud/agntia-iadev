# 0114 — ¿Qué es una biblioteca?

## Contenido original

Una biblioteca es un conjunto reutilizable de funciones, clases y otros recursos de programación.

Por ejemplo, existen bibliotecas para trabajar con documentos PDF, procesar imágenes o realizar cálculos matemáticos.

Utilizar bibliotecas evita tener que construir todas las capacidades desde cero.
