# 0067 — ¿Qué es el directorio de trabajo?

## Contenido original

Es el conjunto de archivos del proyecto que tienes disponibles para consultar y modificar.

Cuando un agente cambia un archivo, normalmente está modificando el directorio de trabajo.

Esos cambios todavía no tienen por qué formar parte de un commit.
