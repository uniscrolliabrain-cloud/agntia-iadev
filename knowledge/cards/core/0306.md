# 0306 — ¿Qué es una herramienta de agente?

## Contenido original

Es una capacidad externa que el agente puede invocar para realizar una operación.

Por ejemplo, leer un archivo, buscar código, ejecutar un comando o consultar Git.

El modelo decide qué herramienta solicitar, pero el sistema que lo ejecuta debe controlar los permisos y la operación real.
