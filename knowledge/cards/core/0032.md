# 0032 — ¿Qué es un modelo de IA?

## Contenido original

Un modelo es un sistema matemático y computacional que ha sido ajustado mediante un proceso de entrenamiento para producir determinados resultados.

Por ejemplo, un modelo puede recibir una fotografía y estimar qué objetos aparecen en ella.

Otro puede recibir texto y generar una respuesta.

El modelo es una pieza del sistema. La aplicación que lo utiliza puede incluir muchas otras.
