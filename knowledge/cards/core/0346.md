# 0346 — ¿Qué es Prometheus?

## Contenido original

Prometheus es un sistema de monitorización y almacenamiento de métricas de series temporales.

Se utiliza habitualmente para recopilar y consultar indicadores de infraestructura y aplicaciones.

Puede integrarse con Grafana para crear paneles.
