# 0413 — ¿Qué es la memoria episódica?

## Contenido original

Es una forma de organizar recuerdos sobre acontecimientos o experiencias anteriores.

En una aplicación agéntica puede representar ejecuciones, conversaciones o decisiones pasadas.

Es una analogía funcional inspirada en conceptos de memoria humana, no una prueba de que el sistema tenga experiencias subjetivas.
