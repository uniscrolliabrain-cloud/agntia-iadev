# 0362 — ¿Qué es un parámetro?

## Contenido original

Es un valor numérico que forma parte del funcionamiento de un modelo.

Durante el entrenamiento, muchos de estos valores se ajustan para mejorar el comportamiento del sistema.

Un modelo puede contener millones o miles de millones de parámetros.

Tener más parámetros no garantiza automáticamente mejores resultados en todas las tareas.
