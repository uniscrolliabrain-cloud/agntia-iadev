# 0081 — ¿Qué es un README?

## Contenido original

Es un documento que suele explicar qué es un proyecto, cómo instalarlo, cómo ejecutarlo y dónde encontrar más información.

Normalmente se llama `README.md`\.

Un buen README ayuda a que una persona o agente entienda el proyecto antes de modificarlo.
