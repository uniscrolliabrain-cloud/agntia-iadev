# 0431 — ¿Qué es una cola de trabajos?

## Contenido original

Es una estructura que almacena trabajos pendientes de procesamiento.

Permite separar el momento en que se solicita una tarea del momento en que se ejecuta.

Por ejemplo, una aplicación puede añadir cien correos a una cola para procesarlos progresivamente.
