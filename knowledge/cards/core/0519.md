# 0519 — ¿Qué es la carga cognitiva?

## Contenido original

Es el esfuerzo mental requerido para procesar información o realizar una tarea.

Las interfaces pueden aumentar esa carga cuando presentan demasiadas opciones, conceptos desconocidos o decisiones innecesarias.

Reducirla no significa ocultar funcionalidades importantes, sino organizarlas adecuadamente.
