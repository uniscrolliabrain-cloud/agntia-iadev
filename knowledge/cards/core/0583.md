# 0583 — ¿Qué es una variable de entorno?

## Contenido original

Es un valor que el entorno de ejecución proporciona a un proceso.

Puede utilizarse para configurar una conexión, seleccionar un modo de funcionamiento o localizar servicios.

Las variables de entorno no son, por sí mismas, un sistema seguro de almacenamiento de secretos.
