# 0353 — ¿Qué es un correlation ID?

## Contenido original

Es un identificador utilizado para relacionar registros y operaciones que pertenecen a un mismo flujo.

Por ejemplo, una petición de usuario puede generar varias llamadas a servicios diferentes.

Compartir un identificador de correlación facilita reconstruir ese recorrido.
