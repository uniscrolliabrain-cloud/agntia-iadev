# 0275 — ¿Qué es el acoplamiento?

## Contenido original

Es el grado de dependencia entre componentes.

Si modificar una función obliga a cambiar veinte módulos, probablemente existe un acoplamiento elevado.

Reducir dependencias innecesarias puede facilitar el mantenimiento.

Sin embargo, no toda dependencia es mala: los componentes necesitan colaborar.
