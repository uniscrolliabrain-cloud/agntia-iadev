# 0350 — ¿Qué es una alerta?

## Contenido original

Es una notificación generada cuando una condición de monitorización se cumple.

Por ejemplo, cuando aumenta la tasa de errores o un servicio deja de responder.

Las alertas deben diseñarse cuidadosamente para evitar exceso de notificaciones y distinguir problemas importantes de variaciones normales.
