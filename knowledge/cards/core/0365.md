# 0365 — ¿Qué es un tokenizador?

## Contenido original

Es un componente que convierte texto en unidades que el modelo puede procesar.

Estas unidades se denominan *tokens*\.

Un token puede representar una palabra completa, parte de una palabra, un signo o incluso determinados bytes, según el tokenizador utilizado.
