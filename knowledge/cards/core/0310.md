# 0310 — ¿Qué es el principio de supervisión humana?

## Contenido original

Es la práctica de mantener a las personas responsables de las decisiones importantes del proceso.

Un agente puede proponer código o ejecutar pruebas, pero operaciones como publicar versiones, modificar permisos sensibles o integrar cambios críticos pueden requerir aprobación.

**Descubrimiento\:** dar autonomía a un agente no significa renunciar al control del proyecto.
