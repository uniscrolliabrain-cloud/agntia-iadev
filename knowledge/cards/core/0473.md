# 0473 — ¿Qué es la validación de respuestas externas?

## Contenido original

Es la comprobación de que los datos recibidos de otro sistema cumplen las condiciones esperadas.

Una API externa puede devolver campos ausentes, formatos nuevos o errores.

Validar evita que datos incorrectos se propaguen por la aplicación.
