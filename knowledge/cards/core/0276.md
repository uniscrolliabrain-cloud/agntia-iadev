# 0276 — ¿Qué es la cohesión?

## Contenido original

Es el grado en que los elementos de un módulo están relacionados con una responsabilidad común.

Un módulo dedicado exclusivamente a gestionar clientes suele tener mayor cohesión que otro que mezcla clientes, pagos, vídeos y autenticación sin una razón clara.
