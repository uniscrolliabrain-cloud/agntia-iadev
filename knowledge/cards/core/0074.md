# 0074 — ¿Qué es un merge?

## Contenido original

Un *merge* es una operación que integra historias de desarrollo.

Si has creado una función en una rama, puedes combinarla con otra rama mediante un merge.

Git puede realizar algunas integraciones automáticamente, pero otras requieren resolver conflictos.
