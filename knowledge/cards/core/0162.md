# 0162 — ¿Qué es una base de datos relacional?

## Contenido original

Es una base de datos que organiza la información mediante relaciones y estructuras tabulares.

Por ejemplo, podemos tener una tabla de empresas y otra de clientes.

Cada cliente puede estar asociado a una empresa mediante un identificador.
