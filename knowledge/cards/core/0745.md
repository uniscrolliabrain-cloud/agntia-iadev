# 0745 — Version negotiation: negociación de versiones

## Contenido original

Es un mecanismo mediante el cual dos sistemas determinan qué versión de una interfaz utilizar.

Puede realizarse mediante rutas, cabeceras o capacidades anunciadas.

No todos los sistemas necesitan negociación dinámica.
