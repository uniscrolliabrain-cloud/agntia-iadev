# 0816 — JWT claims: afirmaciones del token

## Contenido original

Son campos que describen información asociada al token.

Algunos habituales son\:

- `sub`\: sujeto o identidad.
- `iss`\: emisor.
- `aud`\: destinatario previsto.
- `exp`\: expiración.
- `iat`\: momento de emisión.

Los permisos reales pueden requerir comprobaciones adicionales en la base de datos.
