# 0817 — jose: biblioteca de tokens y criptografía

## Contenido original

`jose` es una biblioteca de JavaScript y TypeScript para trabajar con JWT, JWS, JWE y claves criptográficas.

Un agente puede utilizarla para implementar verificaciones de tokens.

Por ejemplo\:

```ts
import { jwtVerify } from "jose";

const { payload } = await jwtVerify(token, publicKey, {
  issuer: "https://auth.example.test",
  audience: "orbita-api",
});
```

Aquí `publicKey` representa una clave de verificación previamente configurada. En un sistema real deben seleccionarse algoritmos y claves compatibles con el emisor de confianza.
