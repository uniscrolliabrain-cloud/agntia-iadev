# 0117 — ¿Qué es un script?

## Contenido original

Un script es un programa que normalmente ejecuta una tarea concreta.

Por ejemplo, un script puede leer un archivo CSV, calcular estadísticas y generar un informe.

Los scripts son una forma habitual de empezar a automatizar trabajo repetitivo.
