# 0435 — ¿Qué es el exponential backoff?

## Contenido original

Es una estrategia que aumenta progresivamente el tiempo de espera entre reintentos.

Por ejemplo, un sistema puede esperar aproximadamente uno, dos, cuatro y ocho segundos.

Suele combinarse con variación aleatoria para evitar que muchos procesos reintenten simultáneamente.
