# 0166 — ¿Qué es SQL?

## Contenido original

SQL significa *Structured Query Language*\.

Es un lenguaje utilizado para definir, consultar y modificar información en bases de datos relacionales.

```sql

SELECT nombre, email
FROM clientes
WHERE activo = true;
```

Esta consulta solicita el nombre y el correo de los clientes activos.
