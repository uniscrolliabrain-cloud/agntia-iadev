# 0034 — ¿Qué es un LLM?

## Contenido original

LLM significa *Large Language Model*, o modelo de lenguaje de gran tamaño.

Es un tipo de modelo entrenado para trabajar con secuencias de información, especialmente lenguaje, y generar continuaciones apropiadas según su entrenamiento y contexto.

Puede explicar conceptos, resumir documentos, traducir, escribir código o ayudar a analizar problemas.

ChatGPT utiliza modelos de esta familia.
