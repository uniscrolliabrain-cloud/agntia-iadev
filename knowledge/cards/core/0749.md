# 0749 — Integration rollback: reversión de integración

## Contenido original

Es el procedimiento para recuperar un estado compatible después de un cambio transversal fallido.

Puede requerir revertir varios componentes de forma coordinada.

No siempre basta con restaurar una única rama.
