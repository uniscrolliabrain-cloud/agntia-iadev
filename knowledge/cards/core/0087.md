# 0087 — ¿Qué es un secret?

## Contenido original

Un *secret* es un dato sensible utilizado por un sistema, como una contraseña, un token o una clave de API.

GitHub permite almacenar secretos para determinados procesos automatizados.

No deben introducirse directamente en archivos públicos de código.
