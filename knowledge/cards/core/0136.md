# 0136 — ¿Qué es un hook?

## Contenido original

Un hook es una función especial de React que permite utilizar capacidades como estado, efectos y referencias dentro de componentes.

Uno de los más conocidos es `useState`\.

```jsx

import { useState } from "react";

function Contador() {
  const [numero, setNumero] = useState(0);

  return (
    <button onClick={() => setNumero(numero + 1)}>
      Pulsaciones: {numero}
    </button>
  );
}
```
