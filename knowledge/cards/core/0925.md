# 0925 — CI workflow

## Contenido original

Es la definición de tareas automatizadas que se ejecutan dentro de un pipeline.

Por ejemplo\:

```yaml
name: Verify

on:
  pull_request:

jobs:
  checks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 11
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck
      - run: pnpm test
```

Es un ejemplo que debe adaptarse a la versión de Node, pnpm y los scripts del proyecto. Para producción conviene fijar acciones a commits revisados y aplicar permisos mínimos.
