# 0432 — ¿Qué es un worker?

## Contenido original

Es un proceso o componente encargado de ejecutar trabajos.

Puede recoger tareas de una cola, procesarlas y registrar sus resultados.

Los workers son útiles para operaciones que no deben bloquear la respuesta inmediata de una aplicación.
