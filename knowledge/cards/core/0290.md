# 0290 — ¿Qué es una dependencia entre repositorios?

## Contenido original

Es una relación en la que un repositorio necesita capacidades, contratos o artefactos de otro.

Por ejemplo, una aplicación principal puede necesitar una versión concreta de un SDK desarrollado en otro repositorio.

Estas dependencias deben documentarse y comprobarse.
