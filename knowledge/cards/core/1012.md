# 1012 — Dependency graph: grafo de dependencias

## Contenido original

Es una representación de qué tareas necesitan que otras terminen primero.

Por ejemplo\:

`Contrato → Backend → Integración → E2E`

Permite identificar qué trabajos pueden comenzar en paralelo.
