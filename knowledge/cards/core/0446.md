# 0446 — ¿Qué es una aprobación humana?

## Contenido original

Es una autorización explícita requerida antes de realizar determinadas acciones.

Por ejemplo, enviar un correo sensible, aprobar un pago o eliminar información.

Una aprobación debe asociarse a la operación concreta que se autoriza.
