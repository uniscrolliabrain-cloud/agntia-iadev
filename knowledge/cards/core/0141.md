# 0141 — ¿Qué es UI?

## Contenido original

UI significa *User Interface*, o interfaz de usuario.

Es el conjunto de elementos mediante los que una persona interactúa con una aplicación.

Incluye botones, menús, formularios, paneles, iconos y otros controles.
