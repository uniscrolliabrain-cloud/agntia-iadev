# 0533 — ¿Qué son las WCAG?

## Contenido original

Son las *Web Content Accessibility Guidelines*, directrices internacionales para mejorar la accesibilidad del contenido web.

Incluyen criterios relacionados con percepción, operación, comprensión y robustez.

Se utilizan como referencia para diseñar y evaluar interfaces accesibles.
