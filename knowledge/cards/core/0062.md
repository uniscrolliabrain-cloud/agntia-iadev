# 0062 — ¿Qué es Git?

## Contenido original

Git es un sistema de control de versiones distribuido.

Permite registrar cambios, crear líneas de trabajo independientes, comparar versiones y combinar modificaciones.

Git funciona en tu ordenador y no necesita GitHub para realizar muchas de sus operaciones.

**Analogía\:** Git es la maquinaria que mantiene el historial de tu proyecto. GitHub es uno de los lugares donde puedes alojarlo y colaborar.
