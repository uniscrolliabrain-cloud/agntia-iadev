# 0382 — ¿Qué es fine-tuning?

## Contenido original

Es un proceso de entrenamiento adicional que adapta un modelo a datos o comportamientos específicos.

Puede utilizarse para especializar tareas, estilos o formatos.

No siempre es necesario: muchas aplicaciones pueden resolver sus necesidades mediante prompting, herramientas y recuperación de información.
