# 1008 — Cherry-pick

## Contenido original

Es una operación de Git que permite aplicar un commit concreto sobre otra rama.

Puede ser útil para integrar fixes aislados.

No sustituye una estrategia de integración ni garantiza ausencia de conflictos.
