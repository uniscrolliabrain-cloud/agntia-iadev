# 0169 — ¿Qué es una transacción?

## Contenido original

Es una unidad de trabajo que agrupa operaciones de base de datos bajo determinadas garantías.

Imagina una transferencia bancaria: hay que descontar dinero de una cuenta y añadirlo a otra.

Una transacción ayuda a evitar que solo se complete una parte del proceso.
