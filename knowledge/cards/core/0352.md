# 0352 — ¿Qué es una ejecución de agente?

## Contenido original

Es una instancia concreta de trabajo realizada por un sistema agéntico.

Puede comenzar con una solicitud del usuario y terminar con un resultado, un error o una cancelación.

Cada ejecución debería poder identificarse para facilitar su seguimiento.
