# 0046 — ¿Qué es un entorno de ejecución?

## Contenido original

Es el conjunto de recursos donde un programa o agente realiza su trabajo.

Puede incluir sistema operativo, archivos, dependencias, intérpretes, terminal y acceso a servicios.

Un agente de programación necesita un entorno adecuado para comprobar que el código funciona.

Generar texto que parece código no es lo mismo que ejecutarlo.
