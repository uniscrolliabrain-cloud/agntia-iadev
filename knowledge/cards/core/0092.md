# 0092 — ¿Qué es la sintaxis?

## Contenido original

La sintaxis es el conjunto de reglas que determina cómo debe escribirse el código.

Por ejemplo, en JavaScript podemos escribir\:

```javascript

const nombre = "Ana";
console.log(nombre);
```

En Python, una operación parecida sería\:

```python

nombre = "Ana"
print(nombre)
```

Ambos ejemplos guardan un nombre y lo muestran, pero utilizan sintaxis diferente.
