# 0005 — ¿Qué es una aplicación?

## Contenido original

Una aplicación es software diseñado para realizar determinadas tareas útiles para una persona u organización.

WhatsApp permite comunicarse. Un calendario permite organizar citas. Un editor de vídeo permite montar secuencias audiovisuales.

Una aplicación puede contener muchos programas y componentes internos.
