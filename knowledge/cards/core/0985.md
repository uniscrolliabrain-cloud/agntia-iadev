# 0985 — Contract test: prueba de contrato

## Contenido original

Comprueba que dos componentes respetan una interfaz acordada.

Por ejemplo, que una API devuelve los campos y tipos esperados.

Es especialmente útil cuando distintos agentes desarrollan servicios independientes.
