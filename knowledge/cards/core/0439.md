# 0439 — ¿Qué es un timeout?

## Contenido original

Es un límite de tiempo establecido para una operación.

Si la operación no termina dentro del intervalo permitido, el sistema puede interrumpir la espera o marcarla como fallida.

Un timeout no garantiza que una operación remota se haya cancelado realmente.
