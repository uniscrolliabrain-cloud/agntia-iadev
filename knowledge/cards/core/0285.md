# 0285 — ¿Qué es un multirepo?

## Contenido original

Es una estrategia en la que un sistema o ecosistema utiliza varios repositorios independientes.

Por ejemplo, uno para la aplicación principal y otros para integraciones o servicios especializados.

Permite separar ciclos de desarrollo, pero exige coordinar versiones, contratos y dependencias.
