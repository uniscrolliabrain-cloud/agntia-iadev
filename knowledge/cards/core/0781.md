# 0781 — Persistence: persistencia

## Contenido original

Es la capacidad de conservar información después de que termine una operación o se reinicie un programa.

Por ejemplo, cuando guardas una factura, esperas encontrarla mañana.

Una variable de JavaScript normalmente vive en la memoria del proceso. Una base de datos permite conservar información más allá de ese proceso.
