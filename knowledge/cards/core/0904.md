# 0904 — Fly.io

## Contenido original

Es una plataforma que permite ejecutar aplicaciones y servicios en infraestructura cloud.

Puede utilizarse para APIs, workers y procesos que necesitan un entorno de ejecución de servidor.

Un agente puede preparar su configuración, pero el despliegue debe verificarse contra los requisitos reales del servicio.
