# 0228 — ¿Qué es un gestor de secretos?

## Contenido original

Es una herramienta o servicio diseñado para almacenar, distribuir y controlar el acceso a credenciales sensibles.

Permite separar secretos del código fuente y gestionar su utilización en diferentes entornos.

También puede facilitar rotación, auditoría y control de permisos.
