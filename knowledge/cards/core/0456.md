# 0456 — ¿Qué es un adaptador?

## Contenido original

Es un componente que traduce entre la interfaz interna de tu aplicación y la interfaz de otro sistema.

Por ejemplo, tu aplicación puede utilizar una operación interna llamada `listarCorreos()`, mientras el adaptador se encarga de llamar al proveedor correspondiente.

Esto permite cambiar implementaciones sin modificar toda la lógica empresarial.
