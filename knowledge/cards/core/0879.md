# 0879 — Distributed trace: traza distribuida

## Contenido original

Es el registro del recorrido de una operación por distintos componentes.

Por ejemplo\:

`Chat → API → Runtime → PostgreSQL → Proveedor externo`

Una traza permite identificar qué parte del recorrido consume más tiempo.
