# 0017 — ¿Qué es backend?

## Contenido original

El backend es la parte que realiza tareas del lado del servidor, como procesar solicitudes, aplicar reglas, consultar bases de datos y coordinar operaciones.

Si pulsas un botón para crear una tarea, el frontend recoge tu acción y el backend puede comprobar permisos, registrar la tarea y devolver un resultado.

**Descubrimiento\:** una interfaz bonita no garantiza que exista un sistema funcional detrás.
