# 0278 — ¿Qué es una interfaz de programación?

## Contenido original

Es un contrato que define cómo puede utilizarse un componente.

Puede describir funciones, parámetros, resultados y comportamientos esperados.

En TypeScript, una interfaz también puede definir la estructura de determinados datos.

Las interfaces ayudan a que los componentes colaboren sin necesitar conocer todos sus detalles internos.
