# 1057 — Tool calling: invocación de herramientas

## Contenido original

Es la capacidad de un modelo para proponer llamadas a herramientas con argumentos estructurados.

Por ejemplo, solicitar una búsqueda de facturas.

La aplicación debe validar los argumentos y comprobar permisos antes de ejecutar la herramienta.
