# 0843 — HTTP client: cliente HTTP

## Contenido original

Es el componente que realiza peticiones a una API.

En JavaScript podemos utilizar `fetch`\:

```ts
const response = await fetch(
  "https://api.example.test/customers",
  {
    headers: {
      Authorization: `Bearer ${token}`,
    },
  }
);
```

En un sistema real, debemos gestionar errores, límites de tiempo y validación de respuestas.
