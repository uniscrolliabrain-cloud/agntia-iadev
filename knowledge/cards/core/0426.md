# 0426 — ¿Qué es un trigger?

## Contenido original

Es el acontecimiento o condición que inicia una automatización.

Puede ser un evento, un horario, una solicitud HTTP o una acción humana.

Por ejemplo, recibir un formulario de contacto puede iniciar un proceso de captación de clientes.
