# 0273 — ¿Qué es un módulo?

## Contenido original

Es una unidad de organización del código que agrupa funcionalidades relacionadas.

Un módulo de clientes puede contener operaciones para crear, consultar y actualizar registros de clientes.

Los módulos ayudan a evitar que todo el programa se convierta en un único archivo gigantesco.
