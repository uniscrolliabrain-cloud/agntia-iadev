# 0372 — ¿Qué es la predicción del siguiente token?

## Contenido original

Es un mecanismo utilizado por muchos modelos de lenguaje generativos.

El modelo calcula una distribución de probabilidades sobre posibles tokens siguientes, teniendo en cuenta el contexto disponible.

Después se selecciona un token mediante una estrategia de decodificación.

El proceso se repite para generar una secuencia.
