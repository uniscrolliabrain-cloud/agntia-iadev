# 0845 — API adapter: adaptador de API

## Contenido original

Es una capa que traduce entre nuestro modelo interno y el de un proveedor.

Por ejemplo, nuestro software puede utilizar una operación común\:

`sendEmail(message)`

Y el adaptador la transforma en la petición concreta de Resend o de otro servicio.
