# 0682 — Topological order: orden topológico

## Contenido original

Es una secuencia de tareas que respeta las dependencias de un grafo dirigido sin ciclos.

Si `B` depende de `A`, entonces `A` debe aparecer antes que `B`\.

Es útil para ordenar waves y patchsets.
