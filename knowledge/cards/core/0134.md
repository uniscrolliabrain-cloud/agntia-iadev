# 0134 — ¿Qué son las props?

## Contenido original

Las *props* son datos que un componente recibe desde su componente padre.

Permiten reutilizar una misma estructura con contenido diferente.

```jsx

function Tarjeta({ nombre }) {
  return <p>Empleado: {nombre}</p>;
}
```

Podemos utilizar `Tarjeta` para mostrar a Ana, Pedro o cualquier otra persona.
