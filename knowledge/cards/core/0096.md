# 0096 — ¿Qué es un booleano?

## Contenido original

Es un tipo de dato que representa uno de dos valores: verdadero o falso.

```javascript

const pagado = true;
const cancelado = false;
```

Los booleanos son útiles para representar estados y evaluar condiciones.

Por ejemplo, una aplicación puede comprobar si una factura está pagada antes de permitir determinadas operaciones.
