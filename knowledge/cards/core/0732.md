# 0732 — Cross-repo dependency: dependencia entre repositorios

## Contenido original

Existe cuando un proyecto necesita un contrato, paquete o servicio proporcionado por otro.

Por ejemplo, una aplicación web puede depender de un SDK de facturación.

Conviene registrar estas dependencias para planificar cambios compatibles.
