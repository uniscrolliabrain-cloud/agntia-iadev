# 0707 — Conditional acceptance: aceptación condicionada

## Contenido original

Es una decisión de aceptar un resultado con restricciones o condiciones documentadas.

Por ejemplo, aprobar una versión para staging, pero no para producción.

No debe utilizarse para saltarse controles obligatorios sin autorización.
