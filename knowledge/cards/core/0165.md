# 0165 — ¿Qué es una clave foránea?

## Contenido original

Es un campo que referencia una clave de otra tabla.

Por ejemplo, un cliente puede tener `empresa_id = 12`\.

Esto permite representar la relación entre el cliente y la empresa correspondiente.
