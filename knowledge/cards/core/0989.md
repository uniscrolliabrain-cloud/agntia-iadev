# 0989 — Quality gate: gate de calidad

## Contenido original

Es un control que determina si una modificación cumple los criterios establecidos.

Puede incluir\:

`TYPECHECK · UNIT · INTEGRATION · E2E · SECURITY · REVIEW`

Cada criterio debe registrar `PASS`, `FAIL` o `BLOCKED`, según corresponda.
