# 0833 — Delegated authority: autoridad delegada

## Contenido original

Es la autorización limitada para actuar en nombre de otra identidad.

Por ejemplo, un agente puede preparar una factura en nombre de un empleado.

La delegación debe tener alcance, límites y duración definidos.
