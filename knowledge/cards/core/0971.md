# 0971 — Vitest

## Contenido original

Es un framework de testing para proyectos JavaScript y TypeScript.

Permite organizar suites, ejecutar pruebas y utilizar aserciones y mocks.

Ejemplo\:

```ts
import { describe, it, expect } from "vitest";

describe("invoice total", () => {
  it("sums two amounts", () => {
    expect(200 + 300).toBe(500);
  });
});
```

**Con agentes\:** podemos pedirles que creen tests en un patchset independiente, ejecuten Vitest y registren los fallos encontrados.
