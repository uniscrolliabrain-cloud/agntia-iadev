# 0920 — Container image

## Contenido original

Es un paquete que contiene la aplicación y los elementos necesarios para ejecutarla.

La imagen puede utilizarse para crear contenedores.

Una buena práctica es construir imágenes reproducibles y analizar sus dependencias y vulnerabilidades.

**Descubrimiento\:** Docker empaqueta la aplicación, Doppler ayuda a gestionar secretos y los proveedores cloud proporcionan infraestructura para ejecutarla. Son responsabilidades diferentes.
