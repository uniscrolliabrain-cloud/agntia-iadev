# 0467 — ¿Qué es un webhook?

## Contenido original

Es un mecanismo por el cual un servicio envía una solicitud a otro sistema cuando ocurre un acontecimiento.

Por ejemplo, un proveedor puede avisar de que se ha recibido un mensaje.

Esto evita consultar continuamente la API para descubrir cambios, aunque algunos sistemas combinan ambos métodos.
