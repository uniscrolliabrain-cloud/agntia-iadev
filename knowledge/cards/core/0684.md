# 0684 — Contract freeze: congelación de contratos

## Contenido original

Es una decisión temporal de mantener estable una interfaz mientras varios equipos desarrollan componentes que dependen de ella.

Puede aplicarse a esquemas, APIs o formatos de eventos.

No significa que el contrato nunca pueda cambiar; significa que sus modificaciones requieren coordinación.
