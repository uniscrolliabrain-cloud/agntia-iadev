# 0528 — ¿Qué es una command palette?

## Contenido original

Es una interfaz que permite buscar y ejecutar acciones mediante texto o atajos.

Por ejemplo, abrir un proyecto, buscar un cliente o crear una tarea.

Puede mejorar la velocidad de uso para personas que conocen el producto.
