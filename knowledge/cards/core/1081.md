# 1081 — Token

## Contenido original

Es una unidad de texto utilizada por los modelos de lenguaje para procesar entradas y generar respuestas.

Un token no equivale necesariamente a una palabra.

La cantidad depende del tokenizador, idioma y contenido.

**Con agentes\:** podemos instrumentar cada llamada para registrar tokens consumidos, modelo, operación y coste estimado.
