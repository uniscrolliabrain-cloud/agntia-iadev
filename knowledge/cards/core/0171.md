# 0171 — ¿Qué es un usuario?

## Contenido original

Es una identidad que interactúa con un sistema.

Puede representar una persona y, en algunos diseños, también una cuenta de servicio u otro actor autorizado.

Una aplicación empresarial necesita distinguir quién realiza cada operación.
