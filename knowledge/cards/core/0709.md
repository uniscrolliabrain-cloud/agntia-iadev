# 0709 — Human approval gate: aprobación humana

## Contenido original

Es un control que exige una decisión explícita de una persona autorizada.

Puede utilizarse antes de modificar infraestructura, fusionar ramas o desplegar.

La IA puede preparar evidencias y recomendaciones, pero no debe atribuirse una aprobación inexistente.
