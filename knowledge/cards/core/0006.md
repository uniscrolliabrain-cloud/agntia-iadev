# 0006 — ¿Qué es un sistema operativo?

## Contenido original

Es el software fundamental que administra los recursos del ordenador y permite ejecutar otros programas.

Windows, Linux, macOS y Android son sistemas operativos.

Gestionan memoria, archivos, procesos, dispositivos y permisos.

**Analogía\:** si el ordenador fuera un edificio, el sistema operativo administraría las instalaciones y permitiría que distintas empresas trabajaran dentro.
