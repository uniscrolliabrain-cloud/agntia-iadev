# 0389 — ¿Qué es un presupuesto de tokens?

## Contenido original

Es un límite o planificación del consumo de tokens para una operación.

Puede utilizarse para controlar coste, longitud de respuesta y recursos computacionales.

El coste real depende de los precios del proveedor y de los tokens u otros recursos facturados.
