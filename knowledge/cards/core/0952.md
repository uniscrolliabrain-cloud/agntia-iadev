# 0952 — SQL injection: inyección SQL

## Contenido original

Es una vulnerabilidad que puede aparecer cuando datos no confiables se incorporan incorrectamente a consultas SQL.

Las consultas parametrizadas son una defensa fundamental.

```ts
await pool.query(
  "SELECT id FROM invoices WHERE id = $1",
  [invoiceId]
);
```
