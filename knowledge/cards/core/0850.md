# 0850 — API quota: cuota de uso

## Contenido original

Es un límite de consumo de recursos o funcionalidades.

Por ejemplo, una cantidad de mensajes, minutos de voz o peticiones.

Las cuotas pueden tener consecuencias operativas y económicas.

**Descubrimiento\:** una API externa amplía las capacidades del software, pero también introduce dependencias que no controlamos completamente.
