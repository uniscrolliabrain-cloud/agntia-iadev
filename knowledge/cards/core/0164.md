# 0164 — ¿Qué es una clave primaria?

## Contenido original

Es un identificador que permite distinguir de manera única cada registro de una tabla.

Por ejemplo, dos clientes pueden llamarse Ana, pero tener identificadores diferentes.

La clave primaria ayuda a evitar confusiones y permite relacionar registros.
