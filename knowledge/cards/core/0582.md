# 0582 — ¿Qué es un archivo de configuración?

## Contenido original

Es un archivo que define cómo debe comportarse un programa o servicio.

Puede incluir puertos, nombres de servicios, opciones y referencias a variables de entorno.

Separar configuración y código facilita utilizar una misma aplicación en diferentes entornos.
