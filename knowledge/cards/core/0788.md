# 0788 — Constraint: restricción

## Contenido original

Es una regla que la base de datos comprueba.

Por ejemplo\:

```sql
amount_cents INTEGER NOT NULL
CHECK (amount_cents > 0)
```

Esto impide guardar un importe nulo o no positivo en esa columna.

Las restricciones complementan la validación de Zod.
