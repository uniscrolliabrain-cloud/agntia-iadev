# 0108 — ¿Qué es Node.js?

## Contenido original

Node.js es un entorno que permite ejecutar JavaScript fuera del navegador.

Se utiliza para construir servidores, herramientas de desarrollo, automatizaciones y aplicaciones de línea de comandos.

Esto permite utilizar JavaScript o TypeScript tanto en la interfaz como en servicios del backend.
