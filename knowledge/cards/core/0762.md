# 0762 — State machine: máquina de estados

## Contenido original

Es un modelo que define los estados posibles y las transiciones permitidas.

Por ejemplo, una factura no debería pasar directamente de `DRAFT` a `PAID` sin registrar el proceso correspondiente.

Los agentes pueden proponer transiciones, pero el sistema debe validar que sean legales.
