# 0664 — Phase: fase

## Contenido original

Una *fase* es una etapa dentro de la campaña.

Por ejemplo\:

`P0 Audit → P1 Diagnóstico → P2 Diseño → P3 Implementación → P4 Tests → P5 Report`

Las fases ordenan el proceso lógico.

No siempre tienen que ejecutarse de forma completamente secuencial: algunas pueden solaparse cuando sus dependencias lo permiten.
