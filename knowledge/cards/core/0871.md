# 0871 — Observability: observabilidad

## Contenido original

Es la capacidad de comprender el estado y comportamiento de un sistema a partir de la información que produce.

No consiste simplemente en saber si el servidor está encendido.

También permite investigar errores, latencia, consumo, operaciones y dependencias.
