# 0172 — ¿Qué es la autenticación?

## Contenido original

Es el proceso de verificar la identidad de quien intenta acceder.

Puede utilizar contraseñas, claves de acceso, códigos temporales o proveedores de identidad.

Autenticarse responde a la pregunta: «¿Quién eres?».
