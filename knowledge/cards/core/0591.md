# 0591 — ¿Qué es el versionado semántico?

## Contenido original

Es una convención para identificar versiones mediante tres números: `MAJOR.MINOR.PATCH`\.

Por ejemplo, `2.4.1`\.

En el esquema SemVer, MAJOR señala cambios incompatibles en la API pública, MINOR funcionalidades compatibles y PATCH correcciones compatibles.

Su significado requiere que el proyecto defina qué considera su API pública.
