# 1107 — A/B testing

## Contenido original

Es un experimento donde diferentes grupos reciben variantes para comparar resultados.

Puede utilizarse para evaluar prompts, modelos o interfaces.

Es importante controlar sesgos y definir previamente la métrica principal.
