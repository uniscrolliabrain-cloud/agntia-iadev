# 1028 — Backward compatibility: compatibilidad hacia atrás

## Contenido original

Es la capacidad de una versión nueva para seguir funcionando con consumidores anteriores dentro de las garantías establecidas.

Añadir un campo opcional puede ser compatible; eliminar uno obligatorio puede romper consumidores.

La compatibilidad debe verificarse, no suponerse.
