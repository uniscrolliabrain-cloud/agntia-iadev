# 0529 — ¿Qué es un dashboard?

## Contenido original

Es una pantalla que reúne información y acciones relevantes para una persona o función.

Puede mostrar indicadores, tareas, alertas y accesos directos.

Un dashboard eficaz prioriza información útil sobre decoración o exceso de métricas.
