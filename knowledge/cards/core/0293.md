# 0293 — ¿Qué es un puerto?

## Contenido original

En arquitectura hexagonal, un puerto es una interfaz que define cómo el núcleo del sistema interactúa con capacidades externas o cómo estas pueden invocarlo.

Por ejemplo, un puerto de almacenamiento puede definir la operación `guardarFactura()`\.
