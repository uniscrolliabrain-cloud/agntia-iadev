# 0504 — ¿Qué es el contexto de ejecución?

## Contenido original

Es el conjunto de datos relevantes para determinar cómo se ejecuta una operación.

Puede incluir usuario, organización, agente, permisos, identificadores y origen de la solicitud.

El contexto debe validarse y propagarse de forma segura.
