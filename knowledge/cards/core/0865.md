# 0865 — Provider timeout: tiempo límite de proveedor

## Contenido original

Es el máximo tiempo que esperamos una respuesta externa.

Si se supera, el sistema debe gestionar el resultado como incierto cuando corresponda.

Por ejemplo, un correo podría haberse enviado aunque nuestra aplicación no recibiera la confirmación.
