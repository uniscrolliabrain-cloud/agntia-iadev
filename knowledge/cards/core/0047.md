# 0047 — ¿Qué es una terminal?

## Contenido original

La terminal es una interfaz que permite interactuar con el sistema mediante comandos de texto.

Por ejemplo\:

```bash

pwd
ls
mkdir mi-proyecto
```

En muchos sistemas Unix, estos comandos muestran la carpeta actual, enumeran archivos y crean una carpeta.

Los agentes de programación utilizan frecuentemente terminales para instalar dependencias, ejecutar tests y trabajar con repositorios.
