# 0061 — ¿Qué es el control de versiones?

## Contenido original

Es un sistema que permite registrar y gestionar los cambios realizados en archivos a lo largo del tiempo.

Imagina que estás escribiendo un libro. Cada vez que terminas un capítulo, guardas una versión identificable. Si después eliminas accidentalmente una sección, puedes consultar una versión anterior.

En software hacemos algo parecido, pero con herramientas capaces de gestionar miles de archivos y cambios.
