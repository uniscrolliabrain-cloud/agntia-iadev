# 0394 — ¿Qué es el parsing documental?

## Contenido original

Es el proceso de interpretar la estructura de un documento y extraer sus elementos.

Por ejemplo, identificar títulos, párrafos, tablas o campos.

La calidad del parsing importa porque una extracción incorrecta puede provocar respuestas equivocadas.
