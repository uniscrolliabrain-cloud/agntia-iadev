# 0959 — Security acceptance gate: gate de aceptación de seguridad

## Contenido original

Es un control que determina si una modificación cumple los requisitos de seguridad establecidos.

Puede exigir tests de autorización, análisis de dependencias, revisión de secretos y pruebas de regresión.
