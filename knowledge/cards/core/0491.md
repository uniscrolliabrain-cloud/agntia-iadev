# 0491 — ¿Qué es un rol?

## Contenido original

Es una categoría que agrupa responsabilidades o permisos dentro de una organización.

Por ejemplo, propietario, administrador, empleado o invitado.

Los roles facilitan gestionar autorizaciones sin configurarlas individualmente para cada usuario.
