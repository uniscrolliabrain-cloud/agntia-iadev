# 0106 — ¿Qué es una función asíncrona?

## Contenido original

Es una función que puede trabajar con operaciones cuyo resultado estará disponible más adelante, sin bloquear necesariamente toda la ejecución.

Por ejemplo, consultar una API puede tardar un tiempo.

JavaScript utiliza mecanismos como promesas y `async/await` para gestionar estas operaciones.
