# 0363 — ¿Qué es el entrenamiento?

## Contenido original

Es el proceso mediante el cual se ajustan los parámetros de un modelo utilizando datos y un objetivo de aprendizaje.

En modelos de lenguaje, una parte importante del entrenamiento consiste en aprender patrones estadísticos del lenguaje.

El entrenamiento requiere recursos computacionales, datos y procedimientos de optimización.
