# 0642 — Multipatch: ejecución coordinada de varios parches

## Contenido original

En nuestra metodología, utilizaremos *multipatch* para describir una operación que agrupa varios parches o patchsets bajo un plan de aplicación controlado.

No es un término universal con una única definición técnica.

Puede servir para ejecutar una serie de modificaciones relacionadas, respetando dependencias y verificaciones.
