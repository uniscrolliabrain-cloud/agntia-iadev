# 0056 — ¿Qué es una dependencia?

## Contenido original

Una dependencia es un componente externo o una condición que otro componente necesita para funcionar.

Una aplicación puede depender de React para su interfaz o de una base de datos para almacenar información.

También existen dependencias entre tareas: no puedes comprobar una integración que todavía no has implementado.
