# 0004 — ¿Qué es un programa?

## Contenido original

Un programa es un conjunto organizado de instrucciones que un ordenador puede ejecutar.

Por ejemplo, un programa sencillo puede recibir el precio de un producto, calcular el IVA y mostrar el resultado.

No todos los programas necesitan una pantalla. Algunos trabajan silenciosamente en segundo plano.

**Descubrimiento\:** hay muchísimo software funcionando que nunca vemos.
