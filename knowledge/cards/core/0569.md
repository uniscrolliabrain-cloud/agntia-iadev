# 0569 — ¿Qué es una entrega incremental?

## Contenido original

Es la incorporación progresiva de capacidades funcionales.

Permite desarrollar y verificar el producto por partes.

Una entrega incremental no implica necesariamente desplegar cada cambio a producción.
