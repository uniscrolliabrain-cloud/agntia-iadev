# 0547 — ¿Qué es Kanban?

## Contenido original

Es un método para visualizar y gestionar el flujo de trabajo.

Normalmente utiliza columnas que representan estados como pendiente, en curso y terminado.

Ayuda a detectar acumulaciones, bloqueos y exceso de tareas simultáneas.
