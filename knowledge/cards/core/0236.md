# 0236 — ¿Qué es un audit log?

## Contenido original

Es un registro diseñado para conservar evidencias de acciones relevantes.

Por ejemplo, quién cambió un permiso, cuándo se aprobó una operación o qué servicio ejecutó una tarea.

Los registros de auditoría ayudan a investigar incidentes y reconstruir acontecimientos.
