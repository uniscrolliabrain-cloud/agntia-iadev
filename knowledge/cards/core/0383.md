# 0383 — ¿Qué es instruction tuning?

## Contenido original

Es una forma de ajuste destinada a mejorar la capacidad de un modelo para seguir instrucciones.

Se utilizan ejemplos de instrucciones y respuestas esperadas durante el entrenamiento.

Es una de las técnicas que contribuyen al comportamiento de los asistentes conversacionales.
