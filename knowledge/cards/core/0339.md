# 0339 — ¿Qué es una traza distribuida?

## Contenido original

Es una representación del recorrido de una operación a través de distintos componentes.

Una petición puede pasar por el frontend, el backend, un servicio de autenticación y una API externa.

La traza permite estudiar cómo se relacionan esas operaciones y cuánto tarda cada etapa.
