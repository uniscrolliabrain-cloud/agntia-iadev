# 0101 — ¿Qué es JavaScript?

## Contenido original

JavaScript es un lenguaje de programación ampliamente utilizado para crear comportamientos interactivos en aplicaciones web.

Permite responder a pulsaciones, modificar contenido, procesar información y comunicarse con servicios.

También puede ejecutarse fuera del navegador mediante entornos como Node.js.
