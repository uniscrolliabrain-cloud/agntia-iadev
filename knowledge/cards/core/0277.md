# 0277 — ¿Qué es una abstracción?

## Contenido original

Es una representación que oculta detalles innecesarios y expone lo esencial para utilizar una capacidad.

Por ejemplo, una función `enviarCorreo()` puede ocultar las operaciones técnicas necesarias para comunicarse con un proveedor de email.

La abstracción permite trabajar con conceptos más cercanos al problema que queremos resolver.
