# 1031 — Event-driven architecture: arquitectura orientada a eventos

## Contenido original

Es un enfoque donde los componentes reaccionan a acontecimientos del sistema.

Por ejemplo, cuando se crea una factura, se publica el evento `invoice.created`\.

Otros componentes pueden procesarlo sin que el módulo de facturación tenga que conocer todos sus detalles internos.
