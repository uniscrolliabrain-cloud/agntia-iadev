# 0844 — SDK: kit de desarrollo de software

## Contenido original

Es una biblioteca que facilita trabajar con una plataforma.

En lugar de construir manualmente todas las peticiones HTTP, podemos utilizar funciones proporcionadas por el proveedor.

Un SDK no elimina la necesidad de comprender los permisos y los errores de la API.
