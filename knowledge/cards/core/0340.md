# 0340 — ¿Qué es un span?

## Contenido original

Es una unidad de trabajo registrada dentro de una traza.

Puede representar una consulta SQL, una llamada HTTP o la ejecución de una herramienta.

Un span suele incluir nombre, duración, atributos y relación con otros spans.

**Descubrimiento\:** un log cuenta qué ocurrió; una métrica ayuda a medir cuánto ocurre; una traza muestra cómo se desarrolló una operación.
