# 0175 — ¿Qué es un tenant?

## Contenido original

Un *tenant* es una unidad lógica de aislamiento dentro de una aplicación compartida.

En software empresarial suele representar una organización o cliente.

Por ejemplo, ACME y SOL pueden utilizar la misma aplicación sin compartir sus datos privados.
