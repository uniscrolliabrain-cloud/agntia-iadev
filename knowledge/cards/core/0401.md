# 0401 — ¿Qué es un índice vectorial?

## Contenido original

Es una estructura de datos que facilita buscar vectores cercanos sin tener que comparar necesariamente todos los elementos uno por uno.

Algunos índices aproximados sacrifican cierta exactitud para mejorar velocidad y escalabilidad.
