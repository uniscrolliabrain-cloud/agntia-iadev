# 0757 — Action: acción estructurada

## Contenido original

Es una solicitud formal para realizar una operación concreta.

Puede contener un tipo, parámetros, identidad del solicitante y contexto.

```ts
type Action = {
  type: "invoice.prepare";
  tenantId: string;
  actorId: string;
  customerId: string;
  amountCents: number;
};
```

El runtime no debería aceptar ciegamente los valores de identidad enviados por un modelo: debe obtenerlos o verificarlos mediante el contexto autenticado.
