# 0132 — ¿Qué es un componente?

## Contenido original

Es una unidad reutilizable de interfaz.

Puede representar un botón, una tarjeta de cliente, un formulario o una pantalla completa.

Por ejemplo, una aplicación empresarial puede utilizar el mismo componente de tarjeta para mostrar distintos empleados.
