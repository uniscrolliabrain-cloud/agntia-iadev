# 0019 — ¿Qué es una API?

## Contenido original

API significa *Application Programming Interface*, o interfaz de programación de aplicaciones.

Es una forma definida de permitir que un programa utilice funciones o datos de otro.

Por ejemplo, una aplicación puede consultar una API meteorológica para obtener una previsión sin construir su propio sistema de predicción.

En el desarrollo con IA, las APIs son fundamentales porque permiten conectar modelos, servicios empresariales y aplicaciones.
