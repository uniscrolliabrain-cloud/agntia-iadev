# 0029 — ¿Qué es un test?

## Contenido original

Un test es una comprobación que evalúa si el software cumple determinadas expectativas.

Por ejemplo, un test puede verificar que una persona sin permisos no puede consultar las facturas de otra empresa.

Los tests ayudan a detectar errores y evitar que vuelvan a aparecer cuando modificamos el código.
