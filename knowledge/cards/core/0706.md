# 0706 — NOT\_RUN: comprobación no ejecutada

## Contenido original

Es un estado explícito para indicar que una prueba todavía no se ha realizado.

Es importante porque la ausencia de errores registrados no demuestra que una comprobación haya sido satisfactoria.
