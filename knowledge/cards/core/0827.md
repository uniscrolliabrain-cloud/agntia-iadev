# 0827 — Refresh token: token de renovación

## Contenido original

Es una credencial que permite solicitar nuevos tokens de acceso bajo determinadas condiciones.

Su robo puede tener consecuencias importantes.

Debe almacenarse y gestionarse con controles adecuados, incluyendo rotación cuando corresponda.
