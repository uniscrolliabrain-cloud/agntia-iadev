# 0107 — ¿Qué es una promesa?

## Contenido original

Una promesa, o *Promise*, es un objeto que representa el resultado eventual de una operación asíncrona.

Puede encontrarse pendiente, cumplida o rechazada.

Es útil cuando una aplicación espera una respuesta de red, una lectura de datos u otra operación que no termina inmediatamente.
