# 0399 — ¿Qué es pgvector?

## Contenido original

pgvector es una extensión de PostgreSQL que permite almacenar vectores y realizar operaciones de similitud.

Puede utilizarse para incorporar búsqueda semántica a una aplicación que ya utiliza PostgreSQL.

No es necesario crear una base de datos independiente para todos los proyectos RAG.
