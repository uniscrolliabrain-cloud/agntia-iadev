# 0656 — Atomic write: escritura atómica

## Contenido original

Es una operación diseñada para que un cambio de archivo se haga visible como una unidad, evitando determinados estados intermedios.

Puede implementarse escribiendo un archivo temporal y sustituyendo después el destino mediante una operación apropiada del sistema de archivos.

No debe confundirse con escribir directamente todo el contenido mediante una sola llamada.
