# 0557 — ¿Qué es un conflicto de integración?

## Contenido original

Es una incompatibilidad entre cambios realizados por diferentes trabajos.

Puede manifestarse como un conflicto de Git o como un problema funcional que Git no detecta.

Por ejemplo, dos agentes pueden modificar contratos de manera incompatible aunque sus cambios se fusionen sin errores textuales.
