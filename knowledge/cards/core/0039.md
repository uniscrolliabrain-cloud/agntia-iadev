# 0039 — ¿Qué es una alucinación de IA?

## Contenido original

Es una respuesta generada por un modelo que presenta información falsa, inventada o no respaldada como si fuera correcta.

En desarrollo puede manifestarse cuando la IA afirma que una función existe, inventa una API o asegura que un test ha pasado sin haberlo ejecutado.

**Regla esencial\:** una afirmación del modelo no equivale a una comprobación técnica.
