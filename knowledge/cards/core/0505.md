# 0505 — ¿Qué es el aislamiento multitenant?

## Contenido original

Es el conjunto de mecanismos que impiden accesos indebidos entre organizaciones.

Puede incluir filtros de datos, políticas de base de datos, separación de almacenamiento y controles de autorización.

No debe depender únicamente de la interfaz visual.
