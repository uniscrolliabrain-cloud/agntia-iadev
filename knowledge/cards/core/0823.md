# 0823 — Google OAuth

## Contenido original

Es la integración con los mecanismos de autorización de Google.

Puede permitir que una aplicación solicite acceso a servicios concretos, como Calendar o Gmail.

Cada permiso debe justificarse y solicitarse mediante los scopes correspondientes.
