# 0344 — ¿Qué es un collector?

## Contenido original

Es un componente que recibe y procesa telemetría.

Puede agrupar datos, aplicar transformaciones, filtrar información y enviarla a diferentes destinos.

El OpenTelemetry Collector es un ejemplo de este tipo de herramienta.
