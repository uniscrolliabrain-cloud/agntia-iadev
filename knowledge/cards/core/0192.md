# 0192 — ¿Qué es producción?

## Contenido original

Producción es el entorno donde una aplicación presta el servicio real para el que fue construida.

Suele requerir mayores controles de seguridad, disponibilidad, recuperación y supervisión.

Una aplicación que funciona en tu ordenador todavía puede necesitar mucho trabajo antes de estar preparada para producción.
