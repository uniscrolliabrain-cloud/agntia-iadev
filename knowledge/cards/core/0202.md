# 0202 — ¿Qué es un certificado TLS?

## Contenido original

Es un documento digital que vincula una identidad o nombre de servicio con una clave pública, bajo un sistema de confianza.

Se utiliza, entre otras cosas, para establecer conexiones HTTPS seguras.

Los certificados tienen periodos de validez y deben renovarse.
