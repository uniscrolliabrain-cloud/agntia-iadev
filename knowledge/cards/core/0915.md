# 0915 — Environment variable

## Contenido original

Es un valor de configuración que el proceso recibe desde su entorno.

Por ejemplo\:

```ts
const port = process.env.PORT ?? "3000";
```

Permite configurar aplicaciones sin modificar su código para cada entorno.
