# 0184 — ¿Qué es una dirección IP?

## Contenido original

Es un identificador utilizado para comunicar dispositivos mediante el protocolo Internet.

Las direcciones IPv4 suelen representarse mediante cuatro números separados por puntos.

Por ejemplo, `192.0.2.10` es una dirección reservada para documentación.

Las direcciones IP permiten encaminar información entre redes.
