# 0170 — ¿Qué es un índice de base de datos?

## Contenido original

Es una estructura que permite localizar determinados datos más eficientemente.

Puedes imaginarlo como el índice de un libro.

En lugar de recorrer todas las páginas para encontrar una palabra, utilizas una estructura organizada que facilita la búsqueda.

Los índices mejoran algunas consultas, pero también consumen espacio y pueden añadir trabajo a las escrituras.
