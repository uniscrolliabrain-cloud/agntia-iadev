# 0068 — ¿Qué es el staging area?

## Contenido original

Es una zona de preparación donde Git reúne los cambios que incluirás en el siguiente commit.

Puedes modificar diez archivos y decidir registrar solamente tres.

Esto permite organizar los cambios de manera más clara.
