# 0900 — Observability acceptance gate: gate de observabilidad

## Contenido original

Es un control que verifica que una funcionalidad puede investigarse y supervisarse adecuadamente.

Puede comprobar que existen logs útiles, métricas, trazas, gestión de errores y alertas cuando sean necesarias.

**Descubrimiento\:** la observabilidad no es solamente un dashboard bonito. Es una infraestructura que permite comprender, mantener y mejorar el software con evidencias.
