# 0724 — Interface schema: esquema de interfaz

## Contenido original

Es una definición formal de la estructura de los datos que intercambian los componentes.

Puede establecer campos obligatorios, tipos, formatos y restricciones.

Por ejemplo\:

```json
{
  "customerId": "cus_123",
  "amountCents": 12500,
  "currency": "EUR"
}
```

El esquema ayuda a evitar que un servicio envíe datos que otro no sabe interpretar.
