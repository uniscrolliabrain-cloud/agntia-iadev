# 0138 — ¿Qué es el routing?

## Contenido original

Es el mecanismo que determina qué pantalla o contenido debe mostrarse según una ruta o ubicación de navegación.

Por ejemplo\:

`/clientes`

`/tareas`

`/configuracion`

Las aplicaciones de una sola página suelen utilizar bibliotecas de routing para navegar sin recargar completamente el documento.
