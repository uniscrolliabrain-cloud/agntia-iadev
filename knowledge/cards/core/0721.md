# 0721 — System boundary: límite del sistema

## Contenido original

Es la frontera que define qué responsabilidades pertenecen a un componente y cuáles quedan fuera.

Por ejemplo, el servicio de facturación calcula y registra facturas, mientras que la aplicación principal gestiona la experiencia del usuario.

Un límite claro evita que cada módulo intente hacerlo todo.
