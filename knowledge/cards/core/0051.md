# 0051 — ¿Qué es una especificación?

## Contenido original

Una especificación describe con suficiente precisión qué debe hacer un sistema y qué condiciones debe cumplir.

Es más concreta que una idea.

«Quiero una aplicación bonita» es una intención.

«Quiero una aplicación móvil con tres pantallas, autenticación y una lista de tareas que se sincronice entre dispositivos» comienza a ser una especificación.
