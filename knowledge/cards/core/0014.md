# 0014 — ¿Qué es un servidor?

## Contenido original

Un servidor es un programa o sistema que proporciona servicios a otros programas o dispositivos.

Puede almacenar información, verificar contraseñas, ejecutar cálculos o responder a solicitudes.

Imagina que entras en una tienda y preguntas por un producto. El empleado consulta el inventario y te responde. Un servidor puede desempeñar un papel parecido digitalmente.

Un mismo ordenador puede ejecutar varios servidores, y un servicio puede estar distribuido entre múltiples máquinas.
