# 0244 — ¿Qué es una prueba unitaria?

## Contenido original

Es una prueba que comprueba una unidad pequeña de comportamiento, como una función.

Por ejemplo, podemos verificar que una función calcula correctamente el IVA.

Las pruebas unitarias suelen ser rápidas y relativamente fáciles de ejecutar.
