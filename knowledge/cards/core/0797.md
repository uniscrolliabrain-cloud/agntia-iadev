# 0797 — ACID

## Contenido original

Son cuatro propiedades clásicas de las transacciones\:

**Atomicidad\:** todo o nada.

**Consistencia\:** se respetan las restricciones definidas.

**Aislamiento\:** se controlan las interacciones entre transacciones concurrentes.

**Durabilidad\:** una transacción confirmada se conserva según las garantías del sistema.
