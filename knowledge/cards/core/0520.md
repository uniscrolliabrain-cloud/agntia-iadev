# 0520 — ¿Qué es la divulgación progresiva?

## Contenido original

Es una técnica de diseño que presenta primero la información esencial y revela detalles adicionales cuando son necesarios.

Por ejemplo, un formulario puede mostrar opciones básicas y ofrecer una sección de configuración avanzada.

**Descubrimiento\:** una buena interfaz no muestra necesariamente todo lo que el software puede hacer; muestra lo que el usuario necesita en ese momento.
