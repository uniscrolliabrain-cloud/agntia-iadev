# 0585 — ¿Qué es un contenedor de aplicación?

## Contenido original

Es una forma de empaquetar software junto con los elementos necesarios para ejecutarlo en un entorno aislado a nivel de procesos.

Los contenedores facilitan la portabilidad y consistencia.

No proporcionan por sí solos el mismo aislamiento de seguridad que una máquina virtual completa.
