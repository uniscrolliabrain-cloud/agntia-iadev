# 0691 — Execution report: reporte de ejecución

## Contenido original

Es un documento que registra qué operaciones se realizaron durante una tarea o campaña.

Debe responder preguntas concretas\:

¿Qué se hizo? ¿Dónde? ¿Con qué resultado? ¿Qué no se pudo completar?

**Ejemplo\:** el agente encargado de facturación informa de tres archivos modificados, seis tests ejecutados y una prueba bloqueada por falta de credenciales.

No basta con escribir «tarea completada».
