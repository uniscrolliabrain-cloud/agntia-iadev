# 0065 — ¿Qué es un hash?

## Contenido original

Un hash es un identificador calculado a partir de información mediante una función matemática.

Git utiliza identificadores hash para sus objetos, incluidos los commits.

Cuando ves una cadena como `a8c32f1`, normalmente estás viendo una abreviatura de un identificador más largo.

Esto permite referirse con precisión a un estado concreto del proyecto.
