# 0434 — ¿Qué es un retry?

## Contenido original

Es un nuevo intento de ejecutar una operación que ha fallado.

Puede ser apropiado cuando el error es temporal, como una interrupción de red.

No todos los errores deben reintentarse: repetir una operación incorrectamente puede empeorar el problema.
