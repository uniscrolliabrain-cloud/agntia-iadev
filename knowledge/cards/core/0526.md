# 0526 — ¿Qué es un componente reutilizable?

## Contenido original

Es una pieza de interfaz diseñada para utilizarse en diferentes lugares.

Por ejemplo, una tarjeta de empleado o un botón de aprobación.

La reutilización reduce inconsistencias y facilita el mantenimiento.
