# 0222 — ¿Qué es el hashing de contraseñas?

## Contenido original

Es el proceso de transformar una contraseña mediante una función diseñada para su almacenamiento seguro.

Para contraseñas se utilizan algoritmos especializados como Argon2id, que incorporan mecanismos para dificultar ataques de adivinación.

No es lo mismo que cifrar: normalmente no se pretende recuperar la contraseña original.
