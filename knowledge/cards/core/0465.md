# 0465 — ¿Qué es un refresh token?

## Contenido original

Es una credencial que, cuando el proveedor y el flujo lo permiten, puede utilizarse para obtener nuevos access tokens.

Su manejo exige especial cuidado porque puede permitir mantener el acceso durante más tiempo.

No todos los proveedores o flujos entregan refresh tokens.
