# 0576 — ¿Qué es un artefacto de compilación?

## Contenido original

Es un resultado producido durante el proceso de construcción.

Puede ser un archivo comprimido, un paquete, una imagen de contenedor o una carpeta con archivos preparados.

Guardar artefactos identificables ayuda a saber exactamente qué versión se publicó.
