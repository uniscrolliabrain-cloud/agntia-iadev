# 0767 — Timeout: límite de espera

## Contenido original

Es el tiempo máximo permitido para esperar una operación.

Si una API externa no responde, el sistema no debería quedar bloqueado indefinidamente.

Un timeout no garantiza que la operación externa no haya ocurrido.
