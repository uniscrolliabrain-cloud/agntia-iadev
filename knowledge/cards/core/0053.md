# 0053 — ¿Qué es una tarea de desarrollo?

## Contenido original

Es una unidad concreta de trabajo técnico.

Puede consistir en crear un botón, corregir un error, añadir una API o escribir un test.

Una buena tarea tiene un objetivo claro y un criterio para determinar cuándo está terminada.
