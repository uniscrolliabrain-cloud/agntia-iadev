# 0482 — ¿Qué es una cuenta de usuario?

## Contenido original

Es un registro que permite a una persona acceder a determinadas funcionalidades.

Puede contener un identificador, correo electrónico, preferencias y referencias a credenciales.

Una misma cuenta puede pertenecer a varias organizaciones si la aplicación lo permite.
