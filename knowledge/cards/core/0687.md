# 0687 — Merge readiness: preparación para integración

## Contenido original

Es la evaluación de si una rama o conjunto de cambios está listo para proponerse para integración.

Puede exigir pruebas, revisión, documentación y resolución de conflictos.

Estar preparado para un merge no significa tener autorización para realizarlo.
