# 0247 — ¿Qué es un smoke test?

## Contenido original

Es un conjunto reducido de comprobaciones que busca detectar fallos importantes de funcionamiento.

Por ejemplo, verificar que el servidor arranca, la aplicación carga y las rutas esenciales responden.

No sustituye a una batería completa de pruebas.
