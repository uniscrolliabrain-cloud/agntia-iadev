# 0118 — ¿Qué es una automatización?

## Contenido original

Es un proceso que ejecuta tareas siguiendo reglas o instrucciones con poca intervención manual.

Por ejemplo, descargar datos, transformarlos y preparar un documento cada mañana.

Una automatización no necesita necesariamente inteligencia artificial.

Puede ser completamente determinista.
