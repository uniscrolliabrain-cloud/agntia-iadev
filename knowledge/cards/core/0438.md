# 0438 — ¿Qué es una dead-letter queue?

## Contenido original

Es una cola destinada a trabajos que no pueden procesarse correctamente después de determinadas condiciones o intentos.

Permite conservarlos para investigación y tratamiento posterior.

Evita que determinados trabajos fallidos bloqueen indefinidamente el procesamiento normal.
