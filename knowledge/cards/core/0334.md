# 0334 — ¿Qué es un nivel de log?

## Contenido original

Es una clasificación que indica la importancia o naturaleza de un registro.

Entre los niveles habituales encontramos `debug`, `info`, `warn` y `error`\.

Una aplicación puede utilizar niveles distintos según el entorno y las necesidades de diagnóstico.
