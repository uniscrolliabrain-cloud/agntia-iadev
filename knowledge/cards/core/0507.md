# 0507 — ¿Qué es un tenant ID?

## Contenido original

Es un identificador que permite asociar recursos y operaciones con una organización o tenant.

Por ejemplo, una factura puede contener una referencia a la empresa propietaria.

El sistema no debe confiar ciegamente en un tenant ID proporcionado por el cliente.
