# 1002 — Git worktree

## Contenido original

Es una funcionalidad de Git que permite disponer de varios directorios de trabajo vinculados al mismo repositorio.

Cada worktree puede utilizar una rama diferente.

Resulta especialmente útil para agentes que trabajan simultáneamente.
