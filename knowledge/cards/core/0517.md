# 0517 — ¿Qué es una historia de usuario?

## Contenido original

Es una forma breve de expresar una necesidad desde la perspectiva de una persona.

Ejemplo\:

«Como propietario, quiero consultar las tareas pendientes para saber qué necesita mi atención».

Suele acompañarse de criterios de aceptación.
