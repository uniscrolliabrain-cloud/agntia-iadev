# 1054 — Model routing: enrutamiento de modelos

## Contenido original

Es el mecanismo que selecciona qué modelo utilizar para cada tarea.

Por ejemplo, una consulta sencilla puede enviarse a un modelo económico y rápido, mientras que una planificación compleja puede utilizar otro.

El routing puede considerar coste, latencia, capacidades y políticas.
