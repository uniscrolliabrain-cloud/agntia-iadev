# 0135 — ¿Qué es el estado?

## Contenido original

El estado es información que una aplicación o componente mantiene y que puede cambiar con el tiempo.

Por ejemplo, una lista de tareas, el texto de un formulario o si un menú está abierto.

Cuando cambia el estado relevante, React puede actualizar la interfaz.
