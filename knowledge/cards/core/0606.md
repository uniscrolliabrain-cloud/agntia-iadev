# 0606 — Baseline: línea base

## Contenido original

Es el estado de referencia del proyecto antes de realizar cambios.

Puede registrar\:

- Commit o SHA exacto.
- Rama analizada.
- Resultados de typecheck y tests.
- Errores existentes.
- Configuración relevante.

Sin baseline, un agente podría atribuir a sus modificaciones un bug que ya existía.
