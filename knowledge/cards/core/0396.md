# 0396 — ¿Qué es el chunking?

## Contenido original

Es la estrategia utilizada para dividir información en fragmentos.

Puede realizarse por número de caracteres, tokens, párrafos, encabezados o estructura semántica.

Un chunk demasiado pequeño puede perder contexto. Uno demasiado grande puede contener información innecesaria.
