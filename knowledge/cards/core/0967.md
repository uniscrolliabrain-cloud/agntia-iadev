# 0967 — Regression test: prueba de regresión

## Contenido original

Comprueba que un comportamiento que funcionaba anteriormente sigue funcionando después de un cambio.

Cuando encontramos un bug, conviene crear una prueba que reproduzca el problema y evite su reaparición.
