# 0355 — ¿Qué es un event bus?

## Contenido original

Es un mecanismo mediante el cual diferentes componentes publican y consumen eventos.

Permite desacoplar parcialmente productores y consumidores.

Por ejemplo, cuando se crea una factura, otros componentes pueden reaccionar al evento sin estar integrados directamente en la función que la creó.
