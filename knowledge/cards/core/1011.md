# 1011 — Parallel campaign: campaña paralela

## Contenido original

Es una campaña diseñada para ejecutarse simultáneamente con otras.

Debe tener dependencias y superficies de escritura claramente definidas.

No todas las tareas pueden paralelizarse de forma segura.
