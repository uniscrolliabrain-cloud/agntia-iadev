# 0154 — ¿Qué es una petición HTTP?

## Contenido original

Es un mensaje que un cliente envía a un servidor solicitando información o una operación.

Por ejemplo, tu navegador puede enviar una petición para obtener la lista de clientes de una aplicación.

El servidor procesa la solicitud y devuelve una respuesta.
