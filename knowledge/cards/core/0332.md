# 0332 — ¿Qué es la telemetría?

## Contenido original

Es la información recopilada sobre el funcionamiento de un sistema y enviada o almacenada para su análisis.

Puede incluir tiempos de respuesta, consumo de memoria, errores y eventos de ejecución.

La telemetría es la materia prima que utilizamos para observar el software.
