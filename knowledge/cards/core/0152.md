# 0152 — ¿Qué es un servidor web?

## Contenido original

Es un programa que recibe solicitudes mediante protocolos web y devuelve respuestas.

Puede entregar archivos, datos o resultados de operaciones.

Un servidor web puede ejecutarse en un ordenador propio, una máquina virtual, un contenedor o una plataforma cloud.
