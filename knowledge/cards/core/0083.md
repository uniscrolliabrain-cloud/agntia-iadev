# 0083 — ¿Qué es un issue?

## Contenido original

Un *issue* es un registro de trabajo, problema o propuesta dentro de un repositorio.

Puede representar un error, una mejora o una tarea pendiente.

Permite documentar decisiones y mantener conversaciones vinculadas al proyecto.
