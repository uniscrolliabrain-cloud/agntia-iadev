# 0704 — FAIL: verificación fallida

## Contenido original

Indica que una comprobación ejecutada no cumplió sus criterios.

Debe acompañarse de información suficiente para investigar la causa.

Un FAIL no debería ocultarse para que la campaña parezca completada.
