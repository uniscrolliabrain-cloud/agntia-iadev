# 0441 — ¿Qué es la ejecución determinista?

## Contenido original

Es una forma de ejecución en la que, dadas las mismas entradas y condiciones relevantes, un componente produce el mismo resultado conforme a reglas definidas.

En un sistema agéntico, puede utilizarse para validar permisos, transiciones y formatos.

No significa que todo el sistema sea completamente determinista: redes, servicios externos y modelos pueden introducir variabilidad.
