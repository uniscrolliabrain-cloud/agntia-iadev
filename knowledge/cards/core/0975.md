# 0975 — Test fixture: preparación de prueba

## Contenido original

Es un conjunto de datos, objetos o condiciones que necesitamos antes de ejecutar una prueba.

Por ejemplo, crear una empresa ficticia con dos usuarios y tres facturas.

Las fixtures deben ser reproducibles y estar aisladas de datos reales.
