# 0294 — ¿Qué es un adaptador?

## Contenido original

Es una implementación que conecta un puerto con una tecnología o sistema concreto.

Por ejemplo, un adaptador puede utilizar PostgreSQL para implementar un contrato de almacenamiento.

Otro adaptador podría utilizar una base de datos de prueba.
