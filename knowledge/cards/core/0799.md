# 0799 — Index: índice

## Contenido original

Es una estructura que ayuda a localizar registros más rápidamente para determinadas consultas.

Por ejemplo\:

```sql
CREATE INDEX idx_invoices_customer
ON invoices(customer_id);
```

Los índices pueden acelerar lecturas, pero consumen almacenamiento y añaden trabajo a ciertas escrituras.
