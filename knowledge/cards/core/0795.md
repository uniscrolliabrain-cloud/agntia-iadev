# 0795 — Parameterized query: consulta parametrizada

## Contenido original

Es una consulta donde los valores se envían separados del texto SQL.

Esto ayuda a prevenir inyecciones SQL cuando se utiliza correctamente.

```ts
await pool.query(
  "SELECT * FROM customers WHERE id = $1",
  [customerId]
);
```

Los nombres de tablas y columnas dinámicos necesitan otro tratamiento: no se protegen automáticamente mediante parámetros de valores.
