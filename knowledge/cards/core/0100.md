# 0100 — ¿Qué es un operador?

## Contenido original

Un operador es un símbolo o construcción que realiza una operación.

Algunos ejemplos\:

| Operador | Significado |
|--------|--------|
| `+` | Suma o concatenación de texto |
| `-` | Resta |
| `*` | Multiplicación |
| `/` | División |
| `===` | Igualdad estricta en JavaScript |
| `>` | Mayor que |

**Descubrimiento\:** muchos programas complejos se construyen combinando estructuras sorprendentemente sencillas.
