# 0658 — Rollback: reversión

## Contenido original

Es el proceso de regresar a un estado anterior cuando un cambio produce problemas.

Puede realizarse revirtiendo commits, restaurando archivos o utilizando un procedimiento específico de recuperación.

Los cambios en bases de datos requieren especial cuidado.
