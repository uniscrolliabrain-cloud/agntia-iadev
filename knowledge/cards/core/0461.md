# 0461 — ¿Qué es OAuth 2.0?

## Contenido original

Es un marco de autorización que permite a una aplicación obtener acceso limitado a recursos protegidos.

Por ejemplo, un usuario puede autorizar que una aplicación consulte determinados datos de su cuenta de Google.

OAuth no significa que debas conocer la contraseña del usuario.
