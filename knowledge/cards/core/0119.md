# 0119 — ¿Qué es una integración entre lenguajes?

## Contenido original

Es una forma de permitir que componentes escritos en lenguajes diferentes colaboren.

Por ejemplo, una aplicación TypeScript puede comunicarse mediante una API con un servicio Python que procesa vídeo.

Ambos componentes no necesitan compartir el mismo lenguaje, pero sí deben acordar cómo intercambian información.
