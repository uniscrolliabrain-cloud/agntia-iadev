# 0538 — ¿Qué es una interfaz multimodal?

## Contenido original

Es una interfaz que permite combinar diferentes formas de interacción.

Por ejemplo, texto, voz, imágenes y elementos gráficos.

Una aplicación puede permitir conversar con una IA mientras se consulta o edita un documento.
