# 0831 — Service account: cuenta de servicio

## Contenido original

Es una identidad utilizada por software para realizar operaciones.

Puede permitir que un worker acceda a recursos sin iniciar sesión como una persona.

Debe tener permisos limitados y credenciales gestionadas de forma segura.
