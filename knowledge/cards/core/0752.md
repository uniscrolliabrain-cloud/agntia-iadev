# 0752 — Node.js

## Contenido original

Es el entorno que permite ejecutar JavaScript y TypeScript compilado fuera del navegador.

Por ejemplo, un servidor puede recibir una petición, consultar una base de datos y devolver una respuesta.

```bash
node --version
```

Este comando comprueba la versión instalada.

**Con un agente\:** podemos pedirle que inspeccione la versión requerida por el proyecto, revise los scripts y explique cómo se inicia el servidor. No debe cambiar versiones sin analizar compatibilidad.
