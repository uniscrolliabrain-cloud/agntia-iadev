# 1076 — Fail-closed

## Contenido original

Es el principio según el cual, cuando un control de seguridad falla o no puede determinar el permiso, la operación protegida se bloquea.

Por ejemplo, si el motor de políticas no responde, no deberíamos enviar una transferencia bancaria.
