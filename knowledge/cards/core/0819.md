# 0819 — Multi-factor authentication: autenticación multifactor

## Contenido original

Es la combinación de factores diferentes para verificar una identidad.

Por ejemplo, una contraseña y una llave de seguridad.

Aumenta la protección frente a determinados tipos de robo de credenciales.
