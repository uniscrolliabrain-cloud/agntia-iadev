# 0156 — ¿Qué son GET, POST, PUT y DELETE?

## Contenido original

Son métodos HTTP que expresan la intención de una solicitud.

| Método | Uso habitual |
|--------|--------|
| `GET` | Consultar información |
| `POST` | Enviar datos o solicitar una operación |
| `PUT` | Crear o reemplazar un recurso en una ubicación definida |
| `DELETE` | Solicitar la eliminación de un recurso |

Estos métodos no garantizan por sí solos lo que hará el servidor: el comportamiento real depende de su implementación.
