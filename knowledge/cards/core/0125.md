# 0125 — ¿Qué es el DOM?

## Contenido original

DOM significa *Document Object Model*\.

Es una representación estructurada de un documento que permite a los programas consultar y modificar sus elementos.

JavaScript puede utilizar el DOM para cambiar textos, añadir elementos o responder a interacciones.
