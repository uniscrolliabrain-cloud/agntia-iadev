# 0312 — ¿Qué es un handoff?

## Contenido original

Es la transferencia organizada de información y responsabilidad entre colaboradores.

En desarrollo con agentes puede incluir el estado actual, archivos relevantes, decisiones tomadas, tareas pendientes y comandos para continuar.

Un buen handoff permite que otro agente retome el trabajo sin tener que reconstruir toda la conversación anterior.
