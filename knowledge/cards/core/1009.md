# 1009 — Rebase

## Contenido original

Es una operación que permite reproducir commits sobre una base diferente.

Puede ayudar a actualizar una rama.

Debe utilizarse con cuidado, especialmente si otros agentes trabajan sobre la misma historia compartida.
