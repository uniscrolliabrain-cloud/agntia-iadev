# 0778 — RxJS: flujos reactivos

## Contenido original

RxJS es una biblioteca para trabajar con secuencias de valores y eventos a lo largo del tiempo.

Puede utilizarse para coordinar flujos asíncronos.

No es obligatorio usarla para construir un bus de eventos: es una herramienta con un propósito más amplio.
