# 0225 — ¿Qué es un token de acceso?

## Contenido original

Es una credencial que permite a un cliente acceder a determinados recursos o servicios bajo ciertas condiciones.

Puede tener una duración limitada y representar permisos concretos.

Un token debe tratarse como información sensible cuando su posesión permite realizar operaciones.
