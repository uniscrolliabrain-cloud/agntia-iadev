# 0098 — ¿Qué es un array?

## Contenido original

Un *array* es una estructura que permite almacenar una colección ordenada de elementos.

```javascript

const tareas = [
  "Responder correos",
  "Preparar presupuesto",
  "Llamar al cliente"
];
```

Puedes imaginarlo como una lista numerada.

Los arrays permiten recorrer elementos, filtrarlos y transformarlos.
