# 0161 — ¿Qué es la persistencia?

## Contenido original

Es la capacidad de conservar información más allá de la ejecución inmediata de un programa.

Si una tarea sigue existiendo después de cerrar la aplicación y volver a abrirla, existe algún mecanismo de persistencia.

Puede utilizar archivos, bases de datos u otros sistemas de almacenamiento.
