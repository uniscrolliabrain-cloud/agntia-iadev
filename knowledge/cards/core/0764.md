# 0764 — Idempotency key: clave de idempotencia

## Contenido original

Es un identificador que permite reconocer reintentos de una misma operación.

```ts
const key = "invoice-request-001";
```

En producción, las claves deben tener un alcance definido, por ejemplo por empresa y operación. También hay que comprobar que una misma clave no se reutilice con parámetros incompatibles.
