# 0840 — Identity security gate: gate de seguridad de identidad

## Contenido original

Es un control que comprueba que una modificación respeta las reglas de autenticación, autorización, aislamiento y delegación.

Puede exigir pruebas de acceso cruzado, revocación, scopes y permisos mínimos.

**Descubrimiento\:** un agente de IA debe operar con una identidad técnica reconocible y una autorización limitada, no con privilegios ilimitados por ser parte del sistema.
