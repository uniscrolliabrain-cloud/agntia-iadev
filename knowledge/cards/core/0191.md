# 0191 — ¿Qué es un despliegue?

## Contenido original

Un despliegue es el proceso de poner una versión del software en un entorno donde pueda ejecutarse.

Puede realizarse en desarrollo, pruebas o producción.

Desplegar no significa necesariamente que la versión sea correcta o esté preparada para recibir usuarios reales.
