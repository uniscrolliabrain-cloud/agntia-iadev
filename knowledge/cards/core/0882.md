# 0882 — Instrumentation: instrumentación

## Contenido original

Es el proceso de añadir mecanismos para medir el funcionamiento del software.

Puede realizarse mediante bibliotecas automáticas o código explícito.

Por ejemplo, instrumentar una petición HTTP para registrar su duración.
