# 0940 — Security hardening: endurecimiento

## Contenido original

Es el proceso de reducir oportunidades de ataque mediante configuraciones, restricciones y controles adicionales.

Por ejemplo, retirar permisos innecesarios, proteger endpoints y reforzar la gestión de secretos.

**Descubrimiento\:** la seguridad comienza identificando qué tenemos y qué debemos proteger, no ejecutando herramientas indiscriminadamente.
