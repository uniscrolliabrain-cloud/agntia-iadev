# 0886 — Grafana

## Contenido original

Es una plataforma para visualizar y analizar datos operativos.

Permite construir dashboards y configurar alertas a partir de fuentes compatibles.

Grafana no es necesariamente el sistema que almacena todos los logs, métricas y trazas: puede consultar distintos backends.
