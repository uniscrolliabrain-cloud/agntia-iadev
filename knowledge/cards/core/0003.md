# 0003 — ¿Qué es el software?

## Contenido original

El software es el conjunto de programas, instrucciones y recursos digitales que permiten realizar tareas con el hardware.

Un navegador, un videojuego, una aplicación bancaria y un editor de fotografías son ejemplos de software.

**La diferencia fundamental\:** el hardware proporciona las capacidades físicas; el software organiza cómo se utilizan.
