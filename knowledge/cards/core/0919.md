# 0919 — Dockerfile

## Contenido original

Es un archivo que contiene instrucciones para construir una imagen de contenedor.

Ejemplo educativo\:

```dockerfile
FROM node:22-alpine

WORKDIR /app

COPY package.json pnpm-lock.yaml ./

RUN corepack enable && pnpm install --frozen-lockfile

COPY . .

RUN pnpm build

CMD ["pnpm", "start"]
```

Este ejemplo supone que el proyecto dispone de los scripts necesarios. En un monorepo puede requerirse copiar también el workspace y otros manifiestos antes de instalar dependencias.
