# 1048 — Saga pattern

## Contenido original

Es un patrón para coordinar operaciones distribuidas mediante pasos y, cuando corresponda, acciones compensatorias.

Resulta útil cuando no podemos utilizar una única transacción de base de datos para toda la operación.

Las compensaciones no siempre revierten perfectamente todos los efectos externos.
