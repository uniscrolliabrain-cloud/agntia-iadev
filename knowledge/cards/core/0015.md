# 0015 — ¿Qué es un cliente?

## Contenido original

En informática, un cliente es un programa que solicita servicios a otro sistema.

Tu navegador suele actuar como cliente cuando solicita información a un servidor web.

La palabra no significa necesariamente una persona que paga. Describe un papel dentro de una comunicación informática.
