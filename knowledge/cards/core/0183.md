# 0183 — ¿Qué es un puerto?

## Contenido original

Un puerto es un identificador numérico utilizado por protocolos de transporte para dirigir comunicaciones a servicios concretos.

Imagina un edificio con una dirección postal y diferentes oficinas.

La dirección identifica el edificio; el puerto ayuda a identificar el servicio al que queremos comunicarnos.

Por ejemplo, un servidor de desarrollo puede utilizar el puerto 3000 y otro el 5173.
