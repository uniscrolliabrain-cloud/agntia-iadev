# 0513 — ¿Qué es UI?

## Contenido original

UI significa *User Interface*, o interfaz de usuario.

Es el conjunto de elementos con los que una persona interactúa: botones, menús, formularios, textos, iconos y pantallas.

Una interfaz visualmente atractiva no garantiza una buena experiencia de usuario.
