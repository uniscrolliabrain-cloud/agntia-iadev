# 0196 — ¿Qué es Fly.io?

## Contenido original

Fly.io es una plataforma que permite ejecutar aplicaciones y servicios sobre infraestructura administrada.

Puede utilizarse para alojar determinados backends y procesos.

La elección de plataforma depende de los requisitos técnicos, operativos y económicos de cada aplicación.
