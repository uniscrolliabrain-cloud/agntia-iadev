# 0104 — ¿Qué es una interfaz en TypeScript?

## Contenido original

Es una forma de describir la estructura que debe tener un valor.

```typescript

interface Cliente {
  nombre: string;
  email: string;
  activo: boolean;
}
```

Podemos utilizar esta definición para comprobar que diferentes partes del código manejan los datos con una estructura coherente.
