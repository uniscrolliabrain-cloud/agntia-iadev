# 0634 — Hunk: fragmento localizado de un cambio

## Contenido original

En Git, un *hunk* es una sección de un diff que agrupa cambios cercanos y líneas de contexto.

En una metodología de patching, podemos utilizar el término para identificar una modificación localizada dentro de un patchset.

**Convención didáctica\:** un hunk tendrá un objetivo concreto y un identificador, como `H03`\.
