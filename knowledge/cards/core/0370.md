# 0370 — ¿Qué es una capa de transformer?

## Contenido original

Es una etapa de procesamiento que combina mecanismos como atención, transformaciones neuronales y normalización.

Los modelos suelen utilizar múltiples capas.

A medida que la información atraviesa estas capas, se producen representaciones internas cada vez más transformadas.
