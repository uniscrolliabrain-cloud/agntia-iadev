# 0411 — ¿Qué es la memoria persistente de una IA?

## Contenido original

Es un mecanismo que conserva información útil más allá de una interacción o sesión concreta.

Puede almacenar preferencias, decisiones, hechos autorizados o estados de trabajo.

No significa que el modelo haya modificado necesariamente sus parámetros internos.
