# 0319 — ¿Qué es una dependencia entre tareas?

## Contenido original

Es una relación en la que una tarea necesita que otra proporcione previamente un resultado.

Por ejemplo, no podemos integrar una nueva API si todavía no se ha definido su contrato.

Identificar dependencias permite ordenar correctamente el trabajo.
