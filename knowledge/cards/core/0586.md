# 0586 — ¿Qué es un registro de imágenes?

## Contenido original

Es un servicio donde se almacenan y distribuyen imágenes de contenedores.

Un pipeline puede construir una imagen, asignarle un identificador y publicarla en un registro.

Después, un entorno puede recuperar esa imagen para ejecutar la aplicación.
