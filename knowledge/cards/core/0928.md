# 0928 — Rollback: reversión

## Contenido original

Es el procedimiento para volver a una versión o estado anterior después de un problema.

No todos los cambios pueden revertirse fácilmente.

Por ejemplo, una migración destructiva de base de datos puede requerir recuperación específica.
