# 0949 — OWASP ZAP

## Contenido original

Es una herramienta de seguridad para analizar aplicaciones web.

Puede utilizarse en entornos controlados para detectar determinadas debilidades.

Un agente puede preparar un plan de pruebas con ZAP, pero los escaneos activos requieren autorización y límites claros.
