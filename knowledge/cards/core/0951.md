# 0951 — Input validation: validación de entradas

## Contenido original

Es la comprobación de que los datos recibidos cumplen las reglas esperadas.

Por ejemplo, Zod puede rechazar un importe negativo o un identificador vacío.

La validación no sustituye la autorización ni otras medidas de seguridad.
