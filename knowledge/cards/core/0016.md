# 0016 — ¿Qué es frontend?

## Contenido original

El frontend es la parte de una aplicación con la que el usuario interactúa directamente.

Incluye pantallas, botones, formularios, menús, gráficos y otros elementos visuales.

En AgntiaPro, el chat con Laia, el menú de navegación y los paneles de trabajo pertenecen a la experiencia frontend.
