# 0679 — Write collision: colisión de escritura

## Contenido original

Ocurre cuando dos agentes intentan modificar la misma superficie de trabajo de forma incompatible.

Puede provocar conflictos de Git, pérdida de cambios o inconsistencias.

Las allowlists y la planificación de waves ayudan a reducirlo.
