# 0226 — ¿Qué es JWT?

## Contenido original

JWT significa *JSON Web Token*\.

Es un formato para representar información mediante declaraciones o *claims*, que puede estar firmado y, en determinadas variantes, cifrado.

Un JWT no es seguro simplemente por tener tres fragmentos separados por puntos.

El sistema debe validar correctamente firma, algoritmo, emisor, audiencia, caducidad y otras condiciones relevantes.
