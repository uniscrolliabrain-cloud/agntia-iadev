# 0873 — Structured logging: logs estructurados

## Contenido original

Un log es un registro de algo que ocurrió.

Los logs estructurados utilizan campos identificables, habitualmente en JSON.

```json
{
  "level": "info",
  "event": "invoice.prepared",
  "tenantId": "company_demo",
  "durationMs": 128,
  "status": "success"
}
```

Esto permite filtrar y analizar información automáticamente.

**Con un agente\:** podemos pedirle que busque todos los errores relacionados con una operación, los agrupe por causa y genere un diagnostic report.
