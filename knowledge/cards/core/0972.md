# 0972 — Node.js Test Runner

## Contenido original

Es el sistema de pruebas integrado en Node.js.

Permite escribir y ejecutar tests sin instalar necesariamente un framework externo.

```ts
import test from "node:test";
import assert from "node:assert/strict";

test("invoice amount", () => {
  assert.equal(450 + 50, 500);
});
```

El comando exacto para ejecutar archivos TypeScript depende de la versión de Node y de la configuración del proyecto.
